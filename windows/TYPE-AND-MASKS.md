# 文字、蒙版与排版

适用于 Windows **1.5.5.0 Preview**。

## PSD 与文字编辑

导入 8 位 RGB／CMYK PSD 或 PSB 后，支持的 TySh／EngineData 文字保留 Unicode 内容、字体名和字符范围样式，矢量蒙版保留闭合贝塞尔路径、孔洞与启用／链接状态。缺失字体可通过“文字 → 管理缺失字体”在整个文档替换。双击／使用 T 工具点击已有文字，拖动选择字符；Shift 配合方向键扩展选区，Ctrl+A/C/X/V 全选、复制、剪切和粘贴。字体、字号、颜色、粗斜体及字符属性应用到选中文字。插入、删除和撤销保留范围格式；空白原有文字层也能继续输入。存为 `.comp` 后保留编辑能力。

顶部“文字”菜单提供字符、段落、字形、字符样式和段落样式面板；消除锯齿、横排／竖排、OpenType、创建工作路径、转形状／栅格化／段落文本、块／圆形／拱形／领结几何、文字变形、匹配字体、字体预览大小、语言与数字方向、更新文字层、缺失字体管理、Lorem Ipsum 和默认样式。字符和段落样式可创建、应用、更新、清除覆盖或删除。字形面板按字体枚举实际支持的 Unicode 字形，可按区段过滤并插入。

字体输入框右侧下拉按钮提供本机字体搜索、分类、收藏和实际字体预览。已移除 Adobe Fonts 外链入口。匹配字体需要输入样本文字，按本地字形与比例排序；不执行 OCR，也不下载或自动激活收费字体。OpenType 效果取决于字体是否提供对应特性。

文字渲染使用 Skia／HarfBuzz。PSD 的缺失字体、复杂排版、倾斜矩阵与变形可能与 Photoshop 不同；转换报告会说明。Windows／Windows LCD 消除锯齿选项对应 Skia 字体边缘与 hinting。几何文字、亚洲断行和阿拉伯整形为本项目实现，并非 Adobe 排版引擎；段落设置当前作用于文字对象，复杂变形文字的选择高亮为近似区域。

## 蒙版与缩览图菜单

直接在蒙版缩览图上右键：启用／停用、删除、应用像素蒙版或栅格化矢量蒙版，以及添加／减去／交叉选区。“蒙版选项”设置叠加显示颜色、不透明度；“选择并遮住”进入属性侧栏。

侧栏支持预览模式、显示边缘／原稿、实时预览、预设、半径／智能半径、平滑、羽化、对比度、边缘偏移、清除／反相、净化颜色；可输出为原图层蒙版、选区、新图层或带蒙版的新图层。确定形成可撤销编辑，取消恢复原文档。颜色／对象识别采用局部颜色或亮度差异加权边缘算法，并非 Adobe 的云端主体识别模型。调整矢量蒙版边缘后输出为像素蒙版；同层 PSD 像素与矢量双蒙版目前合并为单个像素蒙版。

图像／文件夹缩览图右键提供混合选项、适用的调整编辑、像素／透明度选区操作、无／小／中／大缩览图、图层／文档边界裁切和颜色标签。文件夹无独立像素时相关选区操作禁用。

## 界面与印刷输出

首选项切换浅色主题后，图层模块、输入控件与图标立即使用同一套主题色。左侧栏间距缩小到 2，属性输入与按钮变紧凑。对齐与分布图标以用户 084116 截图为准，居中及其他基准线均为 1.5 逻辑像素，详见[设计来源](design/README.md)。

“视图 → CMYK”可选择内置 US Web Coated SWOP、Coated FOGRA39 或载入 CMYK ICC 配置文件，开启校样颜色和色域警告。PSD／JPEG／TIFF 的 CMYK 配置文件随新文档保留。工作像素仍为 sRGB；软打样仅改变显示。色域警告根据配置文件往返转换的 RGB 差异标记灰色，与其他软件的容差可能不同。

“导出为”每次默认 RGB。选择 CMYK 可导出含 ICC 的 JPEG／TIFF／单页 PDF，透明部分按背景色铺底。TIFF 的“文档模式”保留当前 Lab／灰度等模式。PNG／EXR 保持 RGB。渐进模糊支持线性／径向、起止半径、位置百分比、反转、预览和重复上次滤镜，使用 12 级浮点高斯结果插值；位置通过面板数值控制，当前输出限制在图层边界内，与上游可拖动控制线及边缘扩展有差异。

新范围样式、文字几何、矢量填充规则、附加颜色标签和 ICC 配置需要[Windows 格式 v20](../docs/project-format.md#windows-extension-version-20)。OpenCL 迁移保持暂缓，渲染仍采用 Skia。

文字输入后按 Esc 提交并结束编辑，Ctrl+Esc 取消本次编辑。文字面板的 × 可关闭，拖动标签可浮动，详情见 [窗口菜单手册](WINDOW-MENU.md)。
