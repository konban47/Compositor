# Windows 1.5.12.0 Preview

2026-10-29。本次交付文件工作流和 Web 导出的高级功能，并修正 Prism Fringe。界面沿用项目主题、字体和按钮；布局与分组参考用户截图。全部截图的高级功能尚未完成，具体边界见 [文件工作流](FILE-WORKFLOWS.md)。

- Web 导出：原稿／优化／双联／四联预览，PNG-24、PNG-8、JPEG、GIF、WBMP，颜色量化、仿色、透明度、可编辑调色板、锁定颜色、目标大小优化、五种重采样、ICC 和元数据选项。预览取消、快速切换和窄窗口有交互检查。
- 批处理与图像处理器：文件／文件夹／已打开文档、递归扫描、内置图像调整、尺寸限制、多格式输出、六段命名、错误日志、可取消执行、JSON 配方和 Windows 快捷批处理。
- 联系表 II：单位和分辨率换算、横／纵向布局、自动间距、旋转最佳位置、文件名题注、拼合或保留图层、参数载入／保存。另有图像统计、平移对齐、载入图层、静态多页 PDF、图层导出和图层复合导出。
- 文件菜单：存储副本、关闭全部／其他、恢复磁盘项目（可撤销）、文件简介、打开为智能对象／嵌入置入、限制图像和条件模式更改接通已有文档与撤销流程。
- 文档元数据：标题、作者、说明、版权、联系信息、关键词和相机信息随项目保存；导出按五种保留策略过滤。PNG、JPEG、TIFF 和 GIF 支持 XMP；并未实现全部历史 EXIF/IPTC 字段。
- 项目格式按使用功能选择版本：Prism Fringe 非默认值需要 v30，非空文档元数据需要 v31；旧项目仍按已支持字段读取。
