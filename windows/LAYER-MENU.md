# 图层菜单与钢笔操作

适用于 Windows **1.5.2.1 Preview**。参考图片展示的是“图层”菜单；本版按该结构整理，原“图像”菜单继续保留。

## 菜单接入

| 分组 | 实际功能 |
| --- | --- |
| 新建／复制／删除 | 命名图层与组、白底背景层、组／图层转画板或画框、通过拷贝或剪切建立图层、复制命名、删除选中／隐藏层 |
| 导出和样式 | 图层 PNG／导出为、复制 CSS／SVG、既有样式窗口、复制／粘贴／清除、全局光、效果显隐及缩放 |
| 填充与调整图层 | 纯色／渐变／图案通过可编辑图层样式实现；补充亮度对比度、自然饱和度、照片滤镜、通道混合器、颜色查找、色调分离、阈值、可选颜色等可编辑调整图层 |
| 图层／矢量蒙版 | 显示／隐藏全部或选区、从透明区域创建、当前路径、应用／删除、启停、链接；复用密度／羽化与历史 |
| 智能对象 | 转换、独立拷贝、编辑／替换／导出内嵌内容、复位变换、转换为图层、栅格化 |
| 栅格化 | 文字、形状、智能对象、矢量蒙版、样式；按当前可编辑内容启用 |
| 排列与组织 | 编组／取消编组、显隐、置顶／上移／下移／置底／反向、链接、锁定、合并可见及拼合 |
| 合并形状 | 统一、减去顶层、相交、排除重叠；产生仍可编辑的路径形状，沿用顶层颜色与外观参数 |
| 对齐／分布／切片 | 接入已有对齐与分布算法、按所选图层边界新建切片 |
| 修边 | 去边与颜色净化用邻近不透明像素延展颜色，保留 Alpha；移除黑／白杂边使用反解底色公式 |

显示范围与限制：

- 单层目前只有一个蒙版槽，不能同时独立保存像素蒙版和矢量蒙版；已有蒙版时不再启用新建入口。
- 填充层采用普通像素底层加颜色／渐变／图案样式，不是 Adobe 原生填充层对象。打开“图层内容选项”继续编辑。
- 新增八类调整层写入 Windows v19，参数及 LUT 随项目保存；重新打开编辑保留原参数。对已有色阶／曲线等调整类型仍使用原格式。
- 智能对象是本应用内嵌源，转换为图层产生有边界的画框组，保留源画布裁切、背景、整体不透明度、蒙版和原图层 ID，子图层可编辑。复杂变换仍遵循现有变换算法。
- 带蒙版、样式、高级混合、剪贴关系，或不在同一父组的形状不启用布尔合并；直线不是闭合面积形状。空交集不会删除原层。
- “颜色净化”与“去边”共用颜色延展算法，只是初始半径不同，不等同于 Adobe 选择并遮住的颜色净化。没有不透明邻域时不能恢复未知前景颜色。
- 智能滤镜、外部链接智能对象、统计堆栈、视频／3D、把每个样式效果独立拆层均未实现并有禁用说明。清晰度／去朦胧可通过已有 Camera Raw 设置，未新增同名调整图层算子。
- 对没有可栅格化内容的普通像素层，栅格化不产生新历史；调整图层不会被误当成独立像素图像烘焙。

## 快捷键和钢笔

Ctrl+J 为通过拷贝的图层：存在像素选区时复制选区内容，没有选区时复制图层。Ctrl+Shift+J 保留本应用已有“复制图层”映射；“通过剪切的图层”可在快捷键窗口另行指定，避免覆盖用户配置。

Ctrl+]／Ctrl+[ 前移／后移一层；Ctrl+Shift+]／Ctrl+Shift+[ 置顶／置底。多选排列保持相对顺序并在各自父组内处理，锁定保护不变。其他既有快捷键见 [图层样式手册](LAYER-STYLES.md)。

钢笔、自由钢笔、增删锚点及转换锚点工具显示钢笔形光标。拖出曲线控制柄时绘制锚点至控制柄的辅助线；移动指针只刷新覆盖层。颜色／线宽与首选项中的路径及控制线共用设置，钢笔光标可独立关闭。
