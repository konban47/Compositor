## 上游 1.4.9 对应关系

- Camera Raw：接入 CRT3 的 763 张 17³ 测量表、校准原色、颜色混合器、参数曲线、颜色分级和暗角更新；普通颜色链预合成为 33³ LUT。与上游六个颜色测量样例、两个暗角样例做数值回归。平台渲染、CPU 实现和近似滤镜的差异仍见 README。
- 原表使用 XZ；Windows 构建嵌入同一量化数据的 DEFLATE 表，不增加运行时 XZ 依赖。重建脚本 `windows/scripts/convert-camera-raw-tables.py` 可重复执行。原表 SHA-256 为 `e67ff4dbcce35cb7765752acff4405be5c934d913ef1396b2ca3fc6dc8a85190`，Windows 表为 `bc1f99628beadb07f50ddee1fc50de719b97c6e417e47d30b079532395e81034`。
- 图层样式：调整、滤镜与像素编辑保留样式；图像重采样按几何平均倍数缩放描边、阴影距离／模糊和发光范围。裁剪、画布大小、仅分辨率变更保留可编辑文字和形状；实际图像重采样会将文字／形状栅格化。
- WebP：沿用 Windows 已有解码支持，无需重复实现。
- 标签页：唯一空白起始页不显示关闭按钮；未保存项目采用可用的最小“未标题 N”编号。
- 更新通知：紧凑窗口显示 Windows 发行说明和发行页链接，不使用 macOS DMG 更新地址。

- Release 构建，警告视为错误；**975 项核心测试**。
- 11 组英文、5 组中文 UI 回归，包含真实路由的鼠标／键盘操作与截图：F／Shift+F／Esc、七种形状、节点拖动、旋转视图后对象移动与鼠标锚点缩放、快速蒙版撤销、工具栏跨列表拖拽、历史画笔源、模拟生成结果导入及 DPAPI 存储。

- 生成服务为可配置、同步 Images 协议；不内置密钥、免费额度或指定模型，不声称支持全部服务商，也不包含生成式填充。截图中的工具工作流已实现，仍不等于 Photoshop 全部功能。
- 项目格式沿用 v1–v14，新形状复用 v14 路径字段；工具栏与生成设置独立保存。旧版和 macOS 原版兼容范围见 [项目格式](../docs/project-format.md)。
