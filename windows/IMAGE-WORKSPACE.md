# 图像菜单与属性面板（1.4.10.0）

适用于 Windows **1.4.10.0 Preview**。菜单名称使用 Photoshop 常见中文术语；算法、色彩管理和排版能力的区别列在文末。

## 菜单与弹窗

“工具”分成移动／视图、选区、裁剪／切片／图框、取样／标注、绘画、修饰、橡皮擦、路径／形状、文字九类。69 个工具、快捷键及工具栏预设继续可用；通用参数归入“工具选项”。新“插件”菜单见[插件接口](PLUGINS.md)。

文字按钮根据内容换行和自动增高，固定按钮行会扩展，避免中文内容被裁切。表单内容可滚动，确定和取消保持独立区域。属性数字按 Enter 或离开输入框应用；图标按钮提供中文悬停说明。

## 图像模式与精度

| 命令 | 行为 |
| --- | --- |
| 位图 | 合并可见结果为黑白；可选择误差扩散仿色。工作层仍有 8 位容器，导出为 1 位图像。 |
| 灰度 | 用亮度变换现有图层；8／16／32 位可选。 |
| 双色调 | 合并并使用可配置的单色油墨进行灰阶着色。它是单墨近似，不是 Photoshop 的多版双色调印刷引擎。 |
| 索引颜色 | 合并到 2–256 色调色板，可仿色；“颜色表”编辑十六进制颜色，载入／保存 ACT 或文本。 |
| RGB 颜色 | sRGB 工作颜色。 |
| CMYK 颜色／Lab 颜色 | 保留工作像素，标记输出模式；TIFF 转为真正的 CMYK／Lab 通道。画布及编辑仍以 sRGB 工作。 |
| 多通道 | 合并图像并分离 RGB 为三个命名 Alpha 通道，供通道运算；不支持专色印刷版输出。 |
| 8／16／32 位／通道 | 转换当前图层精度；16 位有 65,536 级整数精度，32 位存储浮点值。将 8 位升级不能还原已丢失的信息。 |

PNG 导出最高 16 位，TIFF 支持 8／16／32 位浮点及 CMYK／Lab；JPEG/PDF 为显示结果。32 位 `.comp` 保存完整浮点资源，不只保存显示 PNG。16 位 PNG、TIFF、HEIF（含 `.hif`）及 RAW 输入保留解码精度，具体位深以源文件为准。RAW 通过 LibRaw 16 位解码后进入曝光、色温、色调、高光恢复、降噪及径向镜头校正面板。

普通像素、原生混合、蒙版及常用调整层有浮点合成路径。包含组、图层样式、剪贴蒙版、高级混合或不受浮点路径支持的调整时，合成导出回退为 8 位效果；“导出为”明确提示，项目仍保留原始深度资源。传统笔刷在笔触处使用 8 位计算，未改变的深度样本保留；液化、涂抹、模糊、图像缩放以及色阶／曲线／曝光等已有深度路径。32 位显示预览会裁切到显示范围，PNG 转为 16 位；深度合成及导出受单表面和资源预算限制。8 位 RGB 超大画布仍可使用分块 PNG。

## 调整与几何

“调整”包含亮度／对比度、色阶、曲线、曝光度、自然饱和度、色相／饱和度、色彩平衡、黑白、照片滤镜、通道混合器、颜色查找、反相、色调分离、阈值、渐变映射、可选颜色、阴影／高光、HDR 色调、去色、匹配颜色、替换颜色、色调均化。颜色查找读取 2–65 点的 `.cube` 3D LUT；匹配颜色可选已打开文档。可选颜色的九个色彩范围分别保留 CMYK 增减参数。

调整作用于当前未锁定的像素层，并尊重像素选区、编辑通道和透明像素锁。对话框支持预览；取消恢复原图。自动色调、自动对比度、自动颜色沿用现有自动分析实现。Ctrl+B 色彩平衡、Ctrl+Alt+Shift+B 黑白、Ctrl+Shift+U 去色、Ctrl+Shift+L 自动色调、Ctrl+Alt+Shift+L 自动对比度、Ctrl+Shift+B 自动颜色；可在快捷键窗口修改。

- 图像大小：重采样所有图层和蒙版，更新通道、参考线及标注；分辨率单独修改不会重采样。
- 画布大小：选择锚点、尺寸及背景；属性中的纵横方向按钮交换画布宽高。
- 图像旋转：180°、顺时针／逆时针 90°、任意角度、水平／垂直翻转。任意角度扩展画布并转换图层、独立蒙版、通道、选区和标注；非直角旋转清除无法表示的斜向参考线。
- 裁剪：按选区边界裁剪；裁切：去除透明或指定角点颜色的边；显示全部：扩展画布以容纳画布外图层。
- 复制：新建独立文档，可选择合并可见图层。
- 生成式放大：使用已配置图像服务的 `/images/edits` 接口发送当前合成 PNG 和提示，预览后导入新文档。服务必须支持编辑接口，不保证其输出倍数。需要用户自己的地址和密钥，不自动调用付费服务。
- 陷印：按可配置像素半径对较深邻域颜色扩展，尊重选区；不是 ICC 分色与印前陷印系统。

## 应用图像、计算、变量与分析

“应用图像”选择已打开文档、图层／合并图层、RGB／红绿蓝／Alpha／灰度／已存 Alpha 通道，并可反相。支持 15 种混合、透明度、加减的缩放／偏移、保留透明区域及可选源蒙版。源图像和蒙版必须与目标文档像素尺寸相同。

“计算”组合两个源，结果可成为新 Alpha 通道、选区或新文档。Alpha 及选区为 8 位覆盖率；新文档结果为灰度。现有 Alpha 通道可以继续作为下一次计算输入。

“变量 → 定义”将变量绑定图层可见性、文字替换或像素替换。“数据组”读取 CSV／TSV（首列 `name`，其余列为变量名称；支持引号、逗号和多行内容），最多 1,000 组。可见性接受 true/false、1/0、是/否；文字变量需要文字图层。图片相对路径以 CSV 文件夹解析。应用数据组为一个可撤销操作；任何变量失败都保留原文档。

“分析”可设置测量比例、选择数据点、记录测量、查看／清除测量记录并导出 CSV，也可切换标尺／计数工具或置入比例标记。记录选区面积、周长、宽高、标尺长度／角度、计数及平均亮度。未建立选区时测量画布；平均亮度基于显示合成（0–255），周长为像素边界估计。数据和比例随项目保存。

## 属性排版

属性按文档、像素层、文字层或蒙版切换。取消图层选择可看文档属性。右侧分隔条可拖动调整属性与图层面板的高度，面板内容可滚动。

- 文档：画布宽高、比例链接、方向、分辨率、模式／位深、填色，标尺／网格／透明网格，标尺单位、参考线显示／锁定／吸附及线型，尺寸／裁剪／裁切／旋转快捷操作。
- 像素层：W/H 与 X/Y 双列、比例锁、角度及翻转按钮；对齐／分布图标矩阵、间距与对齐目标；移除背景、选择主体及蒙版操作。
- 文字层：字体／样式、字号／行距／字距、字符水平／垂直缩放、基线偏移、颜色、语言和抗锯齿；大小写／上下标／装饰／OpenType 特性；段落对齐、两端对齐、缩进与段前段后；动态文字、项目符号／编号、东亚禁则／挤压、中东阅读方向及复杂塑形。
- 各节标题箭头折叠整个分栏；三点按钮折叠或展开高级字段。比例、字号与分栏留白按参考图缩放到本应用的侧栏宽度。

两端对齐与东亚排版是本地实现，OpenType 特性须字体支持。不具备 Adobe 段落书写器、完整日文组版、阿拉伯语 Kashida／变音符高级定位及原生 ICC 印刷校样。此版本的对应功能可用，但不宣称与 Photoshop 所有商业算法及控件逐项等价。

保存新元数据时采用 [Windows 格式 v18](../docs/project-format.md#windows-extension-version-18)。旧 Windows 版本不能读取 v18，交付旧版可导出图像并保留源项目。
