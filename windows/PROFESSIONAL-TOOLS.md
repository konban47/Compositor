# 选区、修饰与辅助工具

适用于 Windows **1.4.9.4 Preview**。本版新增 19 个工具，工具总数为 69。所有工具都有中文名称、快捷键提示，并接入工具菜单和自定义工具栏。旧工具栏预设中的新增项会出现在“附加工具”；在“自定义工具栏”点“恢复默认值”可恢复新版分组。组按钮长按或右键展开，同组按键循环选择。

## 光标、取样与网格

- 仿制图章和修复画笔：按住 **Alt** 出现取样靶心，Alt 单击设置源点；源点以黑白十字显示，状态栏显示坐标。松开 Alt 后显示作用直径圆圈；对齐模式在后续笔触中保持源与目标的偏移，非对齐模式每次从同一源点开始。切换文档清除取样源。
- 画笔、仿制／图案图章、模糊、锐化、涂抹、液化、修复、移除、橡皮擦、历史画笔、减淡／加深／海绵等使用圆形光标，直径为“工具大小 × 视图缩放”；缩放、旋转视图和 Windows 显示缩放使用同一坐标系统。选区画笔和快速选择也显示其画笔大小。
- 横排／直排文字及文字蒙版使用 I 形光标。按空格或使用抓手时切换为平移光标。
- 快捷键窗口的名称允许换行，按键列保留完整宽度，底部按钮留出中文行高；窗口可调整大小。
- “视图 → 显示网格”的布局网格铺满整个编辑工作区，包含画布外右侧、底部和旋转后的四角。缩得很小时均匀稀疏显示，避免密集亚像素线条；网格不导出。
- 像素网格在 800% 起显示，也使用完整视口范围，避免形成右侧／底部仅剩单方向网格的缺口。

## 选区与裁剪

| 工具组 | 操作与选项 |
| --- | --- |
| 选区画笔、套索、多边形套索、磁性套索 **L** | 选区画笔涂出覆盖率选区，可设置大小、不透明度及新建／添加／减去／交叉。Shift 临时添加、Alt 减去、Shift+Alt 交叉。磁性套索单击起点后沿边缘移动，自动吸附高对比边缘；可设置宽度、对比度和锚点频率，Alt 暂停吸附，Backspace 删除锚点，Enter／双击／单击起点闭合，Esc 放弃。 |
| 对象选择、快速选择、魔棒 **W** | 对象选择沿用本地 ONNX 主体分割。快速选择涂过区域，以连续颜色和边缘扩大选区，支持容差、当前／所有图层取样以及增减交叉。魔棒保留容差、取样半径、连续性和图层取样选项。 |
| 裁剪、透视裁剪、切片、切片选择 **C** | 普通裁剪保留比例与居中等原有选项。透视裁剪先拖出四边形，再拖动四角；宽高为 0 时按四边长度自动计算，也可指定输出像素尺寸。Enter 校正并裁剪，Esc 取消；角点交叉或超出尺寸／内存限制时不执行。 |
| 图框 **K** | 拖出矩形或椭圆图框；已有选中图层可装入图框，图框使用可编辑组和矢量蒙版。选中图框后拖入图片，或“置入图像到图框”，图像按覆盖图框的比例居中填充，保留图框裁切和置入确认／取消。 |

透视裁剪保留图层层级、混合、样式、蒙版与 Alpha 通道，重采样各层像素；文字、形状、智能对象与矢量蒙版在此操作中栅格化，可撤销。裁剪后清除轴向参考线、清除选区；文档标注随坐标变换。**K 本版分配给图框**；模糊／锐化／涂抹／液化组默认不设按键，可在快捷键窗口配置。

## 切片、测量与标注

| 工具 | 操作与选项 |
| --- | --- |
| 切片／切片选择 | 拖出切片；选择工具拖动位置，拖右下角改变大小，双击编辑名称、位置、尺寸、URL、颜色与可见性。可按参考线生成切片，或用“列数,行数”划分为等大切片（每轴最多 100）。导出将每个切片与画布的交集写成 PNG，并附 JSON 位置／URL 清单；URL 仅作为数据保存，不自动访问。不覆盖已有同名文件。 |
| 颜色取样器 **I** | 单击添加、拖动移动，最多 10 个取样点；选项栏显示位置及 RGB／十六进制颜色，支持当前／所有图层取样。Alt 单击或 Delete 删除选中点。 |
| 标尺 **I** | 拖动测量线，选项栏显示像素距离和角度。“拉直图层”将选中图层减去测量角度；编辑标注可精确输入起点与终点差值。 |
| 注释 **I** | 单击创建，输入文字；双击编辑文字、名称、位置、颜色和可见性，拖动移动。 |
| 计数 **I** | 单击增加编号，Shift 拖动已有点，Alt 单击删除。输入计数组名创建／选择分组，可独立切换组可见性，清除仅删除当前计数组；组名和标记颜色可编辑。 |

所有标注支持选中后 Delete、选项栏编辑／删除／清除，支持撤销和项目保存。切片以外的标注也不会进入 PNG/JPEG/PDF 合成导出。完整文档复制／历史新建文档保留标注，复制图层不携带文档标注。切片导出不生成网页布局或 Photoshop HTML 模板。

## 修饰与绘画

| 工具组 | 操作与选项 |
| --- | --- |
| 污点修复、移除、修复画笔、修补、内容感知移动、红眼 **J** | 污点修复保留内容识别／创建纹理／近似匹配。移除工具涂画待删除区域，松开时从邻域内容填充。修复画笔先 Alt 取样，复制纹理并校正到目标局部颜色，支持对齐与图层取样。修补先圈出区域，再从选区内拖向干净源区域；“目标”模式将源内容修补到拖动位置。内容感知移动圈选后拖动，填充原位置；“扩展”保留原对象。红眼工具单击或框住瞳孔，调整瞳孔大小与变暗量。 |
| 画笔、铅笔、颜色替换、混合器画笔 **B** | 铅笔固定硬边、不做笔触平滑。颜色替换按笔触起点颜色和容差限制替换，可选颜色、色相、饱和度、明度模式。混合器把载入的前景色与画布采样混合，提供潮湿、载入、混合、流量；可载入／清洁画笔，或每次描边后清洁。 |

像素改动受当前选区及图层锁定限制；智能对象需先栅格化。笔触在松开鼠标时提交为一次历史操作。颜色替换与混合器是本项目的 CPU 算法，修复画笔使用局部颜色校正，移除／内容感知移动采用本地 PatchMatch 填充；它们不是 Adobe 的商业算法或 Firefly 服务，不承诺复杂纹理、毛发及透明边缘的输出与 Photoshop 完全相同。透明笔尖、全部采样／限界模式和 Adobe 笔刷预设库不在本次实现范围。

## 上游按钮与图标

`UpstreamArtwork.cs` 直接移植上游 MIT 源码中的仿制图章、渐变、多边形套索、对象选择四个自绘图标：坐标、填充、笔画和 Floyd–Steinberg 渐变算法保留。工具按钮复用上游的 36×36、7 点圆角、56 点栏宽、10 点间距、白色 12% 填充／14% 边框选中态；全局按钮使用同一圆角与单色视觉样式。

上游其余图标调用 Apple **SF Symbols**，按钮控件由 **SwiftUI/AppKit** 提供，仓库没有可以直接加载到 Windows 的相应图标文件或控件。Windows 使用矢量对应图形；本版新增而上游没有的图标按同一单色、圆端点风格绘制。没有把自行绘制的图标标成上游原始资源。具体来源和 SHA-256 清单见 [上游 UI 来源](UPSTREAM-UI.json)，CI 校验其与保留的 Swift 源码一致。

操作语义参考 Adobe 官方的[套索工具](https://helpx.adobe.com/photoshop/using/selecting-lasso-tools.html)、[磁性套索工具](https://helpx.adobe.com/photoshop/using/tool-techniques/magnetic-lasso-tool.html)和[绘画工具概览](https://helpx.adobe.com/photoshop/desktop/apply-painting-techniques/fill-objects-selections-layers/painting-tools-overview.html)。本项目为独立实现。

新增标注使用 **Windows 项目格式 v17**；无标注时继续按所用特性选择 v11–v16。标注字段、边界与兼容性见[项目格式](../docs/project-format.md#windows-extension-version-17)。
