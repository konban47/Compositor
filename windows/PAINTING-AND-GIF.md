# 画笔、图章、橡皮擦与 GIF

**1.5.12.1 Preview** · 2026-10-23

## 笔尖与设置

工具选项栏左侧的笔尖按钮打开大小／硬度、搜索、分类和缩览图大小。画笔设置按钮或“窗口 → 画笔设置”显示笔尖形状、形状动态、散布、纹理、双重画笔、颜色动态、传递、画笔笔势、杂色、湿边、建立、平滑和保护纹理。分类始终显示在左侧，右侧独立滚动参数；底部笔触预览与“+”预设按钮保持可见。窄面板为最小值和渐隐步数换行，并为滚动条预留空间。

每类勾选框决定效果是否启用，点击分类名会启用并打开该类；锁定按钮决定切换预设时是否保留该类参数。“传递”按不透明度、流量、湿度和混合抖动分成四组，数字输入与滑块双向同步；控制为“关”时最小值禁用，选择“渐隐”启用步数。湿度／混合组仅对混合器画笔启用。笔尖方向图拖动改角度，Shift 拖动改圆度。参数改变后，底部用实际绘制引擎生成笔触预览。24 个程序笔尖为本项目原创；载入自定义纹理支持常规图像，最大 2048×2048、文件 4 MB。

“+”保存命名预设，可选择捕获大小、包含工具设置和包含颜色。未捕获大小／颜色时，应用预设保留当前值；不包含工具设置时保留当前工具及其流量等工具栏参数。预设管理器可重命名、删除、导入／导出 Compositor JSON。暂不读取 Adobe ABR/PAT 文件。

| 橡皮擦 | 画笔／铅笔／块模式，流量、不透明度、压力、平滑、角度与对称；“抹到历史记录”改为恢复选定历史来源。 |

| 魔术橡皮擦 | 点击按容差 0–255 选择区域；消除锯齿、连续、所有层取样和不透明度分别影响匹配与擦除。 |

对称菜单有垂直、水平、双轴、对角、波纹、圆形、螺旋线、平行线、径向和曼陀罗；还可使用工作路径、变换对称或隐藏引导线。径向／曼陀罗支持 2–12 段。只在画笔、铅笔和橡皮擦中启用，以免影响其他工具的取样坐标。

压力、倾斜和旋转依赖硬件输入；鼠标使用固定压力。当前 Avalonia 输入不提供可用光笔轮轴时，轮轴按 1 处理。笔画松开后一次性提交，可撤销；移动期间显示路径预览。超长笔画、大直径或高散布若超预算会拒绝并保留原像素。

## GIF

导入 GIF 后仍是单个图层。“窗口 → 时间轴”选择帧，随后绘制即编辑该帧；复制、删除、移动帧或更改延迟可撤销。可选择“帧延迟”或“所有帧相同”，范围 0.02–655.35 秒。播放从各动画当前选中帧开始，按保存的逐帧或统一时长推进；单调时钟跳过因解码耗时错过的帧，不累计额外延迟。播放和导出期间为同一来源复用解码器及一个工作帧缓冲，停止后释放，返回的帧图像互不覆盖。快速停止／重播会丢弃旧请求的结果。播放使用独立画布预览，不更改当前编辑帧、脏标记或历史记录；切换工具、开始编辑或停止播放回到编辑图像。

`.comp` 保存原始 GIF、已编辑帧 PNG、顺序、删除记录、时长和图像大小变换。读取上游 v17 GIF，Windows 动画项目保存为 v27。最多 4096 帧，稳定身份上限 8192；像素／源数据及导出同时受到进程预算约束。

“文件 → 导出为 → 更多 → GIF”或时间轴“导出 GIF”合成可见图层。多条动画合并时间点，较短图层保持末帧；透明背景可选。GIF 采用调色板和百分之一秒计时，不承诺高位深或完全无损颜色。常规图层可创建文档视频时间轴或帧动画，参见 [时间轴与预设](TIMELINE-AND-PRESETS.md)。未创建文档时间轴的 GIF 文档自动展开帧编辑器；两种时间轴入口共用图层与撤销系统。

本版同步 [上游 v1.5.6 后续 GIF 修复](https://github.com/robbietilton/Compositor/commit/64097c9379ea8128d65d13e817549e6bad3d603c)。算法与 UI 针对 Windows 实现；未宣称 Photoshop 专有笔刷逐像素等同。

动画图层支持图像大小和非破坏性图层变换。会单独改变帧像素网格的破坏性变换（如透视裁剪）目前明确拒绝并回滚，避免生成无法重新打开的动画项目。
