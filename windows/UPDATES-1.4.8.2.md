2026-10-10。基于上一版 1.4.8.1，保留已同步的上游 `75147a27d90c681215151a6301373dd2b07b7aa2`。本次为 Windows 编辑工作流改进，没有修改原 macOS 源码。

## 属性与蒙版

- 变换：W/H/X/Y、约束比例、旋转、重置旋转、翻转。对齐：左右／上下／中心，三层以上可等距分布中心。
- 文字：字体、点字号、像素行距和字距、颜色、仿粗／仿斜、下划线／删除线、三种段落对齐、编辑文本、项目符号／编号、大小写。形状：填充色、圆角或线宽。调整层调用原有参数面板。
- 蒙版：密度、羽化、反相、启用／停用、链接、载入选区、选区替换、应用、删除。选择并遮住提供预览／取消、移动边缘和平滑；色彩范围确认直接生成蒙版。可从选区创建矢量蒙版并保留路径元数据。
- 修复蒙版状态原先被历史记录共享造成无法撤销的问题；修正灰度蒙版缩略图误按 Alpha 绘制成全白。渲染使用蒙版独立位置／旋转，并覆盖组蒙版、图层效果和分块导出。
- 通过 Enter 或离开数值输入框提交。滑块在松开后提交。锁定功能继续生效。

## 历史与兼容性

- 最多 100 个撤销／重做状态、20 个快照，共享 256 MiB 保留像素预算；超限释放旧状态，随后释放旧快照。大型快照（超过 8 MP）使用图标，避免同步生成缩略图阻塞编辑。
- 历史与快照只存在于当前会话；保存项目不会保存历史。新文档复制像素，关闭原文档不会使副本文档失效。
- `.comp` 读取 **v1–v13**。非默认蒙版密度／羽化、矢量路径及新增文字样式写 **v13**；仅有 v12 功能时仍写 v12，无扩展时写 v11。旧 Windows 版本不能读 v13，macOS 原版不能读 v12/v13。
- v13 的 PNG 图层和蒙版回退资源仍保存；不以静默丢弃元数据的方式绕过版本限制。要交给旧版可导出合成 PNG，或移除相应扩展后另存为。

## 验证

- 核心测试 **930 项**，包含新增 19 项蒙版、历史、独立复制、对齐、格式往返和参考线测试。
- Release 构建使用 `-warnaserror`。
- 英文十组窗口回归；中文窗口、导入交互、图层／通道和新增 `--inspector-checks`。实际触发菜单、鼠标拖动、数值字段、蒙版删除确认／取消／撤销、选择并遮住预览／取消、色彩范围、历史分支与快照恢复。
- CI 在 Windows Server 2022/2025 跑核心及窗口检查，Windows 2025 构建安装包／免安装包，并检查发布后 EXE 和安装／卸载。查看[对应提交的 Windows 工作流](https://github.com/konban47/Compositor/actions/workflows/windows.yml)获取实际结果。
- 自动化不能替代 Windows 10 实机、真实输入法候选框、数位板及多显示器验收，仍标记 Preview。

## 明确限制

这是本项目编辑引擎上的常用属性／历史工作流，并非 Photoshop 全功能替代。高级 OpenType、上下标／小型大写、动态文字、东亚／中东排版、文字转框架／矢量字形、历史记录画笔、非线性历史和矢量路径节点编辑尚未提供。同层仅有一张像素或矢量蒙版；画笔／反相／平滑／移动边缘等像素操作会栅格化矢量蒙版。两种蒙版均支持密度与羽化。完整范围见 [Windows README](README.md)。
