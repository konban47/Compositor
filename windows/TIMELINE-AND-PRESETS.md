# 时间轴、图层复合与预设

适用于 Windows **1.5.12.3 Preview**。

## 界面

面板按用户截图的区域、控件顺序和菜单分组组织，颜色、字形、字体大小及按钮使用本项目主题。字符和段落是紧凑双列属性面板；注释显示正文及上一条／下一条／删除；图层复合显示列表及底部操作；时间轴默认浮动，可通过现有停靠操作重新排列。浮窗紧凑标题栏按钮保持原样。预设管理器是独立可调整窗口，提供最小化、最大化和关闭；关闭悬停为红色。

## 图层复合

“窗口 → 图层复合”创建、复制、删除、应用、更新及切换复合。每个复合分别记录可见性、位置、外观，也可单独更新其中一组。外观包括不透明度、填充、混合模式、图层效果和高级混合。列表保存到 `.comp`，操作进入撤销历史。恢复最后文档状态返回本次应用复合前的属性。

复合不复制像素、图层顺序或素材，不复活已经删除的图层；新增图层不因应用旧复合被删除。锁定图层和位置锁受保护。当前不导入／导出 Photoshop layer comps，也不控制嵌套智能对象内部的复合选择。

## 时间轴

“窗口 → 时间轴”选择创建视频时间轴或帧动画。视频时间轴为现有图层建立 5 秒片段，支持播放、逐帧定位、拖动／裁切、播放头拆分、工作区域、帧速率、缩略图大小、时间码／帧号、缩放、循环、允许跳帧及备注导出。选中片段与图层选区相联；双击片段编辑时长、速度、淡入淡出及收藏。关键帧记录位置、尺寸、旋转和不透明度，支持线性／保持插值。

帧动画保存各帧的图层属性与延迟，可新增、复制、删除、设置统一延迟以及转换为视频片段。视频转帧按帧速率采样，最多 4096 帧；视频、GIF 像素仍取自原媒体时钟，不会将外部视频逐帧打包为新图像资源。图层复合和时间轴随项目保存，预览不修改素材和历史；开始编辑、切换工具、关闭时间轴即停止预览。洋葱皮仅叠加上一帧，不进入视频输出。

GIF 文件仍作为单个可编辑动画图层。未创建文档时间轴时，时间轴自动展开原有 GIF 帧编辑器；已有复制、删除、重排、计时、画笔编辑和 GIF 导出保留。

视频导入、H.264 MP4 输出使用 PATH 中的 `ffmpeg` 与 `ffprobe`；音频播放还需要 `ffplay`。这些可选程序不随本发行包提供。视频与音频保持本机文件链接，移动素材后使用“重新链接媒体”。视频解码在后台进行，25%／50%／100% 控制预览输出及视频解码尺寸；实际速度取决于媒体、滤镜和 CPU，不保证实时音画同步。音轨可设置起点、源偏移、时长、音量和静音；输出进行 AAC 混音。

“渲染视频”按截图分为位置、格式、大小／帧速率、范围及渲染选项。当前编码器是 FFmpeg，提供逐行 H.264、方形像素、8 位 RGB 转 YUV、无 alpha；透明像素铺黑，奇数尺寸向上补为偶数。支持所有帧、工作区域、指定起止帧、包含音频、文档颜色解释和输出品质。先写临时文件，成功后替换目标；取消保留已有目标文件。未接入 Adobe Media Encoder、3D 轨道或全局灯光动画。

## 指定配置文件

“编辑 → 指定配置文件”提供不应用颜色管理、使用工作空间、指定 ICC 三种选择及预览。配置文件必须匹配 RGB／CMYK／灰度模式。预览开关即时恢复，取消不产生编辑，确定可撤销。

文档保留原素材，以固定的 `profileEncoding` 记录当前通道解释基准，再应用选定 ICC；反复指定不会累计改写素材。由于本项目内部合成为 sRGB，此解释发生在合成输出，不能视为 Photoshop 的原生设备通道混合；复杂混合和赋值后绘画可能与 Adobe 不同。输出标签、CMYK 校样与颜色设置共用 ICC 资料。详见 [颜色管理](COLOR-MANAGEMENT.md)。

## 预设管理器

“编辑 → 预设管理器”默认显示 12 个等高线，支持画笔、图案、形状和等高线分类。Ctrl／Shift 多选、重命名、删除、载入、替换、复位、存储选中项，以及仅文本、小／大缩览图、小／大列表均有效。按钮按选区启用；“完成”关闭窗口，修改即时保存。

管理器、工具栏选择器及图层样式的等高线选择器共享资料。画笔和图案默认资源会对旧设置迁移一次；主动删除后不会在重开时回填。等高线以 2–256 个 0–1 有限样本存储，应用图层样式后将样本复制到文档，删除库预设不破坏已有图层。导入／导出使用 Compositor JSON，不读取 Adobe ABR、PAT、CSH 或 SHC 格式。
