# Windows 1.5.6.0 Preview

2026-10-23。上游同步至 `47cb96b83f73dbb8deda4c417e702c83b7107cab`（v1.5.6）。[GitHub Release：windows-v1.5.6.0](https://github.com/konban47/Compositor/releases/tag/windows-v1.5.6.0) 提供 x64 安装版、免安装版和 SHA256SUMS.txt；沿用 Preview 预发布标记。包内手册与发行标签源码一致。

沿用 Skia、32 DIP 标题栏、同一实际快捷键归组、左侧工具栏取消滚动和既有 imagegen 图标。新增工具图标和笔尖由现有矢量／程序绘制实现，没有复制 Adobe 预设资产。

## 画笔与工具选项

用户第一组图 1–32：13 类画笔设置、大小／硬度／间距／角度／圆度、24 个笔尖、形状／散布／纹理／双重／颜色／传递／笔势控制、预设锁定与实际引擎笔触预览。画笔、铅笔、颜色替换和混合器接入流量、压力、混合模式、取样、平滑及对称；混合器有湿度、载入、混合、流量和载入／清理状态。

第二组图 1–31：仿制／图案图章、历史／艺术历史画笔、橡皮擦、背景和魔术橡皮擦的独立选项。图案预设支持树、草、水滴等原创默认分类、显示模式、搜索、新建、重命名、删除、追加、导入和导出。保留已有五个仿制源、跨文档取样、变换和图层范围。艺术画笔有十种样式；抹到历史记录可恢复透明像素；背景橡皮擦支持三种取样、连通限制、容差压力和保护前景色。魔术橡皮擦按图 31 实现。

这些控件修改实际像素与撤销状态。算法为本项目的确定性 CPU 实现，未宣称与 Photoshop 的专有笔刷或艺术笔触逐像素相同。鼠标压力为 1；数位板数据由 Avalonia 提供，真实设备验证待执行。当前绘制在松开指针后提交像素，移动期间显示路径预览；超出交互工作量或内存预算时拒绝提交。

## 上游 1.5.6

| 上游更新 | Windows 对应实现 |
| --- | --- |
| GIF 图层 | 一个图层保留原始 GIF，按需解码帧；画笔和像素编辑写入当前帧，支持撤销。 |
| GIF 时间轴 | 帧导航、复制、删除、前后移动、逐帧／统一延迟、循环播放与停止；播放使用独立预览文档。保留普通图层 5 fps 预览。 |
| GIF 项目／导出 | 读取上游 v17，Windows 动画文档写 v27；保存源、帧编辑、顺序、几何和延迟。导出可见图层合成动画，短轨道保持末帧，延迟遵循 GIF 最小间隔。 |
| 自动工具栏 | 停靠工具栏高度不足时自动双列；恢复高度后回到单列，用户显式双列保持。 |

图像大小将 GIF 几何作用于未编辑帧，并重采样已编辑帧。GIF 输出为调色板图像，不能保存 HDR 高位深。原始数据、帧资源和导出工作量遵循设备预算；大动画可能需要降低尺寸或帧数。

macOS Swift/AppKit/Metal/Sparkle 原文件随上游合并保留。本机没有 macOS/Xcode，未执行其测试；Windows 10 实机、真实数位板及低端硬件验证不由 Windows 11 或 Server CI 替代。详见 [兼容性方案](COMPATIBILITY.md)。
