# Windows 1.6.3.0 Preview

2026-11-04。本版把上游 main `7f703b4`（1.6.3）合并进仓库并移植适用于 Windows 的改动，按 Windows 11 重做窗口标题栏，并把 `windows/` 下的手册归拢到本目录。版本号与上游 1.6.3 对齐。

## 合并上游

- `windows-port` 现已包含上游全部提交（此前显示落后 67 个）。其中 30 个已在 1.5.12–1.5.14 用重写方式移植到 Windows，这次补上 Git 历史；另 37 个是新提交。
- 合并只更新 macOS 源码；Windows 代码不受合并本身影响。首页 README 保留 Windows 内容，`docs/project-format.md` 同时保留上游版本 1–21 和 Windows 扩展 12–33。完整 UI 对照基线由 `2d75d91` 更新为 `7f703b4`（`UPSTREAM-UI.json`）。

## 上游移植（1.6.0–1.6.3）

- **减少杂色（Reduce Noise，上游 `c1c5356`、`2c98c1b`、`8926ea8`）**：“滤镜 › 减少杂色…”，有强度、保留细节、颜色杂色。Camera Raw 的明度降噪同时换成非局部均值：强度随画面实测噪声而定，干净的照片几乎不变，边缘和纹理得以保留。也可作为滤镜图层（项目格式 Windows v33，或上游 v21）：它按整幅画面估计噪声，分块渲染时每块读取同一画面，结果与所用输入一起缓存，平移和分块不会重算，图层下方内容或设置变化时才重算。上游在 GPU 上计算；Windows 为 CPU 多线程，大图较慢。
- **体积光“保持主体清晰”（上游 `e584c8c`）**：默认开启；关闭后主体按自身深度起雾，远处的人物会被雾气笼罩。首次下载深度模型时，预览最多等 5 秒（上游 `851edb0`），之后先按估算显示，模型到位后重绘。
- **显示额外内容（上游 `bb5c8cc`、`9cd704d`）**：“视图 › 显示额外内容”。移动工具以外按 Ctrl+H，隐藏选区轮廓和参考线；选区仍然限制编辑，新建选区时轮廓自动恢复。移动工具里的 Ctrl+H 仍切换变换控件。
- **距离（上游 `8fb163e`）**：“视图 › 距离”，默认关闭。开启后，用移动工具拖动图层时显示到画布边缘和同排最近图层的像素间距；按住 Ctrl 悬停在其他图层上时显示与该图层的间距。
- **拖动时的尺寸标签（上游 `de6837b`）**：拖选框、形状时指针旁显示宽高，拖直线时显示长度，缩放图层时显示大小。
- **状态栏选区尺寸（上游 `63f1013`）**：画布尺寸后显示“选区 W × H px”，绘制选框时实时更新，已有选区按画布裁切；拖形状时显示“形状／直线”尺寸。
- **撤销停在文档起点（上游 `4f9ed78`）**：连续撤销不会关闭刚打开的图像或新画布。
- **图层面板底部（上游 `b611179`、`21fecb7`）**：调整图层和滤镜图层分成两个菜单，滤镜按钮是圆环内的棋盘格圆盘，菜单从图标上方打开。
- **编辑面板共用位置（上游 `a62490d`、`3717575`）**：滤镜、调整、图层样式、效果、色彩范围、仿色面板打开在上一次留下的位置；首次打开时跨在画布右边缘，避开画面中央。
- **滤镜图层面板去掉“预览”（上游 `2d44b8d`）**：图层的眼睛图标已能对比前后。
- **新版本首次启动铺满屏幕（上游 `9fa59c3`）**：每个版本首次启动铺满工作区（不是全屏）；之后按上次关闭时的大小打开。

选区描边的两处修正（上游 `6793557`、`ead9a0e`）针对 Core Graphics 留下的细碎片段；Windows 用 Skia 路径运算没有这个问题，已加测试锁定。以下不适用于 Windows：深度模型迭代（Core ML）、Vision 手指缝修正（`95d3d63`）、Metal 着色器、macOS 26 修复、服务菜单、更新弹窗、PNG 解码提速、取色时点击画布（Windows 滤镜面板为模态）。上游 Lens Effects 图层的缓存（`4445be9`）是为了让 GPU 画布与导出一致；Windows 的画布和导出走同一个渲染器。

## Windows 11 标题栏

- 内容铺到窗口顶边：此前系统在客户区上方保留一条调整大小边框，显示为按钮上方的隔层，现已消失。主窗口和全部对话框一致。
- 按钮 46×32，贴齐顶边和右边，窗口圆角裁切关闭按钮的红色；标记为 Windows 11 的 10 像素细线，圆角最大化图标，窗口失去焦点时变淡；悬停和按下为系统同款的浅色填充，关闭悬停为 `#C42B1C`。
- 各部分带系统角色：悬停最大化按钮弹出 Windows 11 贴靠布局；拖动标题栏可贴靠，双击最大化，右键打开系统菜单。使用系统自带的窗口边线和阴影。
