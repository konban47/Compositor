# Windows 1.6.6.4 Preview

2026-11-11。本版逐张核对“图像菜单截图”文件夹（87 张：6 张菜单图、81 张对话框与下拉列表截图），按截图重排“图像”菜单，重做其中的全部对话框，并补上截图中出现、此前缺少的功能。上游 main 仍为 `02e53989dc499d749d83f33023ff249de1c7b4eb`（1.6.6，2026-11-07），没有新的提交需要移植。

## 图像菜单

- **菜单结构**：模式／调整｜自动色调、自动对比度、自动颜色｜图像大小、生成式放大、画布大小、图像旋转、裁剪、裁切、显示全部｜复制、应用图像、计算｜变量、应用数据组｜陷印｜分析，顺序、分隔线和访问键与截图一致（“图像旋转”的 180 度(1)、顺时针 90 度(9)、逆时针 90 度(0)）。生成式放大新增 Alt+Shift+Ctrl+U。
- **置灰规则同 Photoshop**：没有选区时“裁剪”置灰；没有变量时“数据组”、没有数据组时“应用数据组”置灰；“陷印”只用于 CMYK 文档；“位图”“双色调”需先转为灰度；“颜色表”只用于索引颜色。
- “拆分通道”不在 Photoshop 的图像菜单中，保留在通道面板菜单。
- **分析**：设置测量比例 ▸ 默认值／自定…（以及存储的比例预设）、选择数据点 ▸ 自定…（以及存储的数据点预设）、记录测量（没有选区、标尺线或计数时置灰）、标尺工具、计数工具、置入比例标记…。

## 调整对话框

- **共用部件**：预设下拉列表（默认值｜内置预设｜本机存储的预设｜自定）和 ≡ 或 ⚙ 菜单（存储预设…、载入预设…、删除当前预设），预设以 JSON 存在设置文件夹的 Adjustment Presets 下，不读取 Photoshop 的预设文件；滑块上方是名称和数值框（百分号、度数在框内），滑块轨道显示对应颜色；右列为确定、取消、自动／选项、吸管和预览。新对话框的预览写作“预览 (Alt+P)”，旧式对话框写作“预览(P)”，均响应 Alt+P。
- **色阶**：通道（RGB Alt+2、红 Alt+3、绿 Alt+4、蓝 Alt+5）、带三角滑块的直方图和输出色阶条，九个内置预设，自动(A)、选项(T)…、黑场／灰场／白场吸管。
- **曲线**：曲线与铅笔工具（铅笔下可“平滑”）、显示数量（光／颜料油墨，后者翻转坐标）、网格大小（4×4／10×10）、显示（通道叠加、直方图、基线、交叉线），十个内置预设，自动、选项、吸管。
- **自动颜色校正选项**：增强单色对比度、增强每通道的对比度、查找深色与浅色、增强亮度和对比度（新增算法）；对齐中性中间调；阴影／高光修剪百分比和目标颜色；存储为默认值后同样用于“自动色调／自动对比度／自动颜色”。
- **曝光度、色相/饱和度、黑白、通道混合器、可选颜色、HDR 色调**：按截图的预设列表；色相/饱和度有范围色块、着色、反相（反转范围）、范围吸管（选取／添加／减去）和“之前 - 之后”色谱；黑白有自动和色调色块。
- **色彩平衡**（截图未包含，按 Photoshop 布局）：色阶数值框、三条色彩滑块、阴影／中间调／高光、保持明度。
- **渐变映射**：渐变拾取器（基础、蓝色、紫色等文件夹，⚙ 菜单的新建渐变预设、重命名、删除、五种显示方式、追加默认渐变、导入、导出所选）、仿色、反向、方法（可感知、线性、古典、平滑、条纹）。多色标渐变写入 [Windows v35](../../docs/project-format.md#windows-extension-version-35)。
- **亮度/对比度**：使用旧版（亮度逐级平移，对比度绕中间调拉伸）和自动。
- **照片滤镜**：20 种滤镜（名称保留英文，与截图一致）或自定颜色、密度、保持明度。
- **颜色查找**：3DLUT 文件列表（设置文件夹 Color Lookup 中的 .cube，载入的 LUT 复制到此处）；摘要和设备链接（ICC 配置文件）不支持，置灰并说明。
- **阈值**：阈值色阶数值框与直方图上的三角滑块联动。
- **阴影/高光**：同一行的阴影、高光滑块；显示更多选项展开色调、半径和中间调；载入／存储。
- **HDR 色调**：17 个预设；方法（曝光度和灰度系数、高光压缩、色调均化直方图、局部适应）各自只显示用到的参数；边缘光（半径、强度、平滑边缘）、色调和细节、高级（阴影、高光、自然饱和度、饱和度）、可折叠的色调曲线和直方图。
- **匹配颜色**：应用调整时忽略选区、中和、使用源选区计算颜色、源文档与图层、载入／存储统计数据和源缩略图。
- **替换颜色**：取样／添加／减去吸管、颜色容差、选区／图像预览（在预览上单击取样）、色相／饱和度／明度替换和结果色块（拾色器选择结果颜色时反算三项偏移）、载入／存储。

## 图像大小与画布大小

- **图像大小**：左侧预览；图像大小（含“之前为”）、尺寸单位、⚙ 菜单的缩放样式；调整为（原稿大小、自动分辨率…、四种屏幕尺寸、四种纸张、四种照片尺寸、载入／存储／删除预设、自定）；宽度、高度（百分比、像素、英寸、厘米、毫米、点、派卡，宽度另有列）和分辨率（像素/英寸、像素/厘米），约束比例链；重新采样八种方式（Alt+1…8）。不勾选重新采样时只改分辨率和打印尺寸。“在生成式放大中打开…”转到生成式放大。
- **画布大小**：当前大小／新大小（含内存）、七种单位（宽度另有列）、相对于当前尺寸、锚点九宫格（箭头指向扩展方向）、画布扩展颜色（前景、背景、白色、黑色、灰色、其它…）。文档底层为“背景”图层时扩展颜色才填充，否则扩展区域透明，与 Photoshop 一致。
- 首选项的“列尺寸”（宽度、装订线）现在启用，供图像大小和画布大小的“列”单位使用。

## 应用图像、计算、变量、陷印

- **应用图像／计算**：源、图层、通道（含透明度和 Alpha 通道）和反相；23 种混合模式按 Photoshop 分组（新增线性加深、深色、线性减淡（添加）、浅色、亮光、线性光、点光、实色混合）；不透明度带滑块；相加／减去显示缩放和补偿；保留透明度；蒙版…展开蒙版的图像、图层、通道和反相（计算也支持蒙版）；计算的结果为新建文档、新建通道或选区；预览实时显示。
- **变量**：定义／数据组（Ctrl+1／Ctrl+2）切换；图层 ◀ ▶；可见性、像素替换（文字图层为文本替换）及名称；像素替换的方法（限制、填充、保持原样、一致）、对齐方式九宫格、剪切到定界框，写入 v35。数据组页可新建、删除、切换、导入 CSV／TSV，并编辑每个变量的值；勾选“应用所选数据组”后确定即应用。
- **陷印**：宽度可用像素、点或毫米。

## 分析

- **选择数据点**：Photoshop 的全部 23 个数据点（通用、选区、标尺工具、计数工具四组），全选／全部取消选择、存储／删除预设。新数据点（灰度最小／最大／中间值、直方图、来源、文档等）写入 v35。
- **测量记录**：改为可停靠旁边的面板窗口：记录测量、全选、全部取消选择、导出所选测量（制表符分隔或 CSV）、删除所选测量，按数据点分列的表格，≡ 菜单含设置测量比例、选择数据点、自动显示面板和关闭。
- **测量比例**：预设（存储预设…／删除预设…），像素长度取最近一次标尺线。
- **测量比例标记**：长度、字体、字体大小（4–72 点）、显示文本、文本位置（底部／顶部）、颜色（黑色／白色）。

## 与 Photoshop 的差异

- 预设数值按 Photoshop 预设的方向和名称设定，不读取其预设文件，细节可能不同；预设以 JSON 存储。
- 八种重新采样方式映射到本应用的三种重采样算法（高质量两次立方、两次线性、邻近）；“保留细节 2.0”不是 Adobe 的 AI 放大。
- 曲线的“显示修剪”、色相/饱和度和曲线的“在图像中单击并拖动”、替换颜色的“本地化颜色簇”、颜色查找的摘要／设备链接和 LUT 仿色未实现，置灰并说明。
- HDR 色调的“平滑边缘”以更大的半径近似边缘保护；“边角”未实现。

沿用既有面板规范：普通窗口 32 DIP 标题栏；菜单和提示显示同一实际快捷键；跨面板交互取消滚动冲突。此前 imagegen 生成的图标参考稿保留为历史记录，运行时使用统一图标体系；本次没有重新生成素材。
