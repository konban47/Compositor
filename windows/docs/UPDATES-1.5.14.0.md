# Windows 1.5.14.0 Preview

2026-10-31。本版移植上游 main `76b7921` 之前的体积光深度改动，统一重绘全部按钮图标、工具图标和面板标志，并按 Photoshop 的方式改造浮窗的标签、折叠／展开、关闭和面板菜单。浮窗的停靠、拖动、浮动、分组和工作区保存逻辑不变。

## 上游移植

- **体积光深度（上游 `039d445`…`76b7921`，共 11 个提交）**：雾气按照片的真实深度分布，不再只按画面位置估计。“距离”决定雾气从场景多远处开始，按照片自身的深度分布换算，同一数值在任何场景都清掉相同比例的近景；“深度对比度”把挤在一起的深度（如远处城市）逐层拉开，默认 0；“长度”默认改为 0。照片自身的灯光按其比周围亮出多少来发光，明亮场景不会整体发光。主体边缘由主体蒙版决定：主体本身算作近处，周围被模型“渗出”的一圈改用其后背景的深度。
- **提取深度**：体积光面板新增“提取深度”，关闭滤镜并把雾气所依据的深度作为新图层（白近黑远）放在该图层上方，同一撤销步骤。
- **预览加速**：同一图层上移动“雾气”“距离”“强度”或颜色时，复用已算好的场景、深度和光束，只重新叠加。
- **深度模型**：上游 DepthMini 是 Core ML 模型，Windows 无法运行。Windows 首次打开体积光时下载 Depth Anything V2 Small（Apache-2.0，ONNX Community 发布的 8 位量化版，27 MB），固定为 HuggingFace 修订 `4472b73`，校验 SHA-256 `fcf51f1b…f20d` 后存于 `%LOCALAPPDATA%\Compositor\Depth Model 1`。下载期间面板显示“正在获取深度…”，“提取深度”和“应用”暂时不可用，“取消”可用；无网络或校验失败时雾气按原方式估计，下次再试。可用环境变量 `COMPOSITOR_DEPTH_MODEL_DIR` 改变存放位置（手动放入同名文件即可离线使用）。
- **平台限制**：上游用 Vision 的人像分割和人体姿态找头发与肩线；Windows 没有对应系统服务，主体轮廓使用随附的 U²-NetP 通用主体蒙版。上游为 Metal 着色器，Windows 为 CPU 实现，结果不保证逐像素一致。

## 图标

- 新增统一图标体系 `IconSet`：24 单位网格、2 单位留白、1.5 线宽、圆头圆角，必要处用实心部分（画笔刷毛、路径选择箭头）。覆盖 69 个工具、全部按钮与选项栏图标、35 个面板标志、排列（前移／后移）图标、画笔设置锁、颜色交换／复位和浮窗标记。
- 上游有的 15 个工具按上游 `ToolRail.swift` 指定的 SF Symbols 造型和线重绘制（移动、选框、椭圆、套索、魔棒、画笔、修复、模糊、形状、裁剪、抓手、缩放、文字 Aa、吸管）；Apple 符号本身不随包分发。上游自绘的仿制图章、渐变、多边形套索和对象选择直接沿用上游绘制代码；应用图标沿用上游 `AppIcon`。
- 只有 Photoshop 有的工具按 Photoshop 的图形含义绘制（钢笔组、路径／直接选择、减淡、加深、海绵、橡皮擦组、油漆桶、锐化、涂抹、历史记录画笔、图案图章、颜色替换、混合器画笔、快速选择、磁性套索、切片、标尺、计数、修补、红眼等）；变体在左上角 6×6 区域加徽标（加号、减号、闪光、回退箭头）。
- 原先三套不同网格和线宽的图形（24 单位 1.65、28 单位 1.8、上游 18 单位）及排列图标的位图遮罩已移除；位图参考稿移至 `windows/design/slice-order-icons`。`--edit-workspace-checks` 另输出全部图标在 22 与 40 逻辑像素下的对照图集，并检查每个图标都有内容。

## 浮窗（参照 Photoshop）

- 面板标签只显示名称：当前标签与面板同色并连成一体，其余标签在更暗的标签条上显示为灰色；去掉标签上的 × 和蓝色下划线。
- 标签行末端新增 ≡ 面板菜单：关闭、关闭选项卡组、浮动面板、浮动选项卡组、折叠为图标／展开面板。右键标签得到同一菜单。
- 停靠的面板组顶部只保留拖动条；折叠为图标由所在列顶部的 » ／ « 控制。浮动面板组的顶部保留 «（折叠为图标）、»（展开）和 ×（关闭）。
- 标记改为 1 像素整像素线，悬停时变亮。拖动、停靠、浮动、分组、折叠和工作区保存逻辑均未改变。

## 维护

- 1.5.13.0 的版本提交误将 `windows/dist-*` 打包目录中的 278 个文档副本纳入版本控制；本版将其移出版本控制并加入 `.gitignore`，本地文件不受影响，已发布的 1.5.13.0 安装包不受影响。

## 验证

- Release 构建零警告、零错误；核心测试见本节末行。新增 `VolumetricDepthTests`（深度对比度、深度减少近处雾气、距离清除近景、主体轮廓决定边缘深度、下载校验失败不保留文件、提取深度图层位置）；用本机下载的真实模型运行 `TheModelSeesTheFloorNearerThanTheWall`（设 `COMPOSITOR_DEPTH_MODEL_FILE` 时运行，CI 不下载模型）。
- `--panel-checks` 检查体积光以上游默认值打开、下载期间“提取深度”与“应用”等待、下载失败后恢复且不留文件；自检用拦截的下载，不访问网络。`--docking-checks` 检查标签上没有关闭按钮、每个面板组有 ≡ 面板菜单且其中“关闭”生效。
- 未验证：真实照片上的深度效果与上游 DepthMini 的差异；首次下载在慢速网络下的体验；Windows 10、扫描仪与实体压感笔。
