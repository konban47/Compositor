# Windows 1.4.7.1 Preview

本次更新处理 2026-10-09 的 Windows 使用反馈，保留 `.comp` 格式版本 11。无需转换原有项目。

## 使用反馈对应修复

| 项目 | 本次行为 | 验证 |
| --- | --- | --- |
| 汉化遗漏 | 修复数值格式导致的按钮漏译；补齐工具提示、状态、选区、网格、Camera Raw 和 PSD 转换报告；新建默认图层名使用中文，已有名称不变 | 中文窗口、工具提示、动态按钮、资源缺项审查 |
| 桌面拖入 | 画布接收 Windows 文件拖放，显示复制光标；支持多文件，复用菜单导入逻辑 | 路由 DragOver/Drop 事件携带实际图像路径，两张图像分别成为图层并可撤销 |
| 单对象移动 | 选中图层后更新变换框；可单击可见对象选择；移动工具不再回退到平移画布；隐藏变换控件仍可移动 | 鼠标拖动只改变目标变换，另一图层与画布视口保持不变 |
| 图层可见性与排序 | 每行有睁眼／闭眼按钮；按住图层名称上下拖动，显示插入线；图层组不会被拖进自己的子层 | 眼睛的实际鼠标点击、拖动排序和撤销；组结构测试 |
| 动态选框 | 连续黑白虚线沿选区边缘运动，支持多轮廓；动画复用合成图像 | 动画相位变化，不重复合成所有图层 |
| 选区内编辑 | 有选区时 Delete/Backspace 清除当前层的选区像素；液化和涂抹增加选区及羽化裁切 | 液化、涂抹、图章、修复、模糊在普通／旋转图层上检查选区外像素逐点不变；空选区与羽化覆盖测试 |
| 项目首页 | README 改为 Windows 项目介绍、安装和快捷操作说明，顶部保留上游链接与致谢 | 文档及链接检查 |

未建立选区时 Delete 仍执行“删除图层”。编辑图层蒙版时清除操作在选区内将蒙版填黑。文字编辑及其他文本输入框保留各自的 Delete 行为。

## 上游更新对照

对照 [上游 1.4.7](https://github.com/robbietilton/Compositor/releases/tag/v1.4.7)，并合并原始源码至 [`b5f9b805`](https://github.com/robbietilton/Compositor/commit/b5f9b805cf91f658ae86039724c6433092cb4622)。Windows 实现单独移植，不能直接运行 Swift/AppKit 代码。

| 上游更新 | Windows 对应处理 |
| --- | --- |
| Last Filter | Ctrl+Alt+F 使用最近应用的滤镜参数，不重复弹出参数面板；菜单显示滤镜名称；取消不会覆盖记录；包括 Camera Raw、仿色和移除背景，调整菜单和内容识别填充不计入 |
| F 全屏、Esc 退出、命令搜索 Cmd+F | Windows 已有 F／Esc、Ctrl+F，保留并回归验证 |
| 窄窗口工具栏滚动 | 工具选项增加横向滚动容器 |
| 平移中光标状态 | 手形／空格／中键平移期间保持 Windows 拖动光标，释放或失去捕获后恢复 |
| 图层面板可读性、选择后定位、避免闪烁 | 新增可读的眼睛图标；选中的行自动滚入视野；普通画布编辑不重建图层列表；Windows 重命名继续使用独立对话框 |
| 更明确的 Don't Save | 未保存关闭提示改为“不保存／取消”，两者保持普通按钮样式 |
| Camera Raw 高光／阴影曲线修复 `0b4c56c` | 移植保持明暗顺序的曲线，保留黑点、白点和中灰；灰阶坡道测试覆盖四种极值 |
| macOS 滑块测试绘制时序修复 | 合并保留原测试源码；Windows 使用自己的指针、控件和像素检查 |

## 验证与发行

核心测试 887 项。窗口测试包括 `--clicks`、`--tools`、`--shortcuts`、`--tabs`、`--camera-raw`、`--dialogs`、`--windows-checks`、`--interaction-checks`。最后两组同时在中文和英文环境运行。CI 在 Windows Server 2022/2025 验证，并测试自带运行时的发行程序、安装与卸载。

Windows 11 本机的自动检查和 CI 不等于人工操作全部硬件的验收。Windows 10 实机、真实输入法候选窗、数位板和多显示器边界仍保留在 [已知差异](README.md#已知差异和验收边界) 中。本次未新增 macOS 人工测试。
