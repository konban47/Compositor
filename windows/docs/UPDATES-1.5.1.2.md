# Windows 1.5.1.2 Preview

2026-10-13。合并上游 [e8c9e29701528413cc0e608d61187c1c61790add](https://github.com/robbietilton/Compositor/commit/e8c9e29701528413cc0e608d61187c1c61790add)。

- 修复浅色主题的图层／通道行背景、文字面板标签字号和关闭操作、图层样式滑块裁切、Esc 导致文字消失。菜单更紧凑，属性三点按钮扩大。画布文字编辑的 Ctrl+A／C／X／V 优先处理文字选区，避免全局图像命令截获。
- 新增“窗口”菜单并保留“文字”。面板可拖出独立工具窗口并停靠，支持工作区预设、保存、恢复、删除和锁定。文档可在多个窗口共享内容与撤销，支持排列和匹配视图。
- 参考线支持专用光标、选择颜色、双击首选项、右键编辑／锁定／按范围清除；画布外右键设置编辑区背景。
- 窗口菜单列出的工具面板接入现有编辑功能。动作、本地库、二维材质、会话图层复合及图层帧预览的范围见 [WINDOW-MENU.md](WINDOW-MENU.md)，不声称与 Adobe 云服务、3D、动画或 ATN 完全兼容。
- 对应上游移植 Camera Raw 分栏重置与预览开关、滚动条留白、快捷键清除按钮、CMYK 校样／色域警告可分配快捷键，以及 Delete 和组合键录入修复。重置恢复参数的真实默认值，不将全部参数错误地归零。
- Windows 格式 v21 仅用于带画板归属的参考线；普通文档继续选择所需的较低版本。源码、中文词条、操作手册、格式说明、发行包清单和 CI 同步更新。
- OpenCL 迁移保持暂缓，继续使用 Skia。

验证：Release 构建将警告视为错误；1153 项核心测试；英文／中文窗口与交互回归、新增 docking 专项覆盖主题实际行、标签关闭／拖出／停靠、共享窗口编辑／撤销／关闭、参考线菜单、Esc 文字保留、滑块端点／拖动和分栏重置。CI 覆盖 Windows Server 2022／2025 及发布包，不能代替 Windows 10 实机、多显示器、数位板和真实输入法人工验收。私人 PSD 及派生项目不上传。
