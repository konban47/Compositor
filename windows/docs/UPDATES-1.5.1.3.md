# Windows 1.5.1.3 Preview

2026-10-13。核对 [上游最新提交 e8c9e29701528413cc0e608d61187c1c61790add](https://github.com/robbietilton/Compositor/commit/e8c9e29701528413cc0e608d61187c1c61790add)，与 1.5.1.2 已合并基线一致，本次没有新的上游提交需要移植。

- 移除“窗口 → 在 Exchange 上查找扩展”和“文字 → 来自 Adobe Fonts 的更多字体”，同时移除字体浏览器的 Adobe 外链按钮、执行逻辑和无用中文词条。本地字体浏览器与 Compositor 插件管理继续可用。
- 修复标签拖动处理截获点击的问题。图层／通道、属性／历史及其他标签在按下时立即选中，小幅移动不分离；双击标签不再误折叠。
- 依据录像实现跨组标签合并／排序、整组浮动、停靠区上下分组和左右分栏、蓝色落点提示、半透明拖动、Esc 还原布局、窄图标栏与浮窗折叠。保留当前主题、紧凑字号和控件风格。
- 上下文任务栏支持浮动、回停、固定和重置位置；保存工作区时记录分组、顺序、选中标签、行列尺寸、折叠与浮窗位置。兼容旧版工作区设置。
- 使用内置 imagegen 为全部 35 个折叠面板／工具窗口逐一生成图标参考，整理为统一线宽的主题矢量；包含深浅色实际预览、SVG、提示词与来源说明。工具浮窗折叠后点击专属图标恢复原尺寸，长图标栏可滚动。左侧工具栏图标保持现状。
- 操作说明与实际范围见 [WINDOW-MENU.md](WINDOW-MENU.md)。工作区布局只更新个人设置结构，图片项目格式仍为 Windows v21。OpenCL 迁移暂缓，继续使用 Skia。

验证：Release 构建将警告视为错误；1153 项核心测试；19 组英文与 13 组中文界面检查，停靠专项增加真实路由鼠标点击／拖放、分组持久化和取消回退覆盖。CI 覆盖 Windows Server 2022／2025、发布包及安装／卸载。多显示器和 Windows 10 实机仍需单独人工验收。私人录像、截帧和 PSD 不进入仓库或发行包。
