# Windows 1.5.2.1 Preview

2026-10-14。再次检查上游，最新仍为已合并的 [Compositor 1.5.2 / 43d691b](https://github.com/robbietilton/Compositor/commit/43d691b67995e924965bcd520f8b300f96b7d5b8)，本次没有额外上游提交需要合并。

- 顶层菜单采用紧凑主题标题栏，保留窗口最小化、最大化、关闭；工具命令移至编辑菜单，选项栏搜索可查找工具及命令，不提供发现按钮。
- 选项栏移除标题及面板控制按钮，以工具图案切换工具预设；浮动状态左侧突出区域用于拖动，停靠时隐藏。增加工作区快捷菜单。
- 移动工具选项补齐自动选择图层／组、显示变换控件、对齐分布、三个悬停／组展开设置。画板工具支持尺寸预设、创建、移动、调整大小、方向、背景、对齐分布及自动嵌套等设置。
- 工具预设支持持久保存、管理、导入导出、过滤、排序、列表大小、复位，以及转换为画笔预设。导入格式为 Compositor JSON，不兼容 Adobe TPL。
- 左工具栏在单列和双列之间切换，浮窗宽度为 46／82 逻辑像素。停靠隐藏关闭按钮，浮动恢复关闭按钮。标题栏约 11 像素，选项卡保持原高度；工作区恢复保留工具栏列数和窄浮窗尺寸。
- 补充工具光标和移动工具边缘／角点缩放、外侧旋转交互，旋转后方向跟随；保留现有画笔、取样、参考线等指针逻辑。
- 点击画板外空白显示文档属性，清除图层隐式回退。标尺追踪鼠标坐标。右侧增加常驻纵向滚动条；横向滚动条嵌入最底部信息栏中间，随缩放、旋转和导航器同步。
- 非白色／透明画板背景保存为 Windows v22 的 `artboardBackground`。白色画板继续使用其他功能所需的较低版本，旧文件按白色读取。上游 macOS 不支持 Windows v22。
- 同步 README、窗口操作手册、项目格式、发行文档、版本号及文档一致性检查；OpenCL 仍暂缓，继续使用 Skia。

验证：Release 构建将警告视为错误，1168 项核心测试；新增 `--chrome-checks`，CI 共 20 组英文、14 组中文界面检查，并对发行包运行检查。实际 Windows 窗口检查与自动化结果记录于本次交付；Windows 10 实机和多显示器仍需独立验收。私人截图和录像不进入仓库或安装包。
