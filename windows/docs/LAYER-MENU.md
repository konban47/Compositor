# 图层菜单与钢笔操作

适用于 Windows **1.6.6.5 Preview**。1.6.6.3 按“图层菜单截图”文件夹（121 张：16 张菜单图与 105 张对话框截图）重排“图层”菜单：顺序、分隔线、访问键（中文界面写作“图层(L)…”，括号在省略号之前）、子菜单和图标与截图一致，没有对应功能的项置灰并在悬停提示中说明原因。原“图像”菜单继续保留。

## 智能滤镜与 Alt 单击剪贴（1.6.6.5）

- 对智能对象使用滤镜即成为智能滤镜，智能对象内容不变；边缘光、体积光仍需先栅格化。缩略图右下角显示智能对象标志；图层右侧从左到右为智能滤镜标志、fx、展开／收起箭头，互不重叠。
- 图层下方为“智能滤镜”行（眼睛、滤镜蒙版缩略图）和各滤镜（最新的在上），每行有眼睛、名称和混合选项图标；这些行属于图层本身，拖动图层时一起移动。双击滤镜重新编辑，双击图标编辑混合选项（模式、不透明度、预览）。
- 右键“智能滤镜”行：停用／启用智能滤镜｜删除／添加滤镜蒙版｜清除智能滤镜；右键滤镜：编辑智能滤镜混合选项…、编辑智能滤镜…｜停用／启用智能滤镜、删除智能滤镜。“图层 → 智能滤镜”子菜单另有停用／启用滤镜蒙版。智能滤镜写入 [Windows v36](../../docs/project-format.md#windows-extension-version-36)。
- 按住 Alt 把指针移到两个图层的分界线，指针变为剪贴光标，单击把上方图层剪贴到下方图层（同 Alt+Ctrl+G），再次单击释放。

## 菜单接入

| 分组 | 实际功能 |
| --- | --- |
| 新建 | 图层…／组…／从图层建立组…弹出“新建图层”“新建组”对话框（名称、颜色、模式、不透明度，图层另有“使用前一图层创建剪贴蒙版”和“填充中性色”）；图层背景；画板…、来自图层组的画板、来自图层的画板…、来自图层的画框…、转换为图框弹出名称与尺寸对话框（画板带预设尺寸）；通过拷贝／剪切的图层 |
| 复制／删除／导出 | 复制 CSS／SVG；“复制图层…”可选择为新名称、目标文档（当前、其他已打开文档或新建）与画板；删除图层或隐藏图层；快速导出为 PNG、导出为… |
| 图层样式 | 混合选项…与十种效果各自打开图层样式窗口的对应页；拷贝／粘贴／清除图层样式；全局光…（角度与高度、实时预览）；隐藏所有效果；缩放效果… |
| 智能滤镜、协调 | 菜单项按截图列出并置灰：滤镜直接作用于像素或保留为滤镜图层；“协调”是 Photoshop 的生成式服务 |
| 填充与调整图层 | 纯色…／渐变…／图案…先弹出“新建图层”（名称默认“颜色填充 1”等），再打开拾色器或样式窗口；22 种调整图层同样先命名，再打开各自设置，清晰度和去朦胧可作为调整图层 |
| 图层／矢量蒙版 | 显示／隐藏全部或选区、从透明区域创建、当前路径、应用／删除、启停、链接；复用密度／羽化与历史 |
| 智能对象 | 转换、通过拷贝新建、在资源管理器中显示链接文件、更新修改的内容、编辑／替换／导出内容、复位变换、重新链接到文件、嵌入链接的／所有链接的智能对象、转换为链接对象…（把内容存为 PNG 并链接）、转换为图层、堆栈模式（无及 11 种统计模式）、栅格化 |
| 视频图层 | “从文件新建视频图层…”把视频导入为帧图层；其余视频时间轴命令置灰 |
| 栅格化 | 文字、形状、填充内容、矢量蒙版、智能对象、图层样式、图层、所有图层；生成式、视频、3D 置灰 |
| 排列与组织 | 编组／取消编组、隐藏、置顶／上移／下移／置底／反向、锁定图层…（透明度、图像、位置、防止自动嵌套、全部）、链接、选择链接图层、合并可见及拼合 |
| 合并形状 | 统一形状、减去顶层形状、统一重叠处形状、减去重叠处形状，每项带图标；产生仍可编辑的路径形状 |
| 对齐／分布／切片 | 顶边、垂直居中、底边、左边、水平居中、右边（带图标）；有选区时“对齐”变为“将图层与选区对齐”；分布另有水平、垂直间距；按所选图层边界新建切片 |
| 修边 | 去边与颜色净化用邻近不透明像素延展颜色，保留 Alpha；移除黑／白杂边使用反解底色公式 |

显示范围与限制：

- 单层目前只有一个蒙版槽，不能同时独立保存像素蒙版和矢量蒙版；已有蒙版时不再启用新建入口。
- 填充层采用普通像素底层加颜色／渐变／图案样式，不是 Adobe 原生填充层对象。打开“图层内容选项”继续编辑。
- 新增八类调整层写入 Windows v19，参数及 LUT 随项目保存；重新打开编辑保留原参数。对已有色阶／曲线等调整类型仍使用原格式。
- 智能对象是本应用内嵌源，转换为图层产生有边界的画框组，保留源画布裁切、背景、整体不透明度、蒙版和原图层 ID，子图层可编辑。复杂变换仍遵循现有变换算法。
- 堆栈模式按内容中各可见图层的逐像素统计生成显示缓存（写入 Windows v34），编辑内容或更新链接后重新计算；“无”恢复普通合成。熵、峰度、偏度、方差和标准偏差按 0–255 显示范围缩放，结果不保证与 Photoshop 逐像素一致。
- “防止自动嵌套”（v34）阻止拖动或移动工具把图层自动放入画板或画框。
- 带蒙版、样式、高级混合、剪贴关系，或不在同一父组的形状不启用布尔合并；直线不是闭合面积形状。空交集不会删除原层。
- “颜色净化”与“去边”共用颜色延展算法，只是初始半径不同，不等同于 Adobe 选择并遮住的颜色净化。没有不透明邻域时不能恢复未知前景颜色。
- 智能滤镜、视频时间轴编辑、生成式图层、3D、重新链接到库图形（Creative Cloud 库）和把每个样式效果独立拆层（创建图层）未实现，菜单项置灰并有说明。
- 对没有可栅格化内容的普通像素层，栅格化不产生新历史；调整图层不会被误当成独立像素图像烘焙。

- 图层面板底部的调整图层和滤镜图层分为两个菜单，滤镜按钮是圆环内的棋盘格圆盘，菜单从图标上方打开（1.6.3）。滤镜图层的面板没有“预览”，用图层的眼睛图标对比前后。

## 多选图层与位深（1.5.13.0）

- “转换为 16 位图层／转换为 8 位图层”在“图层”菜单和图层右键菜单中都有，作用于所有选中图层及选中组内的图层，合为一步撤销。右键菜单只显示会改变某个选中图层的项，选中位深不一的图层时两项都显示；HDR 图层可转为 16 位或 8 位。文字、形状、调整图层、GIF 动画图层和锁定像素的图层不转换。
- 创建／释放剪贴蒙版作用于所有选中图层：全部已剪贴时释放，否则从下往上把未剪贴的图层剪贴到最下方选中图层之下的那一层，合为一步。任一图层无法剪贴（组、最底层）时整组不改变，菜单项禁用。
- 16 位或 HDR 图层经内容识别填充、仿色等 8 位编辑后保持原位深（由每次编辑结束时的历史记录统一处理）：未改动的像素保留原 16 位样本，改动处按新值写入。编辑扩大或平移图层网格（如选区超出图层边界的内容识别填充）时按整像素偏移对齐；重采样、非整像素平移或旋转时整张结果按原位深写入。只有“转换为 8 位图层”会降为 8 位。
- 从 16 位或 HDR 图层复制、剪切后粘贴，或“通过拷贝的图层”，新图层保留原位深与样本（1.5.13.0）；从 8 位图层粘贴仍为 8 位。内容识别移动、修补／仿制、红眼、仿色、油漆桶、渐变、填充、清除、移动像素、剪切、晕影、色调对比度和内容识别填充等 8 位编辑路径均有逐项位深测试。
- “快速导出为 PNG”把每个选中图层单独渲染（保留所在组的不透明度和蒙版、剪贴到它的图层；隐藏的选中图层也照常导出），裁切到可见像素，以图层名命名。单个图层弹出存储对话框；多个图层选择文件夹，同名文件先询问是否替换，重名图层自动编号，没有可见像素的图层跳过并提示。导出成功后触发脚本事件“导出文档”。“导出为…”（原“导出图层为…”）仍将选中图层合并为一个文件。

## 快捷键和钢笔

Ctrl+J 为通过拷贝的图层：存在像素选区时复制选区内容，没有选区时复制图层。Ctrl+Shift+J 保留本应用已有“复制图层”映射；“通过剪切的图层”可在快捷键窗口另行指定，避免覆盖用户配置。

Ctrl+]／Ctrl+[ 前移／后移一层；Ctrl+Shift+]／Ctrl+Shift+[ 置顶／置底。多选排列保持相对顺序并在各自父组内处理，锁定保护不变。其他既有快捷键见 [图层样式手册](LAYER-STYLES.md)。

钢笔、自由钢笔、增删锚点及转换锚点工具显示钢笔形光标。拖出曲线控制柄时绘制锚点至控制柄的辅助线；移动指针只刷新覆盖层。颜色／线宽与首选项中的路径及控制线共用设置，钢笔光标可独立关闭。

1.5.3.2 增加工作路径、Ctrl+Enter 转选区、蓝色选中节点与闭环提示；三个钢笔工具的完整选项、图层拖动与限制见 [钢笔与图层拖动](PEN-AND-LAYERS.md)。
