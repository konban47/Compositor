# Windows 1.6.6.3 Preview

2026-11-11。本版逐张核对“图层菜单截图”文件夹（121 张：16 张菜单图、105 张对话框截图），按截图重排“图层”菜单及其对话框，重做图层样式窗口，并补上截图中出现、此前缺少的功能。上游 main 仍为 `02e53989dc499d749d83f33023ff249de1c7b4eb`（1.6.6，2026-11-07），没有新的提交需要移植。

## 图层菜单

- **菜单结构**：顺序、分隔线、子菜单与截图一致；中文界面的访问键写作“复制图层(D)…”，括号放在省略号之前（此前为“复制图层…(D)”），全部菜单通用。合并形状、对齐、分布各项带图标；有选区时“对齐”显示为“将图层与选区对齐”。
- **新建图层／新建组／从图层建立组**：名称（按“图层 1”“组 1”编号）、颜色（无与 11 种颜色，带色块）、模式（分组列表，组另有“穿透”）、不透明度（带 ⌄ 滑块）；图层可“使用前一图层创建剪贴蒙版”，“填充中性色”在正片叠底、滤色、叠加等有中性色的模式下可用并显示颜色。调整图层和填充图层同样先弹出此对话框。
- **复制图层**：为（新名称）、目标文档（当前、其他已打开文档或新建，新建时可填文档名称）、画板。
- **画板与画框**：画板…／来自图层组的画板／来自图层的画板…弹出名称、预设尺寸（iPhone、iPad、Android、Surface、MacBook、iMac、Apple Watch 等，分隔线位置同截图）、宽度、高度；来自图层的画框…／转换为图框弹出“向图层添加画框”。
- **锁定图层**：透明度、图像、位置、防止自动嵌套、全部，带图标；勾选“全部”时其余项保持勾选并不可改。
- **全局光**：角度与高度圆盘、数值框和预览；确定后作用于所有使用全局光的效果，一步撤销。
- **智能对象**：新增在资源管理器中显示、嵌入所有链接的智能对象、转换为链接对象…（内容存为 PNG 后链接）、堆栈模式（无、标准偏差、范围、方差、峰度、偏度、平均值、熵、中间值、总和、最大值、最小值）。重新链接到库图形置灰（无 Creative Cloud 库）。
- **视频图层**：从文件新建视频图层…把视频导入为帧图层；其余时间轴命令置灰。
- **新建调整图层**：清晰度和去朦胧可作为调整图层使用。
- **置灰并说明的项**：智能滤镜子菜单、协调、栅格化中的生成式／视频／3D、图层样式中的创建图层。

## 图层样式窗口

- 按截图重排左栏（复选框 + 名称，斜面和浮雕下的等高线、纹理子项，可重复效果的 **+**，fx 菜单、上移、下移、删除）、中间的分组框与滑块行、右侧确定／取消／新建样式(W)…／预览／缩览图。
- 新增：设置为默认值／复位为默认值；角度圆盘（斜面和浮雕同时调整高度）；等高线编辑器（预设、映射曲线、输入／输出、载入／存储／新建）与等高线预设列表；消除锯齿；光泽等高线；多色标渐变与渐变方法、仿色；发光的纯色／渐变、范围、抖动；描边叠印；图层挖空投影；纹理反相、紧贴原点；样式页分组与齿轮菜单（追加默认样式、导入／导出、删除组、缩览图大小）。
- 新的效果默认值采用 Photoshop 的数值，例如投影不透明度 35%、距离 3、大小 7。

## 混合模式与项目格式

- 新增溶解、深色、浅色三种混合模式，图层、效果和 PSD 导入／导出均可用。
- 项目格式升级到 [Windows v34](../../docs/project-format.md#windows-extension-version-34)：上述混合模式、防止自动嵌套锁、智能对象堆栈模式、全局光高度和新的效果选项。只有用到这些内容时才写入 v34，较早的 Windows 版本会拒绝打开 v34 项目。
