# Windows 1.5.12.3 Preview

2026-10-30。本版将 Claude 交付的导出事件与 PDF 演示文稿补丁（基线 `windows-port@a2e2ffdc920124ffae6368fa0a844fa9a9809b35`）接入 Windows 项目，并在本机编译及验证。版本号、手册、打包脚本和安装器统一为 1.5.12.3；完整截图任务仍有待办，不能将本版理解为全部功能完成。

- 脚本事件“导出文档”补齐接线：储存为 Web 所用格式、导出图层到文件、导出图层复合到文件／PDF、通道打包、渲染视频成功后派发；Web 与图层导出在对话框关闭后派发一次（对话框内连续存储多次也只派发一次），避免脚本提示压在模态对话框下。取消、失败或未写出文件时不派发。打印仍无对应命令。
- PDF 演示文稿按参考截图补齐“存储为：多页面文档／演示文稿”、背景、字体大小（6–16）与“包含”题注（文件名、扩展名、标题、说明、作者、版权、EXIF 信息），以及“演示文稿选项”：换片间隔（秒）、在最后一页之后循环、过渡效果（无、16 种过渡及随机）。
- 演示文稿以增量更新写入标准 PDF 页面属性 `/Dur` 和 `/Trans`，目录写 `/PageMode /FullScreen`。循环没有标准 PDF 字段，使用 Acrobat 全屏 JavaScript 请求；不支持 JavaScript 的阅读器只会按时换片、不循环。只处理使用传统交叉引用表的 PDF，其他结构会明确报错。“注释”复选框保留布局位置但禁用，本版不写 PDF 注释。
- 本机接入时修复：输出选项中“背景色”“字体大小”沿用 130 DIP 固定标签列，下拉框只剩约 55 DIP，中英文均被截断为“黑”“Bl”“1…”；改为标签自适应宽度后完整显示。
- 本机验证：Release 构建零警告、零错误；核心测试 **1543 项通过、2 项默认跳过**（大型内存诊断、需要 FFmpeg 的真实视频测试），其中 `PdfSlideshowTests` 验证 Skia 输出可增量写入、PDFium 仍识别页数。中英文 `--file-workflow-checks`、`--interaction-checks`、`--windows-checks` 通过，各次使用独立设置目录。新词条“标题”“扩展名”只用于 PDF 题注复选框。
- 未验证：导出事件路径需要文件选择器，暂无自动化检查；演示文稿的全屏、换片、过渡和循环尚未在 Acrobat、Edge、SumatraPDF 中实测，峰值内存约为 PDF 大小的 5 倍，大文件未实测。
