# Windows 1.6.6.1 Preview

2026-11-10。本版补齐 1.6.6.0 列为“尚未按截图完成”的编辑菜单窗口，并把它们做成可用的完整功能。上游 main 仍为 `02e53989dc499d749d83f33023ff249de1c7b4eb`（1.6.6），没有新的提交需要移植。

## 编辑菜单余下的窗口

逐张核对 `编辑菜单截图` 中内容识别填充、天空替换、颜色设置（11 张）、自定 CMYK（4 张）、自定 RGB（3 张）、自定灰度系数、自定网点增大、键盘快捷键和菜单（6 张）、Adobe PDF 预设、预设管理器（3 张）、等高线名称和画笔名称的截图后重做。控件沿用本项目的按钮、字体和深浅主题；对话框在 1080p 屏幕上无需滚动即可完整显示。

- **内容识别填充工作区**：左侧取样画笔、套索、抓手、缩放；选项栏切换添加／减去与画笔大小（Alt 临时反向）。画布上以半透明绿色显示取样区域（可改不透明度、颜色，或改为表示排除区域），虚线框为填充区域。右侧面板：取样区域选项（自动、矩形、自定，对所有图层取样）、填充设置（颜色适应 无／默认／高／非常高；旋转适应 无／低／中／高／完全；缩放；镜像）、输出设置（当前图层、新建图层、复制图层），每组带复位按钮；底部复位全部、确定、应用、取消。预览面板实时显示输出结果并可缩放。
  - 填充内核在原 PatchMatch 移植的基础上加入：只从取样区域复制；旋转、缩放、镜像后的源副本一起参与匹配；颜色适应把填充区与边缘的色差沿边界扩散到整个填充区（类似泊松融合），强度随档位提高。
  - 自动取样区是填充区周围约半个选区宽的一圈，矩形取样区是外扩后的矩形框；两者都会避开所选图层的透明像素，可用像素不足填充区的三倍时自动放宽。
  - “应用”后留在工作区继续填充；每次填充是一个撤销步骤，编辑后的填充区域保留为选区。“滤镜 → 内容识别填充”仍按默认设置直接填充。
- **天空替换**：没有选区时按亮度、平滑度和与顶边的连通性找到天空；有选区时以选区为天空。天空选择器打开天空库：分组折叠、最近使用、缩略图大小滑块、新建组／导入图像／删除按钮，齿轮菜单有获取更多天空（导入图像、导入预设）、创建新天空组、重命名天空、删除天空、显示最近使用的项目、追加默认天空、导出选定的天空。默认的蓝天、盛景、日落共 15 张由 Compositor 首次打开时自己绘制，不含 Adobe 素材；导入的图片以 JPEG 复制进设置目录；导出为 `.skies`（ZIP）。
  - 移动边缘、渐隐边缘；天空调整（亮度、色温（蓝—黄渐变轨道）、缩放、翻转）；前景调整（光照模式 正片叠底／滤色、前景光照、边缘光照、颜色调整）；输出到新图层或复制图层；预览。
  - 对话框不阻塞文档：天空移动工具在画布上拖动天空，天空画笔扩大天空（Alt 缩小），抓手和缩放作用于画布；预览在停止操作约 0.14 秒后更新。
  - 确定后，“新图层”生成“天空替换组”：带蒙版的天空图层、前景光照图层（正片叠底或滤色）、前景颜色图层（颜色模式）；“复制图层”生成一个合成后的图层。“下载免费天空”依赖 Adobe 服务，未提供。
- **颜色设置**：设置下拉按截图分组（自定／其它／日本／北美与欧洲）；工作空间、色彩管理方案（关、保留嵌入的配置文件、转换为工作中的 RGB／CMYK／灰度）、配置文件不匹配与缺少配置文件的询问、转换选项、高级控制、说明区的布局与截图一致。指针移到控件或下拉项上，说明区显示其含义；离开后恢复当前设置的说明。工作空间下拉菜单含自定、载入、存储和“其它”分组。截图中的 Creative Cloud 同步在 Windows 版不适用，改为说明设置的作用范围；引擎列出 Little CMS、Microsoft ICM 和 Compositor 自己的 ACE 兼容引擎（不是 Adobe 的 ACE）。
- **自定 RGB／自定 CMYK／自定网点增大／自定灰度系数**：生成真正的 ICC 配置文件并加入工作空间列表，详见[颜色管理](COLOR-MANAGEMENT.md#自定配置文件1661)。自定 CMYK 的油墨组 Lab 值是近似通用数据，正式印刷请使用印刷厂的 ICC。
- **键盘快捷键和菜单**：一个窗口两个标签页。快捷键页：快捷键用于（应用程序菜单按文件、编辑等菜单分组，或工具）、组（Compositor 默认值与自己存储的组，存储／新建／删除图标）、使用旧版还原快捷键、使用旧版通道快捷键、搜索与区分大小写、命令／快捷键两列树形表、接受、还原、使用默认值、添加快捷键、删除快捷键、摘要（存为 HTML）和说明框。菜单页：搜索、组、命令／可见性／颜色三列，眼睛按钮隐藏项目，颜色列 8 种颜色；隐藏项目后该菜单底部出现“显示全部菜单项目”，菜单关闭后恢复隐藏。Compositor 的面板菜单和任务空间没有可指定快捷键的命令，因此不提供这两项。
- **PDF 预设**：预设列表、预设说明、可折叠的设置小结；完成、新建、编辑、删除、载入、存储为。内置 [高质量打印]、[印刷质量]、[最小文件大小]、[PDF/A-2b]。“导出为”选择 PDF 时可选预设：缩减像素采样（平均／双立方，至与高于的分辨率）、JPEG 品质或 ZIP 无损、转换为工作中的 CMYK、PDF/A-2b 标识；页面尺寸保持不变。截图中的 PDF/X 标准需要 Adobe 的 PDF 引擎，未提供，详见[文件工作流](FILE-WORKFLOWS.md#pdf-预设1661)。
- **预设管理器**：齿轮图标与下拉箭头；预设类型下拉显示 Ctrl+1 至 Ctrl+5 并响应这些快捷键；齿轮菜单按类型命名复位／替换项，复位前询问替换或追加；载入、存储设置、重命名、删除带 Alt 快捷键；重命名使用带缩略图的名称对话框（等高线名称、画笔名称、图案名称等）。

## 验证

- Release 构建零警告、零错误。新增核心测试：`CustomColorProfilesTests`（自定 RGB 在两个引擎下保持白和中灰；自定 CMYK 纸白无墨、黑色和总量限墨、红色用品红和黄；黑版产生档位递增；网点曲线插值）、`PdfPresetTests`（最小文件大小明显更小且页面尺寸不变、阈值以下不缩减、PDF/A 标识、预设读写和无效文件拒绝）、`SkyReplacementTests`（找到天空、移动边缘、合成与前景光照、翻转与亮度）、`ContentFillOptionsTests`（只从取样区复制、颜色适应、新图层只填选区、旋转缩放镜像、自动／矩形取样区及其放宽）。
- `--edit-dialog-checks` 增加：自定 RGB／CMYK／网点增大／灰度系数／油墨颜色窗口，自定 CMYK 与自定 RGB 确定后生成对应模型的 ICC；菜单页隐藏并着色一项后，菜单中出现“显示全部菜单项目”，旧版还原快捷键交换还原与切换最终状态；PDF 预设编辑窗口；内容识别填充工作区出现预览，“应用”在新图层上只填选区；天空替换找到天空、载入默认天空、预览，确定后生成含 3 个图层的天空替换组。
- 未验证：内容识别填充和天空替换在大尺寸照片上的速度；天空自动检测在复杂天际线（树枝、电线）上的效果；Windows 10、扫描仪与实体压感笔。

沿用既有面板规范：普通窗口 32 DIP 标题栏；菜单和提示显示同一实际快捷键；跨面板交互取消滚动冲突。此前 imagegen 生成的图标参考稿保留为历史记录，运行时使用统一图标体系；本次没有重新生成素材。
