# Windows 1.5.12.1 Preview

2026-10-29。本次补齐补充截图中的文件菜单导入与批量图层操作。界面继续使用 Compositor 的主题、字体和按钮，浮窗按钮不变。并未完成全部截图高级功能，范围和限制见 [文件工作流](FILE-WORKFLOWS.md)。

- 脚本菜单接入删除所有空图层、拼合像素图层蒙版和图层效果，并验证撤销／重做。空底层仍被剪贴图层依赖时保留；GIF 首帧透明时不会删除整个动画；锁定层得到保护，禁用蒙版不会意外擦除像素；GIF 蒙版应用到所有帧且保留帧顺序、时间和选择；效果烘焙保留整体不透明度和隐藏状态。
- 导入菜单接入变量数据组、视频帧到图层、注释和 WIA。视频支持范围、帧率、采样间隔、尺寸上限、帧动画和取消；低分辨率视频不放大；导入后保存像素，不再依赖源视频。
- 新增 Compositor 注释文件导入／导出，保留作者、内容、位置和颜色，导入重建 ID，可撤销。
- 新增 DICOM 单／多帧文件导入，生成 16 位文档；合成测试验证各帧像素不同，取消不生成部分文档。
- WIA 接入 Windows 原生扫描界面及无设备／取消处理；没有扫描仪硬件验收，不能宣称已在所有设备上验证。
- 联系表 II 补齐四种颜色模式、8／16 位、ICC、真实字体样式、按文件夹分页、分辨率单位和物理间距。16 位绘制使用浮点图像，不先降到 8 位；预设保留样式、模式、单位和自动间距。
- 本地与仓库交接记录分别保存实现、验证和未完成事项。控制读取范围以降低系统会话压缩后的上下文损失；没有修改或声称关闭系统自动压缩。

依赖和边界：视频需要 PATH 中的 FFmpeg 与 ffprobe；帧动画上限 100 帧，纯图层上限 1000 帧，并受内存预算限制。DICOM 最多 256 帧，使用 ImageMagick 解码，不保留医学元数据。注释为本程序 JSON v1，未实现 Adobe/PDF/FDF 注释格式。动画效果保持非破坏性，不会仅烘焙当前帧。组蒙版／组效果、动画效果烘焙及完整脚本事件管理器仍未完成，详见交接记录。
