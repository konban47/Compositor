# Windows 1.6.6.0 Preview

2026-11-10。本版按 Photoshop 截图重排“编辑”菜单的对话框，并合并上游 main `02e53989dc499d749d83f33023ff249de1c7b4eb`（1.6.6）。版本号与上游 1.6.6 对齐。

## 编辑菜单

逐张核对 `编辑菜单截图` 的 66 张截图后，按截图重排下列窗口，控件保持本项目样式，内容一屏放得下。新增 `--edit-dialog-checks`，在中英文下逐个打开这些窗口、截图并检查不需要滚动。

- **编辑菜单**：顺序与截图一致；“拷贝的图层”移出编辑菜单（仍在“图层 › 新建”）；“变换”子菜单的分隔与截图一致；“清理”的“视频高速缓存”单独一组。
- **填充**：内容为前景色、背景色、颜色…、内容识别、图案、历史记录、黑色、50% 灰色、白色，分组与截图相同；“混合”组的模式改为 Photoshop 的全部 29 种（含溶解、背后、清除、深色、浅色），并支持保留透明区域。选“颜色…”时直接打开拾色器；选“内容识别”时使用内容识别填充。“历史记录”需要先在历史记录面板设置源，否则不可选。
- **描边**：宽度、颜色色块（打开拾色器）、内部／居中／居外、混合（同样 29 种模式、不透明度、保留透明区域）。没有选区时沿图层边界描边。
- **查找和替换文本**：查找内容、更改为；搜索所有图层、向前、区分大小写、全字匹配、忽略重音；完成、查找下一个、更改、更改全部、更改/查找。查找下一个会选中找到文字的图层并显示位置；忽略重音时“Café”能匹配“cafe”。
- **图案名称、形状名称、画笔名称**：左侧显示要定义的内容的缩略图，名称默认按已有数量编号（如“图案 10”），画笔下方显示大小。
- **去除反射**：先选“创建单独的反射图层”和品质（预览／标准／最佳，对应发送的最长边 1024／2048／原尺寸），再进入生成式请求。勾选单独图层时，被去除的部分另存为“反射”图层（线性减淡，默认隐藏），显示它即可还原原图。
- **自动对齐图层**：六种投影带示意图、镜头校正、说明框，与截图相同。Compositor 只能通过平移对齐，“透视”“拼贴”“圆柱”“球面”显示为不可用；没有相机元数据，“晕影去除”“几何扭曲”不可用，说明框写明原因。
- **自动混合图层**：全景图／堆叠图像带示意图，无缝色调和颜色、内容识别填充透明区域。全景图按每张图离边缘的距离加权，接缝渐隐；无缝色调把各图的平均颜色调到一致；内容识别填充补齐空角。
- **管理缺失字体**：警告图标、说明、每个缺失字体一行替换选择（不替换、文档已用字体、默认字体）、底部复选框和取消／确定。
- **转换为配置文件**：从“导出 ICC TIFF”改为与 Photoshop 一致的就地转换：源空间、目标空间（工作中的 CMYK／灰度／RGB、Lab 颜色、RGB／CMYK／灰度配置文件）、转换选项（引擎、意图、黑场补偿、仿色、拼合图像以保留外观）、预览。RGB 之间转换像素并换上新配置文件；换颜色模式时走图像模式转换。

## 上游移植（1.6.5–1.6.6）

- **描边效果各方向等宽（上游 `8e6bca6`，#335）**：图层样式的描边改用欧氏距离，圆形的描边内外都一样粗，方形的外描边转角变圆。原有测试按新行为更新。
- **导出为记住格式（上游 `2facf90`）**：导出为打开时沿用上次的格式，跨启动保留；存储对话框以文档名和所在文件夹开始。上游把 ⌥⇧⌘S 改给导出为；Windows 版沿用 Photoshop 的 Alt+Shift+Ctrl+S 存储为 Web 所用格式，未改。
- 不适用于 Windows：Liquid Glass 滑块、拾色器的 macOS 样式（Windows 版拾色器按 Photoshop 截图布局，见 1.6.4.0）、Metal 描边和 GPU 笔画回退。

以下窗口本版没有按截图重做，仍是原布局：
