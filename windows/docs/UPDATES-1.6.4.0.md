# Windows 1.6.4.0 Preview

2026-11-06。本版按 Photoshop 截图重排“文件”菜单的全部对话框，修好浮窗 ≡ 菜单，加入底部停靠区，让左侧工具栏随窗口高度压缩，修好窗口大小记忆，并合并上游 main `3e81af3fb8aeb379173a4efbae5dd0edd95023b8`（1.6.4）。版本号与上游 1.6.4 对齐。

## 文件菜单与对话框

逐张核对 `文件菜单截图` 的 76 张截图后，按截图重排窗口、分组、工具栏和按钮，控件保持本项目样式。下面这些窗口内容都放得下，不再需要滚动，自检在中英文下都会检查这一点。

- **文件菜单**：顺序改为与截图一致；新增“打开为”“快速导出为 PNG”“打印”“打印一份”。“导出”“自动”“脚本”“导入”子菜单同样重排。打印把合成图交给 Windows 的打印对话框。
- **批处理**、**创建快捷批处理**：左侧“播放”“源”“错误”，右侧“目标”和“文件命名”，附命名示例。“目标”可选“无”（结果作为文档打开）、“存储并关闭”（存到源文件旁边，不覆盖已有文件）和“文件夹”。“错误”可选日志文件位置。动作分“基本调整”和“图像大小”两组。
- **图像处理器**：独立窗口，分四个编号步骤。支持 JPEG（品质 0–12）、PSD、TIFF（LZW 压缩）、调整大小、运行动作、版权信息、包含 ICC 配置文件、保持文件夹结构。
- **PDF 演示文稿**、**Photomerge**、**联系表 II**、**图像统计**、**载入图层**、**镜头校正**：分组标题嵌在边框上；列表和右侧按钮对齐；没有选中时“移除”“复制”“按名称排序”变灰。联系表的文件夹来源改为“选择…”加路径，切换“包含子文件夹”时重新读取；默认分辨率改为截图的 118.11 像素/厘米。镜头配置文件改为“选择…”打开可搜索的列表，“文件类型”和“边缘”的顺序与截图相同。
- **限制图像**、**条件模式更改**、**优化文件大小**：按截图布局，确定和取消在右侧。优化文件大小可选“自动选择 GIF/JPEG”。
- **拾色器**：重做。字段和色带可按 H、S、B、R、G、B、L、a、b 九种模式显示；同时显示 HSB、Lab、RGB、CMYK 和十六进制；新旧颜色对比，单击“当前”回到原色；“只有 Web 颜色”；“添加到色板”写入色板面板并保存；“颜色库”提供 Web 安全色。CMYK 数值用默认印刷配置文件换算。
- **导出为**：三栏布局。左侧“缩放全部”可添加多个尺寸和后缀，一次导出多份；中间预览和双联；右侧格式、品质滑块、图像大小（含重新取样）、画布大小、元数据、色彩空间。
- **存储为 Web 所用格式**：左侧工具（抓手、切片选择、缩放、吸管、吸管颜色、切换切片）；提示条；原稿／优化／双联／四联标签；每个窗格下显示大小、下载时间、仿色和调板，≡ 可选网速；底部缩放菜单和 R/G/B/Alpha/十六进制/索引读数；预览到浏览器；右侧预设（12 项）、优化菜单、颜色表菜单（新建、删除、全选、Web 安全色筛选、锁定、映射透明、转换 Web 调板、排序、载入、存储）、图像大小（百分比）、动画。新增调板“可选择”“Mac OS”“Windows”，新增“损耗”和透明度仿色“数量”。“完成”记住设置，“取消”不记住。
- **脚本事件管理器**、**输出设置**：原有布局已与截图一致，未改动。

## 浮窗与停靠

- **≡ 无反应（修复）**：这是 1.5.14.0 引入的缺陷：`DockButton` 的点击处理把事件标记为已处理，后追加的打开菜单处理因此永远收不到。当时的自检直接调用菜单函数，没有真正点击，所以没发现。现在菜单逻辑就是按钮的动作，自检改为真实点击。
- **面板菜单**：图层（新建图层、复制、删除、新建组、合并可见、拼合图像）、通道（分离通道、通道打包）、历史记录（创建快照、从当前状态新建文档）、字符和段落（原排版菜单）有自己的命令；所有面板都有关闭、浮动和“停靠到底部”。
- **底部停靠区**：画布下方新增停靠区，时间轴和测量记录默认在此，可拖动分隔条调高度，折叠后只留一条，可拖到画布底边停靠。工作区保存和恢复它的内容及高度。仅显示画布模式下隐藏。
- **面板首次打开的位置**：路径并入图层组；调整并入属性组；颜色、色板、渐变、图案在停靠栏顶部成组；字符和段落、字符样式和段落样式、画笔设置和画笔等成对面板互相合并；其余面板在停靠栏左侧浮动，逐个错开，并使用各自的默认大小。复位工作区后重新按此规则。内置工作区把面板放进停靠栏。
- **折叠的浮动面板**显示图标加名称。

## 工具栏与窗口

- **左侧工具栏**：可用高度来自实际布局。窗口变矮时依次是单列改双列、按钮高度从 36 缩到 24、底部按钮收紧，最后才把末尾工具收进 » 菜单。任何高度下都没有按钮被窗口底边遮住，自检从 1000 走到 330 逐级验证。
- **窗口大小记忆（修复）**：设置读取函数 `ToolDefaults.Kept()` 只保留视图开关，把窗口大小和“本版本已铺满”标记都丢了，所以每次启动都是默认大小。现已修复，并保存位置和最大化状态。位置所在的显示器不在时回到主屏居中。安装或更新后首次启动以最大化窗口打开。

## 无反应按钮审计

新增 `ButtonAudit`：设置 `COMPOSITOR_BUTTON_AUDIT` 后运行界面自检，记录所有没有点击逻辑的按钮。全部 24 组自检走到的按钮里，只有 Web 窗口的“原图”说明条（已随重写移除）和一个测试桩。没有被自检打开过的窗口不在此范围内。

对话框里有些复选框是 Compositor 的固定行为，显示为不可改并附说明：“覆盖动作中的打开命令”“禁止显示文件打开选项”“禁止颜色配置文件警告”“最大兼容”。

## 上游移植（1.6.4）

- **选区工具栏（上游 `9986d12`、`70bc6d6`）**：矩形、椭圆、套索、魔棒、快速选择和对象选择的选项栏增加“大小”和扩展、收缩、羽化三个图标按钮，共用一个数值，默认 5，范围 1–500（羽化上限 250）。“选择 › 修改”的默认值同步。
- **羽化累加（上游 `9986d12`）**：重复羽化按数值相加，不再按平方和；扩展和收缩使用斜接转角，矩形保持直角。
- **状态栏羽化（上游 `820b8fa`）**：选区尺寸后显示“· 羽化 N px”。
- **胶囊按钮（上游 `70bc6d6`）**：扩展／收缩／羽化、水平／垂直翻转各合成一个胶囊。
- **色板（上游 `f327645`、`a376ade`）**：色板统一为圆角方块和细描边；工具栏底部的复位和互换移到色板下方，复位是对角分割的小方块，点击区域变大。
- 上游工具栏去掉单位、效果面板对齐的改动：Windows 工具栏和面板布局本来就不同，只移植了色板样式。

## 与 Photoshop 的差异

- 批处理的动作组只有“基本调整”和“图像大小”，截图里的“主体和背景”“创意效果”“参考线”“导出”是 Adobe 自带动作，这里没有。来源没有“导入”“Bridge”。
- 文件菜单没有 Bridge、Adobe Stock、Firefly、裁剪并拉直照片、画板导出、颜色查找表、路径到 Illustrator。
- “颜色库”是 Web 安全色，不含 PANTONE 等色库。
- 联系表的自动间距数值与 Photoshop 不同。下拉列表里的分隔线未复刻。

沿用既有面板规范：普通窗口 32 DIP 标题栏；菜单和提示显示同一实际快捷键；跨面板交互取消滚动冲突。此前 imagegen 生成的图标参考稿保留为历史记录，运行时使用统一图标体系；本次没有重新生成素材。

上游 2026-11-06 核对 main 为 `3e81af3fb8aeb379173a4efbae5dd0edd95023b8`，所有适用于 Windows 的上游提交均已移植。完整 UI 对照基线为 `3e81af3fb8aeb379173a4efbae5dd0edd95023b8`（`UPSTREAM-UI.json`）。
