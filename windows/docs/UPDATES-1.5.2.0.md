- 按本次录像调整停靠交互：拖动标签分离单面板、标题移动整组、边缘新建列／行、标签合并排序、空白区自由浮动和 Esc 还原。浮窗不再有“停靠面板”按钮或返回固定位置菜单。
- 停靠位置使用蓝色细线与柔和模糊光晕；列边缘提示覆盖完整高度。工具栏靠近编辑区左侧或右侧均显示提示并能停靠，标题仅保留缩略／展开和关闭按钮。
- 两列独立缩略／展开，各自恢复原宽度，不改变相邻列。两列均缩略时保留相邻图标栏。点击图标临时展开，拖动可重新分组。工作区保存各列状态和工具栏左右位置，兼容旧版整体折叠设置。
- 修正图标按钮默认最小尺寸及水平／垂直内容对齐，确保高亮区域内居中；保留现有 35 个主题图标和工具栏图案。
- 移植上游 `735c2cc` 自适应 Camera Raw Shadows：区域对数亮度、快速引导滤波、纹理参考亮度和分段系数，处理顺序为高光后、白色色阶前；按原图尺寸选择小图／普通图系数。Windows 预览使用完整图层像素，缩放 API 同样支持原图尺寸选择。保留既有浮点源与选区处理路径。
- 移植 `a3a0e29` RAW 显影窗口“Camera Raw…”入口：导入完成后选择新图层打开滤镜；多文件置入先完成批次和置入，再打开所选 RAW 图层。取消显影不导入，普通显影不自动打开滤镜。
- README、窗口／工作区手册、上游来源清单、包内文档、版本号和数据哈希同步更新。项目格式仍为 Windows v21；OpenCL 迁移仍暂缓，继续使用 Skia。
