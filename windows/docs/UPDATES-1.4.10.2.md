# Windows 1.4.10.2 Preview

2026-10-12。本次基于 `0add0874ca2cb8063681f318514a1f86614b8d79`。重新查询上游 HEAD/main，仍为 [f5ae5bad0b25b32dda9f254e62d2f07f59478698](https://github.com/robbietilton/Compositor/commit/f5ae5bad0b25b32dda9f254e62d2f07f59478698)，没有新增上游提交需要合并。

## 修改

- 首选项按参考图整合为 19 个分类，增加中英文搜索、上一项／下一项、草稿验证、取消、重置及高级图形弹窗。接入主题、光标、工作区、历史、恢复副本、导出、单位、参考线、文字与性能设置，详见 [首选项与接入审查](PREFERENCES.md)。
- 钢笔工具族显示笔形光标，曲线控制柄有连接辅助线。鼠标移动不再反复使整张图像及导航器缓存失效。
- 支持的图层通过不可变图像缓存与 Skia 场景在 GPU 上重放；修改图层才重建场景，平移缩放复用资源。复杂样式、调整层和高位深等继续使用参考合成器，保存／导出保持原管线。
- 整理截图对应的图层菜单，接入新建、填充、蒙版、智能对象、栅格化、排列、形状布尔运算、切片和修边；增加八类可编辑调整层。功能与 Photoshop 的差异见 [图层菜单说明](LAYER-MENU.md)。
- 新增调整层参数需要 **Windows 格式 v19**；其余项目按最低必要版本保存。首选项本身不写入项目文件。
- OpenCL 迁移计划暂缓。本版继续使用 Skia，OpenCL 与 30 位显示入口禁用并说明实际边界，不声称已迁移或已支持 HDR 显示。

## 验证

- Release 构建将警告视为错误，**1132 项核心测试**；覆盖场景与参考合成像素比较、混合／蒙版／缓存生命周期、排列、形状布尔、智能对象拆分外观与撤销、高位深蒙版、扩展调整层验证／往返及最近文件上限。
- CI 配置 **17 组英文、11 组中文界面检查**，新增 `--preferences-checks`，打包后的程序执行 11 组中文检查并验证安装／卸载。新增首选项搜索、草稿取消、保存重载、无效输入、恢复副本及手动保存并行等用例。
- Windows 11 / RTX 4080 上，本地 4697×4549、45 层 PSD：解析约 520 ms，到首次绘制回调约 730 ms，60 次平移／缩放回调中位数 9.40 ms、P95 16.57 ms，实际 GPU 上下文为真，场景只构建一次。测试文件未上传；数值不是显示器呈现 FPS 或跨设备性能承诺。
- 主题、快捷键、菜单、格式、版本、使用说明、包内文件和 CI 文档检查同步。Windows Server 2022／2025 CI 不替代 Windows 10 实机、多屏、数位板或真实输入法人工验收。
