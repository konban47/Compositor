# 编辑菜单与首选项

适用于 Windows **1.6.6.5 Preview**。本次截图展示的是 Photoshop 的“编辑”菜单；原有“图像”菜单保留在 [图像与属性手册](IMAGE-WORKSPACE.md)。以下说明实际行为及平台边界。

## 历史与粘贴

撤销、重做和切换最终状态使用当前文档历史。渐隐按指定不透明度混合最近操作前后的同尺寸像素，不改变图层变换；不适用的操作会提示。清理剪贴板、历史或全部需要确认，清理不能撤销。没有视频缓存，入口置灰。

选择性粘贴包括系统剪贴板纯文字、原位粘贴、贴入和外部粘贴。原位粘贴保留复制图层坐标；贴入／外部粘贴要求目标选区，生成未链接的图层蒙版，保留羽化覆盖率并与原有启用蒙版相乘。跨文档图层、组、样式和高位深资源仍用内部剪贴板复制。纯文字不继承源格式。粘贴及蒙版是一个撤销步骤。

## 文字、填充与描边

- 查找替换可选大小写、整词和全部文字层；替换保留图层级文字样式，清除旧的逐字符字体／颜色运行，以免索引错位。锁定图层不会修改。
- Windows 拼写检查调用本机安装的语言字典，可修改语言标记、查看建议并替换；字典不可用时提示。中文逐字校对、在线语法服务及 Adobe 字典未提供。
- 填充支持前景、背景、自定颜色、图案、黑、白、50% 灰；描边支持宽度、内侧／居中／外侧。两者提供不透明度、七种混合模式和保留透明度，遵守图层锁定、RGB 通道和选区。
- 内容识别填充继续使用本地修复实现。生成式填充把图像交给用户配置的图像 API，将返回结果置于新图层并用原选区蒙版限制可见范围；请求不传 Adobe 专有选区协议。

## 变换、对齐和图像组合

自由变换及缩放、旋转、斜切、扭曲、透视、变形复用置入工具栏。Enter 确认、Esc 取消，应用后为一个历史操作。“再次”重复最近确认的几何变换；不重放网格节点编辑。分割变形仅在活动网格变形时可用。

操控变形建立 9×9 网格：单击添加图钉，拖动图钉改变局部形状，Alt 单击移除；Enter 确认、Esc 取消。使用距离加权网格插值，没有 Photoshop 骨架、深度遮挡与碰撞解算。网格变形与操控变形当前输出 8 位栅格结果，文字／形状会栅格化。

内容识别缩放通过 ImageMagick Liquid Rescale 接缝裁减改变所选层尺寸，并调整图层边界；大幅缩放可能改变人物或重复纹理。没有 Photoshop 皮肤保护／保护通道模式。

自动对齐需要至少两个像素层，按层堆栈中的第一层做亮度相关平移配准，可限制最大位移；不自动解算旋转或透视。自动混合提供均值堆栈和局部对比度加权焦点堆栈，新增结果层并隐藏源层，源层仍可编辑。操作最多处理 3200 万源像素；不是全景接缝或 Adobe 景深合成引擎。

天空替换使用事先选出的天空范围和本地替换图像，生成独立蒙版层，可继续画蒙版。去除反射打开带有参考图和去反射提示的生成式工作区，需要用户已配置的 API；没有内置 Adobe 去反射模型。

## 预设、菜单与首选项

Ctrl+K 打开常规首选项，Ctrl+Shift+K 打开颜色设置，Ctrl+Alt+Shift+K 打开键盘快捷键，Ctrl+Alt+Shift+M 打开菜单设置；可在快捷键窗口更改。

定义画笔记录参数和当前内容的灰度笔尖，黑色为实心、白色为空；定义图案保存像素图案，定义自定形状保存所选矢量路径。预设管理器共享画笔、图案、形状与等高线，支持多选、重命名、删除、JSON 载入、替换、复位、导出及五种显示方式；修改立即保存并刷新工具弹出列表。每图最大 2048×2048，单文件上限 32 MB、最多 500 项；不读取 Adobe ABR／PAT／CSH。

PDF 预设入口设置扁平单页 PDF 的默认分辨率及 JPEG 质量，不实现 Adobe PDF joboptions、分页或印前标准预设。远程连接配置 OpenAI 兼容图像服务的 API 地址和密钥，凭据的保存方式见 [工作区手册](WORKSPACE.md)，不实现 Photoshop 远程控制协议。

菜单窗口可隐藏／恢复命令，配置不依赖界面语言。“菜单”入口始终保留以便恢复。Ctrl+K 现在打开 19 分类的统一首选项，包含搜索、草稿确定／取消／重置、高级图形设置及已有配置入口；主题、光标、历史、恢复、导出、单位、文字与性能等实际接入及限制见 [首选项手册](PREFERENCES.md)。OpenCL 迁移暂缓，继续使用 Skia；暂存盘换出和 30 位显示未实现。

这些配置保存在用户设置目录的 `preferences.json`，预设保存在 `presets.json`，不写入 `.comp`，不需要项目格式升级。

## ICC、OpenColorIO 与 HDR

编辑工作空间仍是 sRGB／扩展 sRGB。颜色设置采用工作空间、策略、转换和高级控制布局，支持 ICC 载入/存储、自定灰度/网点曲线、预览取消与持久保存。默认使用独立 ACE 兼容 CMM，另可选 Little CMS 和 Microsoft ICM；不宣称复刻 Adobe 专有算法的逐位结果。Creative Cloud 同步已移除。

“指定配置文件”提供不管理、工作空间、指定 ICC 三种模式，在最终合成结果上预览解释差异，保留素材像素，支持取消、撤销与重开恢复；“转换为配置文件”导出嵌入 ICC 的 16/32 位 TIFF。静态图像导入、文档输出配置、CMYK 校样和常规导出已接入颜色方案。OpenColorIO 2.4.2 随包提供，设置窗口读取实际配置、角色和颜色空间；EXR/HDR 默认空间导入及显式浮点转换均使用真实 OCIO 处理器。配置/空间和 ICC 输出信息按需写入 v28，重开项目不重复转换。具体格式覆盖、精度和功能边界见 [颜色管理手册](COLOR-MANAGEMENT.md)。


EXR／Radiance HDR 导入和 EXR 导出保留支持路径中的高光；HDR 转 16 位会裁切并量化。JPEG／PNG 为常用格式，PDF／TIFF／EXR 在“更多”中。复杂图层效果和网格变形的精度边界见 [图像手册](IMAGE-WORKSPACE.md)。

## 1.6.6.1 窗口

按 `编辑菜单截图` 补齐 1.6.6.0 尚未重做的窗口，详见[更新记录](UPDATES-1.6.6.1.md)。

- **内容识别填充…**：打开独立工作区。左侧为取样画笔、套索、抓手和缩放；选项栏切换添加／减去和画笔大小（按住 Alt 临时反向）。取样画笔修改绿色的取样区域，套索修改要填充的区域。右侧面板：取样区域叠加（显示、不透明度、颜色、表示取样区域或排除区域）、取样区域选项（自动、矩形、自定，对所有图层取样）、填充设置（颜色适应：无／默认／高／非常高；旋转适应：无／低／中／高／完全；缩放；镜像）、输出设置（当前图层、新建图层、复制图层）。预览面板实时显示结果并可缩放。“应用”填充后留在工作区，“确定”填充并关闭，每次填充为一个撤销步骤，编辑后的填充区域保留为选区。自动和矩形取样区会避开所选图层的透明像素并按需放宽。“滤镜 → 内容识别填充”仍按默认设置直接填充。
- **天空替换…**：没有选区时自动找到天空（明亮、平滑、与顶边相连的区域），有选区时以选区为天空。天空库的默认天空（蓝天、盛景、日落）由 Compositor 首次打开时绘制；齿轮菜单提供获取更多天空（导入图像、导入预设）、创建新天空组、重命名天空、删除天空、显示最近使用的项目、追加默认天空、导出选定的天空（`.skies`，ZIP 包）。对话框不阻塞文档：天空移动工具拖动天空，天空画笔（Alt 减去）扩大或缩小天空，抓手和缩放作用于画布。输出到“新图层”时生成“天空替换组”（天空图层带蒙版、前景光照图层为正片叠底或滤色、前景颜色图层为颜色模式），“复制图层”时生成一个合成后的图层。“下载免费天空”需要 Adobe 服务，未提供。
- **颜色设置…**：设置、工作空间、色彩管理方案、转换选项、高级控制和说明的布局与截图一致；指针移到任一控件上，说明区显示其含义。各工作空间下拉菜单含自定、载入、存储和“其它”分组。Creative Cloud 同步不适用于 Windows 版，原位置改为说明这些设置的作用范围。引擎为 Little CMS、Microsoft ICM 和 Compositor 自己的 ACE 兼容引擎，不是 Adobe 的 ACE。
- **自定 RGB／自定 CMYK／自定网点增大／自定灰度系数**：见[颜色管理](COLOR-MANAGEMENT.md#自定配置文件1661)。
- **键盘快捷键…／菜单…**：同一个“键盘快捷键和菜单”窗口的两个标签页。快捷键页按“应用程序菜单”（按文件、编辑等菜单分组）或“工具”列出；组可存储、基于当前组新建或删除；“使用旧版还原快捷键”把 Ctrl+Z 交给切换最终状态、Ctrl+Alt+Z 交给还原；“使用旧版通道快捷键”改为 Ctrl+~ 和 Ctrl+1／2／3（实际像素改为 Ctrl+Alt+0）；右侧为接受、还原、使用默认值、添加快捷键、删除快捷键和摘要（导出 HTML 列表）。菜单页列出全部菜单项目，可点按眼睛隐藏或给项目着色；有隐藏项目的菜单底部出现“显示全部菜单项目”，选择后在菜单关闭前显示全部项目。Compositor 的面板菜单和任务空间没有可指定快捷键的命令，因此“快捷键用于”只提供应用程序菜单和工具。
- **PDF 预设…**：见[文件工作流](FILE-WORKFLOWS.md#pdf-预设1661)。
- **预设管理器…**：齿轮菜单（仅文本、小／大缩览图、小／大列表、复位、替换、追加默认预设）改用齿轮图标；预设类型可用 Ctrl+1 至 Ctrl+5 切换；复位前询问替换或追加；重命名使用带缩略图的名称对话框（等高线名称、画笔名称等）。

## 1.6.6.2 修正

详见[更新记录](UPDATES-1.6.6.2.md)。

- **定义画笔预设…／定义图案…／定义自定形状…**：以前没有选区时只在状态栏提示，看上去“没有反应”。现在与 Photoshop 一致：没有选区时以整个画布定义画笔或图案（超过 5000／4096 像素按比例缩小）；有选区时取选区范围并保留选区边缘的透明度。自定形状取所选形状图层的路径，或非空的选区轮廓；缺少可用内容时弹出说明框。
- **内容识别填充…**：选择取样画笔时，指针变为与画笔大小相同的圆形，中间的“+”或“−”表示单击会增加还是删除取样区域（按住 Alt 时随之变化）。顶部选项栏随工具变化：取样画笔为添加／减去和大小（⌄ 打开滑块）；套索为新选区、添加、减去、交叉、羽化、消除锯齿、扩展／收缩及数量、复位填充区域（拖动时 Shift 添加、Alt 减去、两者交叉）；抓手为 100%、适合屏幕、填充屏幕；缩放为放大／缩小、细微缩放（左右拖动连续缩放）和同样三个按钮。右下角“取消”不再被遮挡，取样区域选项按钮的文字上下左右居中。填充先用 PatchMatch 在完整 5×5 区块上细化两轮，再按重叠区块投票，规则纹理和渐变的接缝更少。
- **颜色设置…**：RGB、CMYK、灰色、专色下拉菜单中的“自定…”“载入…”“存储…”“其它”等操作项现在显示中文；ICC 配置文件名称保持原文。
