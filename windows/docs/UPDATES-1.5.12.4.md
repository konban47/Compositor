# Windows 1.5.12.4 Preview

2026-10-30。本版移植上游 main `14055459feb47a2bd69ef99c1983f8155bea4e75` 中适用于 Windows 的 5 项改动，在本机编译及验证。版本号、手册、打包脚本和安装器统一为 1.5.12.4；完整截图任务仍有待办，不能将本版理解为全部功能完成。

- **16 位图层保持位深**（上游 `5de396b`）：Windows 原本已在每次编辑结束时恢复 16 位样本，但编辑改变图层尺寸时（如选区超出图层边界的内容识别填充）会把整层降为 8 位。现在按新旧像素网格的整像素偏移对齐，未改动的像素保留原 16 位样本；重采样、非整像素平移或旋转时整张结果按原位深写入。只有“转换为 8 位图层”会降为 8 位。
- **多选转换位深**（上游 `de0a43d`）：“转换为 16 位图层／转换为 8 位图层”作用于所有选中图层及选中组内的图层，合为一步撤销，并加入“图层”菜单。右键菜单只显示会改变某个选中图层的项，位深不一时两项都显示。
- **多选剪贴蒙版**（上游 `d693a2a`）：创建／释放剪贴蒙版作用于所有选中图层，从下往上剪贴到最下方选中图层之下的那一层；任一图层无法剪贴时整组不改变。可用状态在不修改文档的记录副本上判定。隐藏／显示图层此前已支持多选，未改动。
- **逐图层导出 PNG**（上游 `0673a4a`）：“快速导出为 PNG”把每个选中图层单独渲染（保留所在组的不透明度与蒙版及剪贴到它的图层），裁切到可见像素，以图层名命名；多个图层导出到所选文件夹，同名文件先确认替换，重名图层自动编号，Windows 保留名（CON、NUL 等）加下划线，空图层跳过并提示。成功后触发脚本事件“导出文档”。此前该命令把多个图层合并为一张图。
- **选框空格移动**（上游 `fc3c81a`）：拖出矩形或椭圆选框时按住空格，选框保持大小随指针移动，角点对齐整像素，不切换到抓手工具；松开空格后继续调整大小。
- 无需移植：`42eb9b2`（Image Size 拖动上限）。Windows 图像大小对话框没有拖动调值，输入已按文档尺寸上限校验。
- 本机验证：Release 构建零警告、零错误；核心测试 **1555 项通过、2 项默认跳过**，新增 `LayerDepthTests`、`SelectedClippingTests`、`LayerPngExportTests` 共 12 项。中英文 `--file-workflow-checks`、`--interaction-checks`、`--windows-checks`、`--selection-options-checks`、`--layer-style-checks`、`--image-workspace-checks` 通过，各次使用独立设置目录；选框检查新增空格移动与不切换抓手的验证。
- 未验证：多图层导出的文件夹选择与替换确认依赖系统对话框，没有自动化检查；内容识别移动、粘贴等其他 8 位编辑路径未逐一补测。

上游 2026-10-30 核对 main 为 `14055459feb47a2bd69ef99c1983f8155bea4e75`；Volumetric Light（`1405545`）与 Rim Light（`b9a0ed8`、`97c3b3f`）尚未移植。完整 UI 对照基线仍为 `2d75d9172835e1dd6111cb2b659958ec33fa5abf`（`UPSTREAM-UI.json`）。
