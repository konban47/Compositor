# Windows 1.5.12.2 Preview

2026-10-29。本版将 Claude 交付的脚本事件管理器补丁接入 Windows 项目，并在本机修复、编译及验证。版本号、手册、打包脚本和安装器统一为 1.5.12.2；完整截图任务仍有待办，不能将本版理解为全部功能完成。

- 新增“文件 ▸ 脚本 ▸ 脚本事件管理器…”。布局参照截图：顶部启用开关和关联列表，下方选择事件、脚本或动作，右侧完成、移去、全部移去、添加。主题、字体、按钮沿用 Compositor，浮窗按钮不变。
- 事件：启动应用程序、新建文档、打开文档、开始存储文档、存储文档、关闭文档、打印文档、导出文档、全部；“添加事件…”可选择任一菜单命令作为事件。
- 内置脚本由本程序原生实现：Clean Listener（清除事件日志）、显示相机制造商、打开为图层、调整大小（1920 × 1080 内，不放大）、存储额外 JPEG、更新文件信息、警告如果是 RGB、欢迎。“基本调整”动作组提供与批处理相同的 6 个动作。
- 修改文档的脚本和动作各为一个历史步骤，可撤销／重做；在对话框中关闭窗口或按 Esc 会放弃改动，按“完成”才会保存。设置保存在设置目录的 `script-events.json`（版本 1），重启后重新载入；运行记录写入 `script-events.log`。
- 限制：没有 ExtendScript／JavaScript 解释器，“浏览…”选择的外部 JS/JSX 会被明确拒绝，不会显示为可运行。本程序无打印命令，“打印文档”不会触发。Web 导出和图层导出暂不触发“导出文档”。“全部”不包含添加的菜单命令事件。
- 修复原补丁的 `LayerTransform` 类型歧义；项目文件夹和 manifest 共用单次打开事件，PSD 画板与 PDF 页面分别派发；失败打开与图像置入不派发打开事件。关闭主窗口按文档派发，关闭同文档的额外视图不重复派发。
- 独立事件在异步脚本提示后依次处理，脚本自身触发的事件不会递归执行。保存前后事件纳入待完成保存状态，连续存储命令不会重复运行开始存储脚本。打开为图层只合入一次，且可单步撤销／重做。
- 本机验证：Release 构建零警告、零错误；核心测试 **1536 项通过、1 项大型内存诊断默认跳过**。中英文 `--file-workflow-checks`、`--interaction-checks`、`--windows-checks` 通过；脚本事件检查覆盖设置、菜单、取消／完成、撤销／重做、单次项目打开、异步事件排队、并发存储和窗口关闭派发。界面截图核对了空列表与已添加关联状态；自动化不等同于全部原始参考图人工验收。
