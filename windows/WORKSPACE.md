# Windows 工作区使用说明（1.4.9.4）

1.4.9.4 的工具光标、工作区网格和 19 个新增工具见 [选区、修饰与辅助工具](PROFESSIONAL-TOOLS.md)。

1.4.9.3 新增的置入工具栏、变形菜单、跨文档复制、修饰／钢笔／直排工具及统一图标见 [编辑工具手册](EDITING-TOOLS.md)。

入口均来自当前 Windows 界面；菜单和快捷键可从“编辑 → 键盘快捷键”查看或修改。这里的默认按键适用于画布获得焦点时，文本框输入期间不会触发工具切换。

## 全屏与视图

- **F**：切换带工具栏全屏，保留菜单、工具栏、选项栏、图层／通道与属性／历史记录。
- **Shift+F**：切换仅画布模式；**Esc** 恢复正常工作区。工具栏底部屏幕图标也提供三种模式菜单。
- **H／空格／中键**：平移。**R** 拖动旋转视图，Shift 以 15° 为单位，双击或“复位视图旋转”回到 0°。只改变观看方向，不修改图像像素。
- **Z** 单击放大，Alt 单击缩小，双击恢复 100%；滚轮缩放仍围绕鼠标。旋转视图后，图层选择、移动、绘制和缩放使用同一坐标换算。

## 自定义工具栏

“工具 → 自定义工具栏”，或左侧底部“…”菜单打开设置：

1. 在左栏拖动工具，可在组内排序或移到其他组；拖动组标题可调整整个组的顺序。放到列表下方创建新组。
2. 拖到右栏成为附加工具，仍可从底部“…”菜单选择。列表边缘拖动会滚动；也可使用右侧上移、下移、移至工具栏／附加工具、分离为新工具组按钮。
3. “恢复默认值”“清除工具”“存储预设”“载入预设”作用于当前草稿。“完成”保存并立即应用，“取消”保留原布局。导出的 JSON 可在另一台电脑载入；导入会拒绝重复／未知工具。
4. 底部五个开关分别显示附加工具、前景／背景色、快速蒙版、屏幕模式、生成式工作区。勾选“禁用工具栏中隐藏的附加工具的快捷键”后，键盘不会切换到被移出的工具；菜单仍可使用。
5. 组内工具可右键或长按约 0.4 秒展开。小三角标记工具组，列表和悬停说明显示实际快捷键。

布局文件为 `%APPDATA%\CompositorWindows\toolbar.json`；使用 `COMPOSITOR_SETTINGS_DIR` 时写入该目录。预设独立于 `.comp` 文件。

## 形状、路径、快速蒙版

- **U** 选择当前形状（初次为矩形），**Shift+U** 轮换矩形、椭圆、三角形、多边形、星形、直线、自定形状。也可从组菜单或选项栏选择。
- 在画布拖动创建形状图层，按 Shift 约束、按 Alt 从中心绘制。形状选项可设置 3–100 边、星形内半径、心形／箭头／十字／勾选／菱形预设，或输入 SVG 路径。可将当前形状／选区作为自定形状。
- **A** 在路径选择与直接选择之间切换。路径选择拖动整个轮廓；直接选择拖动锚点和贝塞尔控制手柄，双击增加锚点，Alt 单击删除。支持所选形状及矢量蒙版的 M/L/H/V/C/Q/Z 轮廓；含 SVG 弧线 A 的路径仍可显示，但不提供节点编辑。
- 任意轮廓形状使用已有 Windows v14 格式；无需新的项目格式版本。形状选项仅用于当前会话，已创建的形状随项目保存。
- **Q** 将当前选区放入临时快速蒙版；用灰度画笔、橡皮擦等修改覆盖率，再按 Q 转回选区。白色代表选中、黑色代表排除。快速蒙版可撤销，不写入 `.comp` 的 Alpha 通道列表；需要持久保存时退出快速蒙版，再“保存选区为通道”。
- 模糊／涂抹／液化组的默认快捷键由 R 改为 **K**，为旋转视图释放 R。历史记录画笔为 **Y**。

## 对齐与分布、变换、历史记录

属性面板的 W/H/X/Y 保持参考图的双列布局，链条控制宽高比例，角度、水平／垂直翻转、复位以图标表示。数值按 Enter 或移开焦点应用。图标悬停显示说明。

对齐与分布包括左右／上下／水平中心／垂直中心六种对齐、六种边缘／中心分布和水平／垂直间距分布。基准可选“自动”“所选图层”“画布”“选区”：

- 自动：单项相对画布，多项相对所选对象外框。
- 所选图层分布至少三项；画布／选区分布至少两项。选区基准需要先建立选区。
- 图层组作为整体处理；计算旋转后的外框。锁定图层或包含受保护子层的组不会移动。没有可用目标的按钮会禁用，或给出建立选区的提示。

历史记录左侧的画笔图标指定历史记录画笔源，不改变当前状态；点击状态文字仍会跳转。底部依次是从状态新建文档、创建快照、删除。面板“…”菜单还提供清除历史、非线性历史和画笔源选择。历史状态、快照及画笔源仅在会话内保存。

## 生成式工作区

从“工具 → 生成式工作区”或左侧底部图像图标打开。兼容 **OpenAI Images API 风格的同步文生图服务**：

1. 填写 API 基础地址，例如服务商提供的 `https://服务域名/v1`，也可以填写完整 `/images/generations` 地址。只接受 HTTPS；本机开发服务可使用 HTTP localhost。
2. 填写服务商实际提供的模型名和 API 密钥。尺寸与数量应在该模型支持范围内，客户端可请求 1–4 张。
3. 填写提示词并点击“生成”。可取消；请求最多等待十分钟。支持返回 `data[].b64_json`，也支持通过 `data[].url` 下载图像。
4. 选中结果后可保存 PNG、导入为当前文档的新图层、打开为新文档、重用提示词或删除结果。导入是一个可撤销步骤；不把提示词或 API 密钥写入项目。

请求采用 `POST`、`Authorization: Bearer`、JSON `model/prompt/n/size`，不强制发送 `response_format`。协议依据 [官方 Images Generate API](https://developers.openai.com/api/reference/resources/images/methods/generate)。这是协议适配，不是对所有服务商、模型、尺寸或收费政策的承诺；不支持异步任务轮询型 API、图生图编辑或局部生成填充。

连接设置保存在 `image-generation.json`。密钥默认仅存于会话内；勾选加密保存后使用 Windows DPAPI 当前用户保护。复制设置文件到另一账户不能解密密钥。下载结果不会携带 API 密钥，错误信息不会显示服务返回的原始请求或密钥。生成不会上传项目图像；点击生成会向所配置服务发送提示词，费用由服务商收取。

每张图像上限 32 MP，单次响应上限 128 MiB；窗口最多保留 12 张／256 MiB 压缩结果。关闭窗口会清除未保存结果，导入或已保存的图像不受影响。自动化测试用模拟服务验证请求、取消、预览、导入及密钥存储；没有使用用户付费 API 凭据做真实出图验收。

新增窗口、智能对象、画框／画板及截图菜单见 [图层样式手册](LAYER-STYLES.md)。Ctrl+Shift+E 为合并可见图层；旧版 PNG 导出快捷键已腾出。新图层特性使用 v15，原有工具栏、API 设置和路径格式不变。
