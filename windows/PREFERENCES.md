# 首选项、性能与设置接入

适用于 Windows **1.5.6.0 Preview**。Ctrl+K 或“编辑 → 首选项”打开统一窗口。参考截图整理为 18 个分类，并补充本应用的 Camera Raw 入口，共 19 页；中文／英文搜索会同时匹配分类、选项和说明。右侧提供确定、取消、上一个、下一个和重置。

## 保存与生效

普通控件只修改窗口中的草稿。“确定”验证后写入 `%APPDATA%\CompositorWindows\preferences.json`；取消和关闭丢弃草稿。高级图形弹窗的确定只返回主窗口草稿，主窗口取消仍不会保存。重置也只重置草稿。无效颜色或空数值会阻止保存，并定位到对应分类。

“保存并继续：…”会先保存本窗口的有效设置，再打开工具栏、网格、插件、颜色管理、快捷键、Camera Raw 或恢复目录。此按钮明确是一项保存操作。语言与帮助菜单共用已有语言设置文件；工具栏、快捷键、网格、插件及 Camera Raw 保持各自已有配置归属，不复制出第二套设置。

主题、界面字体大小、语言、工具提示、GPU 后端与 GPU 缓存上限需要重启。其他设置在确认后应用，置入、新建文字、导出及新文档参数作为后续操作的默认值，不重写已有图层。

## 分类与实际关联

| 分类 | 接入项目功能 | 生效范围／限制 |
| --- | --- | --- |
| 常规 | 置入时适合画布、创建智能对象、跳过置入变换 | `MainWindow.Files` 新置入栅格图像 |
| 界面 | 四档灰度主题、语言、界面基础字号、画布外背景色 | `Skin`、`EditorTheme`、`Localize`；固定字号的紧凑控件不属于全局 UI 缩放 |
| 工作区 | 大文档标签、工具栏配置、恢复默认工作区 | 标签立即刷新；恢复显示工作区控件、默认工具栏、选项栏及属性面板，并适合画布 |
| 通知 | 工具提示开关 | 全局提示样式；错误和文件转换报告保持可见，无广告／引导通知系统 |
| 工具 | 滚轮缩放、指针位置缩放、画笔平滑、吸管取样环、快捷键入口 | `CanvasView`、工具选项栏；关闭滚轮缩放后滚轮平移，Ctrl+滚轮仍缩放 |
| 历史记录 | 1–1000 个状态、16–1536 MB 保留预算、非线性历史、编辑日志 | 所有打开文档的 `DocumentHistory`；预算减少可能裁减旧撤销记录 |
| 文件处理 | 外部文件重载、0–100 个最近文件、恢复副本及 1–60 分钟间隔 | `ProjectWatch`、`RecentProjects`、恢复定时器；不会重载已修改文档 |
| 导出 | JPEG 质量、PDF 分辨率、透明度默认值 | “导出为”和图层 PNG 导出；JPEG 始终不透明，仍询问输出位置 |
| 性能 | 使用图形处理器、128–2048 MB GPU 缓存上限、大图／低内存预设、进程内存与 GPU 绘制状态 | `Program.Build`、`CanvasView.Display`；缓存上限不是内存预分配，也不是应用总内存限制 |
| 图像处理 | 本地处理说明、ICC 和 OpenColorIO 设置入口 | 复用既有颜色功能；无自动云端上传选项 |
| 暂存盘 | 设置目录、所在磁盘实际剩余空间和能力说明 | 尚无磁盘图块换出引擎，不提供无效的盘符勾选项 |
| 光标 | 钢笔形光标、精确画笔十字、笔尖内十字、绘画时隐藏、轮廓宽度 | `CanvasView.Cursors`，保留 Alt 取样和文字 I 形光标行为 |
| 透明度与色域 | 棋盘格显示、大小与两种颜色 | 更新共享绘制画刷；只改变预览；ICC 软打样／色域警告位于“视图 → CMYK” |
| 单位与标尺 | 标尺单位、新文档分辨率 | 与属性面板双向同步；已有文档分辨率保持原值 |
| 参考线、网格和切片 | 参考线颜色及线型、网格颜色、路径／控制线颜色与宽度、切片编号 | `Skin`、画布与钢笔覆盖层；网格间距／子网格通过已有网格窗口设置 |
| 增效工具 | 已有本地插件管理入口 | 使用本应用插件 API，不实现 Adobe CEP、生成器或远程控制协议 |
| 文字 | 默认字体及像素字号、占位文本；Esc 保留文字／Ctrl+Esc 取消本次编辑 | 新文字默认值；输入法组合状态优先，保留已有字体回退 |
| 技术预览 | 缓存图层显示开关 | 关闭后使用参考合成器；不是 Adobe 保留细节 2.0 或 HDR 显示开关 |
| Camera Raw | 打开当前图层 Camera Raw 面板 | 参数仍属于图层，不变为所有文档共用的全局调色值 |

画笔平滑、取样环、标尺单位及参考线线型在工具栏／属性面板改变后也会写回首选项，避免再次打开窗口时出现旧值。

## 高级图形处理器设置

- **使用 OpenCL**：置灰并说明当前没有 OpenCL 计算内核。OpenCL 迁移计划暂缓，本版继续使用 Skia；不会仅修改设置名称而声称更换了引擎。
- **对参考线和路径应用消除锯齿**：接入画布覆盖层的边缘绘制选项。
- **30 位显示**：置灰；窗口输出当前为每通道 8 位。16／32 位图层源数据仍由原有高位深管线保存，文档精度与显示输出位数分别处理。
- **GPU 合成**：与技术预览中的“加速图层显示”共用同一个字段。它允许缓存场景路径；只有启用图形处理器且实际获得 GPU 上下文时才使用 GPU，否则使用软件绘制。性能页显示最近观察到的加速帧状态。

## 大图显示实现与边界

鼠标移动、画笔光标和钢笔辅助线刷新不再重新合成全部图层。支持的文档记录为可重复播放的 Skia 场景，并复用不可变图像资源；平移／缩放重用场景。Windows 通过 Avalonia 的 ANGLE GPU 后端显示，不可用时回退软件。

简单栅格图层、支持的混合模式、普通组与基本蒙版可以进入缓存路径。调整图层、样式、高级混合、剪贴关系、高位深资源、羽化／非满密度蒙版和画框／画板等仍使用参考合成器。保存及正式导出继续使用原参考管线，缓存场景不写入项目。

本机 RTX 4080、Windows 11，以一份未上传的本地 PSD（4697×4549、45 层、46.44 MiB）验证：解析约 **520 ms**，从解析开始到首个绘制回调约 **730 ms**；随后 60 次平移／缩放的回调等待中位数 **9.40 ms**、P95 **16.57 ms**，场景仅构建一次，实际获得 GPU 上下文。峰值工作集约 **1549 MiB**。这些是单机绘制回调数据，包含调度而不是 GPU 栅栏完成或屏幕呈现时间，不等于 FPS 保证，也不能推广到复杂效果文档。

可自行运行 `Compositor.exe --performance-checks "D:\sample.psd" "D:\report.json"`。这是显式运行的本地诊断：不修改输入、不上传文件，报告中只包含尺寸、图层数和耗时等统计。

## 恢复副本与日志

恢复副本默认关闭。启用后，已修改且不在置入／文字编辑中的文档按间隔保存到设置目录下的 `recovery`，每个标签使用独立文件夹名称。副本采用普通 `.comp` 包，不覆盖原项目、不清除原文档的未保存标记；保存中关闭标签会等待，手动保存与恢复保存使用独立任务。通过“打开恢复目录”找到副本，再使用“文件 → 打开”读取。副本保留至用户手动移除；没有自动弹出的崩溃恢复选择器。

编辑日志默认关闭，启用后记录时间及已提交的命令名到 `history.log`；超过 4 MiB 时轮换为 `.previous`。不记录图像像素，不是可回放脚本或撤销恢复文件。自动恢复失败保留原项目并显示错误。

## 审查与验证

审查覆盖 Core 像素／文档／历史／格式／IO／渲染、Desktop 画布／工具／菜单／属性／导入导出／主题／插件、CLI 共用核心，以及测试与打包文档的设置消费位置。没有后端支持的截图选项保留说明或禁用状态：暂存盘调度、内存百分比分配、Adobe 插件协议、HDR 输出等不作为已实现功能。

`--preferences-checks` 验证分类、搜索、高级弹窗草稿与取消、保存重载、无效字段定位、参考线与棋盘格应用、恢复副本、恢复期间手动保存、调整图层重新编辑、菜单和光标缓存。中文／英文回归与浅色主题截图分别检查。设置属于用户环境，不要求升级项目格式；新增可编辑调整图层另见 [v19 格式](../docs/project-format.md#windows-extension-version-19)。

文字新增字体收藏、预览大小、默认／命名样式；图层缩览图大小和裁切、蒙版叠加颜色和记住的边缘参数均保存到用户首选项。浅色主题会立即更新图层背景、面板控件和图标。

2026-10-22 源码新增独立于 GPU 缓存上限的进程内存准入预算，默认约为 GC 可见总内存的 60%；`COMPOSITOR_MEMORY_MB` 可降低到至少 256 MiB。它没有新增首选项滑块，也不是操作系统硬限额。历史预算现计入选区蒙版与路径；大图 CPU 显示、导航器、滤镜预览和推理采用有界后台任务。详见 [性能说明](PERFORMANCE.md)。
