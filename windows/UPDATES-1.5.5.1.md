# Windows 1.5.5.1 Preview

2026-10-23。上游基线仍为 `551a35fc06fb8429fed3b99b175e31681875f580`；本轮再次查询 upstream HEAD，没有新提交。继续移植上一版明确列出的缺口，并完成用户图 1–24 的辅助、取样和修饰工具。源码构建和 Actions 产物使用 1.5.5.1，未创建 GitHub Release。

沿用 Skia 显示、32 DIP 主题标题栏、同一实际快捷键归组、左工具栏取消滚动及 imagegen 切片排列图标；既有图层、蒙版、文字、钢笔、裁剪和高位深源文件保持可用。

## 冷启动、重算与预算

- Windows 进程内存统计最多每 16 ms 查询一次；期间对已完成分配保守计费，并持续计入并发预留。接近预算时立即刷新真实统计，不靠陈旧数据放行。自定义预算默认仍每次测量，保持故障注入可重复。
- 普通整数平移图层直接绘制，常规不透明调整层原位处理；冷缓存把相邻 512 px 图块合为最多 1024×1024 的工作区，减少重复 halo 与合成初始化。缓存仍受 min(128 MiB, 预算/8) 限制，深色彩路径和最终导出不降采样。
- 编辑版本继承未受影响的精确图块；变动区域覆盖旧/新边界及滤镜 halo。组、复杂混合、效果、裁切和调整层参数变化保守重建，避免显示旧像素。晚到的旧版本结果不能进入新缓存。
- 修复画笔使用有界滑动邻域均值，高扩散和内容识别修补不再为每个候选重复遍历邻域。仿制源叠加在后台生成，编辑期间不在 UI 线程合成全图。
- 性能数据、比较条件和原始证据见 [PERFORMANCE.md](PERFORMANCE.md)。缓存命中合成耗时不等于显示器帧率；复杂滤镜冷算仍有成本。

## 格式、测试与依赖

Windows 扩展 v26 增加图框样式、计数组、注释作者、第二条测量线与滤镜调整参数。读取旧格式默认值；旧 Windows / macOS 不应仅改版本号强行打开 v26。[格式定义](../docs/project-format.md#windows-extension-version-26)与 CI 文档门禁同步。

新增 `--utility-retouch-checks`，中英文与发布包都执行；包含原生 PDFium 两页导入、取消/撤销和设置保存。低资源脚本增加编辑后缓存像素对照与修饰检查。完整测试与打包结果记录在 PERFORMANCE / COMPATIBILITY，CI 以 [Windows 工作流](https://github.com/konban47/Compositor/actions/workflows/windows.yml)中本次提交为准。

本机最终通过 1260 项核心测试（零跳过）、24 组英文 / 18 组中文 UI、两种低资源配置及完整性能门禁。性能三次复测：12 MP PSD 导入至首帧中位 606.07 ms（上一版 1077.73 ms），原复杂视口冷缓存 1189.35 ms（本轮前 1875.76 ms）；小图层编辑重算 86.16 ms，11/12 图块复用，输出逐字节一致。工具位图复制也经过预算检查，失败不提交目标像素。
