# Windows 1.4.8.1 Preview

对应 2026-10-10 的图层／通道面板及交互反馈。感谢 [Robbie Tilton / Wonder Assembly 的 Compositor](https://github.com/robbietilton/Compositor) 和 [chenguisen 的 Windows 移植](https://github.com/chenguisen/Compositor/tree/compositor_win)。

## 用户反馈对应实现

| 项目 | 实现与操作 |
| --- | --- |
| 鼠标中心缩放 | 滚轮以指针下的文档位置为锚点，包含连续小幅滚动及缩放上限；工具栏缩放仍围绕视口中心 |
| 工具快捷键提示 | 左侧工具提示加入当前键位；修改快捷键后立即刷新；组合工具显示共享快捷键 |
| 图层锁定 | 右键“锁定图层”或 Ctrl+\；右侧锁图标点击解锁；锁定组保护所有子层；额外提供透明像素、图像像素、位置锁定 |
| 多选新建组 | Ctrl 点击追加、Shift 点击范围选择，右键菜单保留多选；“新建组”或 Ctrl+G，Ctrl+Shift+G 取消编组；组可折叠 |
| 通道 | 独立“通道”标签，RGB／红／绿／蓝行包含眼睛、缩略图、快捷键 Ctrl+2/3/4/5；分通道编辑保留其他分量；视图显隐不改变导出颜色 |
| Alpha 通道 | 新建／复制／重命名／删除，选区存取、灰度绘制／填充／渐变／滤镜；选区保留灰度覆盖率，反选不会把灰度强制二值化；可撤销并随项目保存 |
| 图层面板 | 按补充截图增加类型筛选、名称搜索、混合模式、不透明度、填充、锁定行、图层／蒙版缩略图、组缩进与折叠、链接；底部图标连接图层样式、蒙版、调整、组、新建、删除操作 |
| 汉化 | 新增界面、工具提示、状态及面板术语采用简体中文，保留已有用户图层名称和内容 |

图层锁定参与撤销，受保护的像素和位置不会通过快捷键或滤镜预览绕过保护。链接成员随移动与变换同步，受锁定保护的成员保持原位。继承组锁定的子层需先解除组锁定。

## 保存兼容性与范围

使用锁定、链接、非默认填充或 Alpha 通道时，项目保存为 **Windows 扩展版本 12**。旧 Windows 和当前 macOS 原版不支持该版本；不使用这些扩展时仍保存为 v11。移除所有扩展后另存为会回到 v11。详见 [格式说明](../docs/project-format.md#windows-extension-version-12)。

通道范围为 RGB 和最多 64 个 Alpha，不包含 CMYK/Lab、专色和完整 Photoshop 通道计算。Alpha 滤镜在应用时更新，不显示拖动参数预览；移动、文字、形状、Camera Raw 等图层命令需选择 RGB。PDF 是单页合成图像，不保留可编辑图层或矢量文字。扫描线光晕在 CPU 全分辨率上计算，与上游的低分辨率模糊存在轻微差异。

## 验证

核心测试 **911 项**。新增测试覆盖锁定和组保护、撤销、RGB 分量隔离、Alpha 选区灰度及反选、格式 v11/v12 读写、填充与图层样式、通道随画布几何变化、三种导出编码、扫描线、Camera Raw 自适应统计与去朦胧。

窗口检查覆盖实际鼠标滚轮和 Ctrl＋中键、Ctrl 点击多选、右键新建组、锁定快捷键与解锁按钮、图层筛选、导航器定位、通道编辑、撤销、导出对话框、扫描线面板。`--panel-checks` 与既有中英文窗口及交互检查进入双 Windows Server CI；发行包另测实际 EXE、安装和卸载。

本地 Windows 11 自动检查及 Windows Server CI 不替代 Windows 10 实机、真实输入法候选窗、多显示器与数位板人工验收，继续标记 Preview。[已知差异](README.md#已知差异和验收边界)。
