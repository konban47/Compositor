# Windows 1.4.10.1 Preview

2026-10-12。开始前核对并 fetch，本地与 `origin/windows-port` 均为 `2ac0535b8f9a9565b53250a1dfe3427c080fa191`。合并上游从 `2522e3b8f8bee3c64b1ab4c474656824969393ff` 到 [f5ae5bad0b25b32dda9f254e62d2f07f59478698](https://github.com/robbietilton/Compositor/commit/f5ae5bad0b25b32dda9f254e62d2f07f59478698) 的 8 个提交。

## 本次修改

- 属性面板内部颜色统一为全局主题；修复不透明度滑块手柄底部裁切和垂直居中。
- 工具栏三点图标增大、底部按钮居中，三点菜单只保留自定义工具栏。颜色控件与标签页按上游布局，移除标签右侧重复新建按钮。
- 审查工具图标和主题字体：上游自绘图标直接移植；SF Symbols 与系统控件采用 Windows 对应图形。内置 imagegen 生成设计参考后制作 16 类矢量对应图形，包括魔棒、画笔、修复、吸管等；不把生成或自行绘制的图标称为上游原始文件。
- 按最新截图扩展“编辑”菜单：选择性粘贴、渐隐、文字查找替换／Windows 拼写、填充／描边、重复变换、操控变形、内容识别缩放、自动对齐／混合、天空替换、预设、菜单、首选项、ICC／OCIO。前一版的图像菜单功能保留。
- 新功能接入实际像素、图层蒙版、选区、锁定和历史；服务功能使用用户配置的图像 API。无对应引擎的首选项置灰，详细实现范围见 [编辑菜单手册](EDIT-MENU.md)。
