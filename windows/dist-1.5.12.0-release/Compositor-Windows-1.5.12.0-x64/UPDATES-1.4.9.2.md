# Windows 1.4.9.2 Preview

2026-10-10。开始前从 GitHub 将 `windows-port` 快进至 `a0014d9ea944a068859dda6d8a3539b87252119f`，保留其 Photoshop 风格配色、排版、图标和窗口改版。复核上游 [Compositor](https://github.com/robbietilton/Compositor) 最新提交仍为 **1.4.9 / `b4bfdea87f9dc0cbc9eabfa63683eb1b9c2bca60`**，已经包含，无新增上游功能需要移植。

## 本次更新

- 统一图层样式窗口：10 类效果、斜面等高线／纹理、重复实例、实时预览、取消恢复、一次确认对应一个撤销步骤、样式库和 JSON 预设。高级混合、RGB、浅／深挖空、蒙版隐藏效果、组／剪贴混合及 Alt 拆分混合颜色带接入实际渲染。
- 截图右键菜单：图层清理、新建／复制／删除、快速导出／导出为、合并可见／拼合、锁定、重命名、隐藏、组、画框、画板、内嵌智能对象、遮住所有对象、剪贴、复制 CSS／SVG 和颜色标签。
- 智能对象保存可编辑源，支持内容页回写关联实例、独立副本与栅格化；源包进入历史预算。修复组调整图层未遵循祖先蒙版的问题，让“遮住所有对象”的蒙版组可用于局部调整。
- Ctrl+Shift+E 调整为合并可见图层；选中图层快速 PNG 导出使用 Ctrl+Shift+'，导出图层为 Ctrl+Alt+Shift+'。菜单显示实际快捷键。保留变换、对齐／分布、历史记录图标布局与悬停解释。
- 保存新增能力时使用 Windows v15；普通旧特性继续按需要写 v11–v14。首页、Windows README、工作区手册、图层手册、格式文档、更新说明与包内副本同步；CI 校验版本、关键字段、快捷键和文档收录。
