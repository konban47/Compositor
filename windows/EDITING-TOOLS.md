# 置入、跨文档复制与新增工具

适用于 Windows **1.4.9.4 Preview**。所有新工具都可从“工具”菜单或“自定义工具栏”找到；组按钮长按／右键展开，同组快捷键循环选择。升级前保存的工具栏布局会把新增工具放入“附加工具”；恢复默认值可得到新版分组。

本版新增选区、裁剪、切片、标注和修复工具、K 图框及光标说明见 [选区、修饰与辅助工具](PROFESSIONAL-TOOLS.md)。

## 拖入与置入变换

在已建立的画布上拖入普通图片或相机 RAW，解码／显影后进入置入状态。顶部显示参考点九宫格、X/Y（像素）、W/H（百分比）、约束比例、旋转角度、变形、取消和确认。按 **Enter 置入**，**Esc 取消**；一次多文件拖入作为一个历史步骤，取消移除本次全部新增图层。普通移动／缩放保留导入图像分辨率。

右键菜单提供置入、取消、缩放、旋转、斜切、透视、扭曲、旋转对象、180 度及双向 90 度旋转、变形、水平／垂直／交叉拆分、移去拆分、切换变换锚点、切换参考线、水平／垂直翻转。缩放可拖控点，旋转可拖动，Shift 约束角度；斜切移动成对角点，透视对向移动，扭曲可单独移动角点。变形网格节点可自由拖动，内部也可整体移动；右键位置决定拆分位置，选中拆分节点后可移去相交的内部网格线。每个方向最多九条网格线。

九宫格选择数值变换的参考点。链条切换比例约束；X/Y 是该参考点的位置。切换工具、文档或保存会先确认置入；需要放弃时先按 Esc。新建画布拖入图片不会替换画布本身。PSD/PSB 和 `.comp` 保留原有“打开为文档”行为。

置入采用 CPU 双线性网格／透视重采样，非 Photoshop 的 Adobe 变形引擎。扭曲／变形写入结果像素，可整体撤销；不存储可再次打开的 Adobe 变形网格。模式内拖动始终从该模式开始时的图像计算，避免每个鼠标事件累积采样。W/H 显示当前像素源的百分比；重采样后基准会更新。

## 文档间复制粘贴

没有像素选区时，在图层面板选择一个或多个图层／组，**Ctrl+C**，切换文档标签后 **Ctrl+V**。也可使用编辑菜单或画布右键菜单。支持双向粘贴和同文档粘贴，**Ctrl+X** 剪切完整图层，所有更改可撤销。

- 保留组、名称、堆叠顺序、位置、缩放、旋转、链接、锁定、透明度、蒙版及其独立位置、样式、文字、路径、调整图层和内嵌智能对象。
- 生成新的图层／组标识；剪贴关系仅在被复制内容内部保留，外部父组／剪贴源不会带入。粘贴到所选图层上方或所选组内；锁定组拒绝粘贴。
- 剪贴数据在复制时独立编码，关闭源文档后仍可粘贴；每次粘贴获得独立像素资源。超出文档或剪贴数据预算会拒绝操作。
- 有像素选区时，Ctrl+C/X 继续处理所选像素。完整图层使用应用内剪贴板，不是 Windows 通用图层交换格式；不在不同应用进程间传递可编辑图层。

## 图中的工具

| 工具／快捷键 | 实际操作与设置 |
| --- | --- |
| 仿制图章／图案图章 S | 仿制图章保留 Alt 取样、对齐和图层取样。图案图章可载入图片作图案、设置缩放、重置为前景色／白色棋盘纹理，跟随画笔大小、硬度与不透明度。 |
| 历史记录画笔／历史记录艺术画笔 Y | 先从历史记录面板设置源。普通画笔恢复原像素；艺术画笔按点绘、松散卷曲、紧密卷曲重绘历史图像，大小控制笔触区域。 |
| 橡皮擦／背景橡皮擦／魔术橡皮擦 E | 普通橡皮擦按笔触擦除；背景橡皮擦按容差擦除取样颜色，可一次／连续取样并保护前景色；魔术橡皮擦单击匹配颜色，可选择连续／不连续和当前／所有图层取样。 |
| 渐变／油漆桶 G | 渐变保持五种形状及前景／背景色设置。油漆桶按容差、连续性和取样范围填充前景色，并遵循不透明度及原有选区。 |
| 模糊／锐化／涂抹／液化（可自定义按键） | 模糊按半径软化；锐化按强度增强局部边缘；涂抹拖动颜色；液化移动像素。 |
| 调整画笔 | 绘制可编辑调整图层的黑白蒙版，选项栏选择曝光度／饱和度与数量；“新建调整”开始独立效果。后续在属性或调整窗口修改参数，擦除模式减少蒙版覆盖。默认无快捷键，可自定义。 |
| 减淡／加深／海绵 O | 减淡提亮、加深压暗，可选阴影／中间调／高光和强度；海绵可去色或加色。 |
| 钢笔／自由钢笔／弯度钢笔 P | 钢笔单击角点、拖出曲线手柄，Alt 可断开手柄；自由钢笔按住拖出平滑路径；弯度钢笔自动计算平滑控制点。点击起点闭合，Enter 完成，Esc 取消。开放路径用线宽描边，闭合路径以前景色填充。 |
| 添加／删除锚点／转换点 | 在路径上添加锚点时拆分贝塞尔曲线且保持形状；删除所选附近的锚点；转换点单击切换角点／平滑点，拖动设定方向手柄。A 的直接选择工具可继续移动点与手柄；路径仍可编辑。 |
| 横排文字／直排文字／直排文字蒙版／横排文字蒙版 T | 单击后输入，Ctrl+Enter 确认、Esc 取消。直排文字逐字向下、各列从右向左排列，支持中文和字体回退。文字蒙版确认后产生文字轮廓选区，不留下文字图层。 |

像素工具遵循当前选区和图层锁定，可撤销。调整画笔通过蒙版限制作用区域；Alpha 通道支持兼容的像素绘制与油漆桶。智能对象需先栅格化后才能直接修改像素。

这些工具使用本项目的 CPU 实现；艺术画笔是离散笔触风格，直排文字采用直立字形排列，不包含 Adobe 全套笔尖库、东亚竖排标点替代及所有商业字体的竖排 OpenType 行为。直排文字与开放路径描边使用 **Windows 格式 v16**；旧项目仍按实际需要写 v11–v15。上游 macOS 原版不读取 Windows 扩展格式。

## 按钮与图标

参照上游 `ContentView.swift` 的工具栏和 `ToolHeaderStyle.swift`：统一圆角、细边框、低对比悬停／按下反馈、淡色选中态，以及单色圆端点线条图标。工具、变换、图层、历史记录和通用操作使用原生矢量绘制，在高 DPI 下保持清晰。仿制图章、渐变、多边形套索和对象选择图标直接移植上游自绘源码；其余 Apple SF Symbols 调用及新增图标使用 Windows 矢量对应图形，来源与参数见 [上游 UI 清单](UPSTREAM-UI.json)。保留 Windows 窗口控件、键盘焦点和现有面板布局。
