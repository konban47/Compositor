# Windows 1.5.3.0 Preview

2026-10-15。合并上游 [Compositor 1.5.3 / 365b574](https://github.com/robbietilton/Compositor/commit/365b5745eda537f984f3d5bed1e53c361dbc9c91)，基线完整提交为 `365b5745eda537f984f3d5bed1e53c361dbc9c91`。保留 Windows 扩展与原有工作区。

- 浮窗面板选项、展开／折叠和关闭图标放大、垂直居中；全局三点圆点统一。上下文任务栏新布局默认关闭，停靠时隐藏名称。保留圆角外框、项目 logo 和较大的窗口控制图案；深灰原生边框颜色统一，关闭悬停为红色。
- 四套主题采用参考图的实心滑块逻辑，右侧纵向滚动条常驻，横向滚动条仍嵌入最底部信息栏中间。
- 补齐 15 种选区／裁剪／切片工具选项和设置弹窗：增加单行／单列选框、交叉与羽化组合、选区软笔尖、对象范围查找与覆盖层、裁剪预设／比例／分辨率／屏蔽／网格／填充，以及切片自动补齐／提升／划分／排列／属性／导出。
- 本机主体识别和对象预览使用随包 U²-NetP；人物入口提供前景点选及云端人物掩模。云端主体／人物和生成式扩展复用用户配置的图像服务，设备模式不能识别人物类别或身体部位。新增 [操作与能力边界手册](SELECTION-CROP-SLICE.md)。
- 上游 `9f1d158`／`9b3f48e`：平滑矩形圆角的曲线数学、半径为零禁用、形状工具／属性、SVG／路径输出和保存。Windows 写入 v23，亦读取上游 v14 的 `shape.smoothing`。
- 上游 `92eba05`：图层列表中键拖动滚动。`fc4c273`：缩放拖动方向变化时立即刷新放大／缩小光标。
- 上游 `f4b7009`／`cf0ffa1`：Windows Camera Raw 保持已有原尺寸参数预览，示波器改为直接从原图以 4 像素步长采样，超过 400 万像素时使用 8 像素步长，避免预缩小稀释小范围剪切。`9329ab8` 的 Metal 管线属于 macOS；Windows 继续使用已验证的 CPU／Skia 与测量表，不宣称移植 Metal 性能，也不启用暂缓的 OpenCL。
- 同步首页、Windows 手册、现有工具说明、项目格式、来源哈希、安装包文档与 CI 一致性检查。扩展切片属性和平滑圆角保存为 Windows v23，其余仍使用最低必要格式。

验证：1184 项核心测试；Release 构建以警告为错误；21 组英文、15 组中文界面回归，新增 `--selection-options-checks` 并用于发行包。实际 Windows 11 窗口检查确认原生边框、项目 logo、红色关闭悬停和滚动条模板；自动化不等同于 Windows 10、真实数位板或多显示器实机验收。云端生成未发送测试请求。用户提供的截图不进入仓库与安装包。
