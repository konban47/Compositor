# Windows 1.5.8.0 Preview

2026-10-24。上游参考源码同步至 `c9c7531c620d9880e5b015fbcc57518e81483bc8`（Compositor 1.5.8）。[GitHub Release](https://github.com/konban47/Compositor/releases/tag/windows-v1.5.8.0) 提供安装版、免安装版及 SHA256SUMS.txt。

新增 14 种工具的选项栏和对应行为：渐变、油漆桶、模糊、锐化、涂抹、调整画笔、减淡、加深、海绵、缩放、抓手、旋转视图、路径选择及直接选择。此前的图章、历史记录画笔、橡皮擦系列及画笔设置继续保留。浮窗标题按钮保持原样。

主要变更包括可编辑渐变及控制点、五种渐变形状与方法、渐变预设管理、图案填充及混合、局部修饰的压力/取样/保护选项、18 类调整画笔蒙版、双列原创笔刷卡片、跨窗口视图同步、路径外观和组件编辑。详情见[工具手册](TOOL-OPTIONS.md)。

## 颜色管理

颜色设置与 OpenColorIO 设置按参考图分组重建并使用项目主题，移除 Creative Cloud 同步。新增独立 ACE 兼容 CMM（非 Adobe 专有引擎，不承诺逐位一致），支持 ICC v2/v4 RGB/CMYK/灰度、矩阵/TRC、LUT、四种意图、黑场补偿和透明度保留；另提供 Microsoft ICM/Little CMS。工作空间策略、ICC 导入导出、自定网点/灰度、显示预览和伽马混合已接入。OpenColorIO 使用真实配置/角色/处理器，包含 HDR 往返、显示变换、浮点 TIFF 和 v28 元数据。[完整功能与边界](COLOR-MANAGEMENT.md)。
