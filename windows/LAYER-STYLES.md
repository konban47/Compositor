# 图层样式与图层右键菜单（1.4.9.2）

## 图层样式

从图层右键“混合选项”、底部 **fx** 或双击图层缩略图打开。智能对象缩略图的双击用于编辑内容；图层行的空白处仍可打开样式。左侧选择效果，勾选启用；右侧“预览”控制画布实时预览。“取消”恢复原样且不增加历史，“确定”生成一个可撤销步骤。窗口过小时，中间参数区和左侧列表可滚动。

| 效果 | 可编辑参数 |
| --- | --- |
| 斜面和浮雕 | 内斜面、外斜面、浮雕、枕状浮雕、描边浮雕；平滑／雕刻技术、深度、方向、大小、软化、角度、高度、高光／阴影颜色及混合模式、等高线、纹理 |
| 描边 | 大小、内部／居中／外部、颜色／渐变／图案填充 |
| 内阴影／投影 | 混合模式、颜色、不透明度、全局光、角度、距离、大小、阻塞／扩展、等高线、杂色 |
| 内发光／外发光 | 混合模式、颜色、不透明度、大小、阻塞／扩展、等高线、杂色；内发光可选中心来源 |
| 光泽 | 混合模式、颜色、不透明度、角度、距离、大小、等高线、反相 |
| 颜色叠加 | 颜色、不透明度、混合模式 |
| 渐变叠加 | 两端颜色、线性／径向／角度／对称／菱形、角度、缩放、偏移、反向及与图层对齐 |
| 图案叠加 | 棋盘格／条纹／圆点／导入图像、颜色、缩放、角度、偏移及与图层链接 |

描边、内阴影、颜色叠加、渐变叠加、投影右侧 **+** 可添加重复实例。左下“添加效果”也可添加；箭头调整实例顺序，垃圾桶删除当前实例。每层最多 40 个实例；背景效果、内部效果、前景描边／斜面分别合成，同一类实例遵循列表顺序。导入图案按比例缩至最长边 512 像素并内嵌，不引用外部文件。

混合选项提供图层混合模式、不透明度、填充不透明度、R/G/B 通道、无／浅／深挖空、将内部效果混合成组、将剪贴图层混合成组、透明形状图层、图层／矢量蒙版隐藏效果。浅挖空止于当前隔离组，深挖空穿透祖先组；降低填充使挖空显现。普通组默认穿透；具有样式、非正常混合或高级混合的组按组整体合成。

“混合颜色带”选择灰色或 RGB 分量，分别调整“当前图层”和“下一图层”的黑／白范围。**Alt 拖动**三角拆分过渡，箭头键微调，Shift+箭头步进 10，Tab 切换手柄。不同分量的范围可同时保留。

“新建样式”存入 `%APPDATA%\CompositorWindows\layer-styles.json`；“样式”页可应用、删除或存储／载入 JSON 预设。最多保留 100 个预设，不包含图层图像、名称或位置；不兼容 Photoshop `.asl`。

## 截图中的右键菜单

Ctrl／Shift 多选后，大部分命令作用于所选图层。锁定、只读编辑目标和必要的选中数量会限制命令。蒙版选中时，删除仍走蒙版确认流程。

| 菜单 | 行为／默认快捷键 |
| --- | --- |
| 图层清理 | 删除空像素图层、空组或隐藏图层；隐藏内容删除前确认，可撤销 |
| 新建图层／新建组 | 命名透明图层；新建组或将所选图层编组（Ctrl+G）；“从图层新建组”允许指定名称 |
| 复制图层／删除图层 | 复用现有复制、剪贴依赖和删除逻辑；Delete 有选区时先清除选区像素 |
| 快速导出为 PNG | **Ctrl+Shift+'**；所选内容合成并按可见像素裁切，选择保存路径 |
| 导出图层为 | **Ctrl+Alt+Shift+'**；PNG/JPEG/PDF、尺寸、透明度及背景预览 |
| 合并图层／合并可见图层 | 选中图层合并；**Ctrl+Shift+E** 合并全部可见，隐藏内容保留，可撤销 |
| 拼合图像 | 可见内容合成白底背景，删除隐藏内容前确认，可撤销 |
| 锁定图层／锁定图层对话框 | Ctrl+\ 切换全部锁定；**Ctrl+/** 打开透明像素／像素／位置／全部锁定设置；行末锁可解锁 |
| 重命名／隐藏图层 | 重命名；**Ctrl+,** 切换所选图层可见性 |
| 混合选项 | 打开统一样式窗口；另有复制／粘贴／清除样式、缩放效果和显示／隐藏效果 |
| 折叠所有组 | 关闭所有组列表；另有展开所有组和取消编组 |
| 来自图层的画框 | 指定名称、位置、尺寸和矩形／椭圆，生成带蒙版的裁切组；右键可置入图像填满画框 |
| 新建画板／来自图层的画板 | 指定位置和尺寸，创建白底裁切组；超出右／下边界时扩展画布与 Alpha 通道；共享当前文档坐标 |
| 转换为智能对象 | 内嵌所选图层、文字、形状、蒙版及样式；以合成缓存显示，保留可编辑源 |
| 遮住所有对象 | 对当前图层离线推理，把分离的显著性区域转成各自的空蒙版组；原图保留，可往组中添加调整图层 |
| 创建／释放剪贴蒙版 | **Ctrl+Alt+G**；沿用相邻图层剪贴工作流 |
| 复制 CSS／SVG | 写入剪贴板；简单未蒙版形状输出原生 SVG 矢量几何，其他外观使用内嵌 PNG；CSS 使用 PNG 背景及尺寸／位置 |
| 颜色 | 无、红、橙、黄、绿、蓝、紫、灰标签，显示在图层行并保存 |

原整图“导出 PNG”仍在文件菜单，默认快捷键已让给“合并可见图层”。现有自定义快捷键保存在个人设置，快捷键面板可检查和修改。

## 智能对象与保存

右键“编辑智能对象内容”或双击缩略图，在新标签页编辑源图层。**Ctrl+S** 将内容回写到父文档中相同 ID 的实例；还需保存父文档才能写入磁盘。普通复制保留关联；“通过拷贝新建智能对象”使用独立源 ID。“栅格化图层”解除源关联并允许绘画；这些操作均可撤销。父文档已关闭或源被删除时，内容页可“另存为”独立项目。

项目格式升级到 [Windows v15](../docs/project-format.md#windows-extension-version-15)。智能对象源包保存在 `images/<LAYER-ID>.SMART.ZIP`，不依赖原始文件路径。单源及项目内源包总量最多 128 MiB；打开源包时限制总展开大小 512 MiB。历史与快照的 256 MiB 保留预算同时计算像素和旧源包。

## 差异与边界

- 这是本应用的 CPU 样式与图层工作流，不是 Photoshop 引擎。斜面光照、预设等高线、纹理、挖空和组混合可能产生不同像素；渐变为两端颜色，等高线为内置曲线，没有 Adobe 任意曲线编辑器或 ASL 导入。高级参数都参与合成，但不保证 Adobe 文件往返兼容。
- 组的渐变／图案／纹理效果使用稳定的全画布中间表面以避免分块接缝，受 200 MP 单表面限制，内存和渲染开销高于普通组。
- 画板是共享文档中的白底裁切组，没有独立色彩空间、单画板自动批量导出或 Photoshop 无限工作区；画框可以手动置入和变换内容。
- 智能对象为内嵌 Compositor 源，支持重编源图层；不实现链接外部源、Adobe 智能滤镜或 PSD 智能对象写回。选择转换前的图层混合模式在源内部合成，依赖外部背景的混合视觉可能改变。
- “遮住所有对象”基于随包 U²-NetP 显著性蒙版的连通区域，最多 32 组；相连主体可能合并，微小区域会过滤，不能等同 Adobe 的实例识别。蒙版后续可在属性面板羽化、调整与绘制。
- SVG/CSS 回退明确保留合成外观，不声称所有像素／文字图层都转换成可编辑网页结构。
