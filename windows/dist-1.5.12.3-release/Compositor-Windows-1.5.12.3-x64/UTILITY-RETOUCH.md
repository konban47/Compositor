# 辅助与修饰选项栏

适用于 **1.5.12.3 Preview**，对应用户图 1–24。窗口较窄时选项栏可横向滚动；弹出设置用外部单击关闭。实际算法为本项目独立实现，不承诺与 Photoshop 专有算法输出相同。

## 图框、取样和标注

| 工具 | 操作 |
| --- | --- |
| 图框 K | 选择矩形、椭圆、三角形、六边形或自定义形状。自定义按钮可输入归一化到 0–1 的 SVG 路径，默认提供星形轮廓，非法轮廓会被拒绝。设置描边颜色（或 none）、像素宽度、内部/居中/外部位置与矩形圆角，再拖出图框；选中图框时修改参数直接更新且可撤销。图框是带矢量裁切的组，原置入流程保留。 |
| 吸管 I | 取样点及 3/5/11/31/51/101 平均；当前、当前和下方、所有、所有无调整、当前和下方无调整五种范围。点击设前景色，取样环比较原色与新色；关闭取样环仍可取色。采样只渲染邻域与所需滤镜 halo。 |
| 颜色取样器 I | 与吸管相同七档范围；单击添加，最多十点，拖动移动；Alt 单击删除，清除全部可撤销。颜色值显示在信息面板。 |
| 标尺 I | 拖出测量线，拖端点调整；Alt 从端点拖出第二臂、Shift 按 45° 约束。选项栏显示 X/Y/W/H/A/L1/L2，可使用文档测量比例；拉直选中图层，清除测量。 |
| 注释 I | 作者与颜色用于新注释/选中注释，单击新建或打开。非编辑时折角纸图标，编辑时叠加铅笔；注释窗口“完成”或关闭提交，取消丢弃本次文字修改。保存或切换文档先提交正在编辑的注释，避免丢字。清除全部可撤销；面板按钮打开当前或首个注释的编辑面板。 |
| 计数 I | 单击编号；组下拉切换，眼睛隐藏/显示，文件夹新组，垃圾桶删除当前组，清除只清当前组。颜色、标记 1–10 px、标签 8–72 px 按组保存；Shift 拖点、Alt 单击删点。总计数、编号及可见性随组刷新。 |

标注不进入合成导出。作者、第二臂、计数组和图框样式随 `.comp` v26 保存，旧项目自动采用缺失字段默认值。

## 污点修复与移除

污点修复支持内容识别、创建纹理、近似匹配，八种混合模式、对所有图层取样、角度和压力大小。笔尖弹窗可调大小、硬度、间距、角度、圆度。取样范围改变真实像素来源；混合和选区覆盖率仅应用一次，透明目标不会重复羽化。

移除工具先选添加/减去（Alt 临时反转）并涂画覆盖区；设置大小或大小滑条、压力，齿轮调叠加颜色/不透明度。开启“每次笔触后移除”在抬笔后应用；关闭后可多笔叠加，Ctrl+Z 撤回最后一笔，Enter/勾选应用，Esc/取消清除待处理区。选“创建新图层”把结果放在独立像素层，原图可保留；所有层取样决定邻域来源。应用作为一次历史编辑，撤销恢复原图。

模式“自动”与“生成式 AI 关闭”使用本地内容填充；“生成式 AI 开启”打开生成对话框，显示当前图像和设置，必须点“生成”才向已配置服务发送。需要用户自己的兼容服务、凭据和可用模型。关闭对话框不应用结果。“查找干扰”打开提供商分割：常规干扰物/人物返回待处理覆盖区，电线电缆在确认分割结果后应用移除。失败时保留原图及待处理区域；反馈按钮只打开仓库 issue 页面。没有凭据时不会伪造云端成功。

## 修复画笔与仿制源

按 Alt 单击取样，松开涂画。选项栏包括八种混合模式，取样/图案、图案选择、对齐、旧版、当前/当前和下方/所有层、忽略调整层、角度、压力、扩散 1–7。图案支持本项目图像图案，未选择时使用可见的黑白格默认图案。扩散改变颜色匹配邻域；旧版使用固定小邻域；替换模式直接使用源纹理。笔尖弹窗的大小、硬度、间距、角度、圆度和压力均影响实际笔触。

仿制源按钮打开五槽面板。每槽独立保存当前会话的源文档/图层/坐标、缩放 W/H（1–1000%）、等比、翻转、旋转、重置、帧偏移/锁帧，以及叠加显示、不透明度、裁剪、自动隐藏、反相与混合。源文档必须保持打开；切换文档可跨文档取样，源关闭后需重新 Alt 取样。对齐保持笔触间偏移；未对齐每笔从固定源点开始。

帧偏移作用于本项目时间轴的“图层帧”，不是视频解码器。叠加只用于预览，不修改源像素；后台生成失败会提示并停止该版本预览，不阻止已有文档保存。槽位与源点不写进 `.comp`；工具 JSON 预设保存可序列化设置，不包含源位图/打开文档对象。

## 修补、内容识别移动与红眼

修补工具先用套索圈选，选项栏支持新建/添加/减去/交叉；在已有选区内拖动执行修补。“源”将拖到的干净区域用于当前选区；“目标”把原选区修补到拖动位置。普通采用局部颜色匹配；内容识别额外搜索邻近候选纹理。扩散调匹配邻域；透明保留目标原 Alpha；“使用图案”以选择的图案填补选区。支持软选区与撤销。

内容识别移动先圈选再拖动；“移动”填原位置，“扩展”保留原位置。结构 1–7 调边缘保留强度，颜色 0–10 调目标颜色适配；所有图层取样决定捕获内容。开启“投影时变换”在拖后进入现有变换控件，可缩放、旋转和变形，Enter/勾选提交，Esc/取消恢复原图；关闭时拖后直接应用。整个移动及填洞合并一次撤销。选区与像素随最终变换更新。

红眼工具单击或框住眼部，瞳孔大小默认 50%、变暗量默认 50%，字段和下拉滑条同步。只校正范围内满足红色优势条件的像素，按选区覆盖率混合，透明度保持；无红眼时不创建无效历史步骤。

以上为 8 位修饰运算；既有高位深源文件可以打开，但修饰目标采用现有栅格编辑策略。真实数位板、Windows 10、真实生成式服务未在本机验证。自动回归入口为 `--utility-retouch-checks`；低资源与实机步骤见 [COMPATIBILITY.md](COMPATIBILITY.md)。
