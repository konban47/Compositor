# 钢笔、工作路径与图层拖动

适用于 Windows **1.5.12.3 Preview**。

## 三种钢笔

P 工具组包含钢笔、自由钢笔与弯度钢笔。默认选择“路径”，创建不参与渲染的工作路径；“形状”创建可编辑形状层，闭合路径默认填充，开放路径至少使用 1 像素描边。“像素”与参考图一致禁用。形状模式提供前景色和描边宽度；“对齐边缘”将新节点定位到整数像素，路径模式下禁用。

- 钢笔：单击添加节点，按住拖出方向柄，Alt 拖动断开传入手柄。“自动添加/删除”开启时，单击现有路径边添加节点，单击节点删除；关闭该选项或按住 Ctrl 可选择和拖动节点。方向柄可直接拖动。
- 自由钢笔：按住左键绘制，释放后拟合并完成路径。“曲线拟合”控制简化程度。“磁性的”吸附到当前合成图像的局部边缘；宽度是搜索半径，对比是边缘阈值，频率控制采样间距。Alt 临时跳过吸附。“钢笔压力”调节磁性搜索半径，鼠标按完整压力处理；真实数位板需单独验收。
- 弯度钢笔：依次添加节点，自动生成曲线。双击节点切换角点／平滑点，可拖动调整位置。

已有至少三个节点时，鼠标距起点不超过 **10 屏幕像素**会显示右上角小圆圈，起点变为实心蓝色；单击即闭合。距离不受画布缩放影响。选中的节点也显示实心蓝色。Enter 完成开放路径，Esc 取消当前草稿；自由钢笔在起点附近释放可闭合。

齿轮菜单包含路径粗细、颜色与预览。钢笔和弯度钢笔有“橡皮带”，预览下一段；自由钢笔另有拟合和磁性设置。粗细与颜色沿用首选项里的路径显示设置，不改变实际形状描边。钢笔参数可保存为工具预设，导入时校验数值范围；应用预设后继续修改不会改写原预设。

## 建立选区、蒙版和形状

- **Ctrl+Enter** 把当前草稿／工作路径／所选形状或矢量蒙版轮廓转换为现有选区。开放轮廓按闭合面积取选区；画笔、填充、删除、选区画笔、滤镜和蒙版继续使用这份选区。文本编辑时不会抢占文字输入。
- “建立 → 选区…”可设置羽化、消除锯齿，以及新建／添加／减去／交叉四种操作。
- “蒙版”把路径转为选中图层的矢量蒙版，遵循绘制锁定。当前版本一个图层只有一个蒙版槽，因此该操作替换已有蒙版。
- “形状”创建可编辑形状层。工作路径保留，可再次转换。以上操作可撤销。
- “窗口 → 路径”面板提供完成／取消、路径转选区、删除工作路径和文字建立工作路径入口。

工作路径随 `.comp` 保存为 **Windows v24**，参与撤销、恢复、裁剪、缩放、旋转及翻转；草稿尚未完成时不写入项目。旧 Windows 版本与 macOS 原版不读取 v24。没有工作路径的项目仍按所需最低版本保存。

## 组件操作

路径操作菜单支持新建、合并、减去顶层、相交和排除重叠；设置作用于下一条完成的路径。合并先保留独立子路径，“合并形状组件”再执行联合运算。布尔运算按填充面积处理，开放路径会隐式闭合。

排列菜单把选中节点所在的子路径置顶／前移／后移／置底；没有节点选择时作用于最后一个子路径。对齐和分布作用于当前路径的所有子路径，可按路径整体范围或画布对齐；分布需要足够的组件。形状模式下作用于所选形状。操作不需要栅格化，撤销可恢复。

## 图层拖动

在图层名称区域或图像缩略图上按住左键约 **220 毫秒**，或移动超过 **5 DIP**，进入拖动。浮动名称预览跟随鼠标，蓝色插入线表示释放位置，原始行淡出；落位后以 150 毫秒动画移动到新位置。

Ctrl／Shift 先多选后拖动，保留各层的相对顺序；选中组连同后代移动。指针靠近列表上下边缘会自动滚动，停住也持续滚动。Esc 或丢失鼠标捕获取消操作，锁定与组循环保护继续生效，一次拖动可一次撤销。可拖到另一个文档标签复制图层。

眼睛、折叠按钮、蒙版缩略图及 Ctrl+单击图像缩略图保留原动作。蒙版缩略图用于选择蒙版；图像缩略图用于选择像素或开始拖动。中键平移列表继续可用。
