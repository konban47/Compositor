# Windows 1.4.9.4 Preview

2026-10-11。开始前 fetch 并核对：本地与 `origin/windows-port` 均为 `ef97e9222a3a152b112252b429d17ce3bbd56f6c`，无远端差异需合并。上游 [Compositor](https://github.com/robbietilton/Compositor) 仍为 **1.4.9 / `b4bfdea87f9dc0cbc9eabfa63683eb1b9c2bca60`**，没有新增提交需要移植。

## 修复与新增

- Alt 取样显示靶心与源点十字、状态坐标；仿制图章／修复画笔支持对齐偏移显示，切换文档清除取样。作用范围工具显示随直径、缩放和视图旋转一致的圆形光标；文字工具使用 I 形光标。
- 快捷键窗口增加宽度、允许名称换行、保留按键列，调整中文按钮行高。网格按整个视口生成，修复右侧／底部缺线，旋转及极小缩放也不会截断。
- 增加选区画笔、磁性套索、快速选择、透视裁剪、切片、切片选择、图框、颜色取样器、标尺、注释、计数、移除、修复画笔、修补、内容感知移动、红眼、铅笔、颜色替换和混合器画笔，合计 69 个工具。所有新增工具具有实际操作、中文选项和快捷键分组。
- 文档切片／标注／测量支持移动、编辑、删除、撤销、保存以及文档坐标变换；图框导入按比例填充；切片可按参考线生成、等分和导出 PNG＋JSON。新标注使用格式 v17，旧项目按最低必要格式保存。
- 四个上游自绘图标直接移植：仿制图章、渐变、多边形套索、对象选择。工具按钮参数来自 `ContentView.swift`。其余 SF Symbols／SwiftUI 调用使用 Windows 矢量及控件对应实现，新增图标匹配单色风格。来源清单、MIT 说明与 CI 哈希校验同步。
- 首页、Windows 说明、工作区／编辑／新增工具手册、项目格式、包内文档、版本号和 CI 防漂移检查一起更新。
