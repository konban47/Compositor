# Windows 1.5.12.2 Preview（草稿，未发布）

2026-10-29。**本说明尚未对应任何发布包**：代码未在 Windows 本机编译和测试，版本号仍为 1.5.12.1。验证通过后再将各手册、`Compositor.Desktop.csproj`、`package.ps1`、`Compositor.iss` 与 README 切换到本版本。

- 新增“文件 ▸ 脚本 ▸ 脚本事件管理器…”。布局参照截图：顶部启用开关和关联列表，下方选择事件、脚本或动作，右侧完成、移去、全部移去、添加。主题、字体、按钮沿用 Compositor，浮窗按钮不变。
- 事件：启动应用程序、新建文档、打开文档、开始存储文档、存储文档、关闭文档、打印文档、导出文档、全部；“添加事件…”可选择任一菜单命令作为事件。
- 内置脚本由本程序原生实现：Clean Listener（清除事件日志）、显示相机制造商、打开为图层、调整大小（1920 × 1080 内，不放大）、存储额外 JPEG、更新文件信息、警告如果是 RGB、欢迎。“基本调整”动作组提供与批处理相同的 6 个动作。
- 修改文档的脚本和动作各为一个历史步骤，可撤销／重做；在对话框中关闭窗口或按 Esc 会放弃改动，按“完成”才会保存。设置保存在设置目录的 `script-events.json`（版本 1），重启后重新载入；运行记录写入 `script-events.log`。
- 限制：没有 ExtendScript／JavaScript 解释器，“浏览…”选择的外部 JS/JSX 会被明确拒绝，不会显示为可运行。本程序无打印命令，“打印文档”不会触发。Web 导出和图层导出暂不触发“导出文档”。“全部”不包含添加的菜单命令事件。
- 验证计划：`ScriptEventsTests`（设置往返、校验、匹配、日志、调整大小、文件信息、额外 JPEG、打开为图层、动作）和 `--file-workflow-checks` 中的脚本事件自检。

其余未完成项保持不变，见 [交接记录](TASK-CHECKPOINT.md)。独立颜色引擎不是 Adobe ACE 原引擎，未声称逐像素等价。不提供 Creative Cloud 同步。
