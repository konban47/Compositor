# 选区、裁剪与切片

适用于 Windows **1.5.6.0 Preview**。工具栏右键／长按展开工具组；M 为选框组，L 为选区画笔／套索组，W 为对象／快速选择／魔棒组，C 为裁剪／切片组。旧工具栏预设可通过“自定义工具栏 → 恢复默认值”显示新增单行与单列工具。

## 选区

| 工具 | 选项和作用 |
| --- | --- |
| 矩形、椭圆、单行、单列 | 新建、添加、减去、交叉；羽化；正常／固定比例／固定大小；宽高互换。单行／单列始终为跨画布的 1 像素选区，尺寸框禁用。矩形及单行／列使用硬边，椭圆可切换消除锯齿。 |
| 选区画笔 | 添加／减去、不透明度、笔尖大小／硬度弹窗、叠加颜色。软笔尖和不透明度写入选区覆盖率；交叉可按 Shift+Alt 临时使用。 |
| 套索、多边形套索 | 四种组合模式、羽化、消除锯齿、选择并遮住。 |
| 磁性套索 | 套索选项，加宽度、对比度、频率、笔压力控制宽度。Alt 暂停吸附；Backspace 删除点；Enter／双击／起点闭合；Esc 取消。压力来自数位笔事件，鼠标按满压力处理。 |
| 魔棒 | 四种组合模式、取样点或 3／5／11／31／51／101 像素平均、容差、消除锯齿、连续、所有图层取样、选择主体、选择并遮住。 |
| 快速选择 | 新建／添加／减去、笔尖大小／硬度、角度、所有图层取样、增强边缘、选择主体、选择并遮住。按笔触沿途播种颜色连通区域，角度改变横向播种方向，增强边缘进行颜色引导的边缘平滑。 |
| 对象选择 | 四种组合模式；矩形或套索圈定区域，选择与范围相交的完整前景连通对象；单击选取鼠标下的对象。支持所有图层取样、硬化边缘、查找程序开关、对象减去、自动／手动刷新、全部对象预览、叠加颜色／轮廓／不透明度／显示方式及画布尺寸提示。 |

Shift 临时添加，Alt 临时减去，Shift+Alt 临时交叉；原有软覆盖率在组合时保留。选择并遮住提供半径／智能半径、平滑、羽化、对比度和移动边缘的实时预览；取消恢复原选区，确定成为一次撤销操作。工具预设保存这些参数，导入检查范围并拒绝无效尺寸。

“选择主体”旁的下拉框选择设备／云。设备模式使用随包 U²-NetP，图像不上传。对象查找同样依赖显著性分割，不能保证识别每个独立物体。“选择人物”提供画布点选和云端两条路径：本机由用户指向人物前景区域，不具有人物类别、面部或身体部位分类；云端发送人物掩模指令，经生成窗口由用户确认运行。云端服务须在生成式工作区配置，不是 Adobe Firefly，也不保证服务模型返回严格掩模；未配置时不能执行云端生成。

## 裁剪与透视裁剪

裁剪下拉菜单包含比例、宽×高×分辨率、原始比例、1:1、4:5、5:7、2:3、16:9、常用打印／像素预设、前面的图像，以及新建／删除自定义预设。宽高为 0 时不限制该组尺寸；宽×高×分辨率模式在两项尺寸均大于 0 时重采样。分辨率可切换像素／英寸和像素／厘米，保存统一使用 ppi，最大 9600 ppi。

拉直工具沿应当水平或垂直的边拖线，旋转图像并保留一次撤销。网格菜单包括三等分、网格、对角、三角形、黄金比例和黄金螺线，支持自动／始终／从不显示、循环种类和取向。齿轮菜单设置经典模式、显示裁剪区域、自动居中预览、裁剪屏蔽及其颜色／不透明度。经典模式拖动裁剪框；默认模式在固定裁剪框下平移图像。自动居中控制应用后的适合视图，自动不透明度在拖动时减弱屏蔽。

“删除裁剪的像素”清除普通栅格层框外像素；关闭则保留框外源像素。可编辑文字、形状及智能对象保留其源内容。透明填充保留扩展空白；内容识别填充从当前合成图的邻域纹理补全扩展区；生成式扩展打开已配置服务的生成窗口，只把生成结果的扩展区作为底层加入，保留原区域。透明且没有可采样源的区域无法内容识别填充。所有裁剪使用草稿，确认后提交一次撤销；取消不修改文档，耗时结果不会覆盖随后发生的编辑。

透视裁剪提供宽高、互换、分辨率及单位、前面的图像、清除、显示网格。拖出四边形后移动四角，Enter 应用，Esc 取消。输出尺寸为 0 时按边长推算。透视校正会栅格化文字、形状、智能对象和矢量蒙版；可以撤销。

## 切片

切片工具支持正常、固定比例、固定大小，以及基于参考线的切片。自动切片覆盖用户切片之外的画布空隙，不写入项目；“隐藏自动切片”只改变显示。“提升”将选中的自动切片转为用户切片。

切片选择可单击或 Shift 多选、整体拖动、拖右下角调整大小、双击编辑。四个排列按钮调整前后顺序；六种对齐、六种边缘／中心分布和两种间距分布，以选区或画布为基准。Delete 删除所选用户切片。

“划分”分别启用水平／垂直划分，按数量等分或按每片像素数切分，末片保留余数；预览开关不提交文档，取消清除预览，不会提升自动切片。总标注数限于 10,000。

切片选项包含图像／无图像、名称、URL、目标、信息文本、Alt 标记、X／Y／W／H、背景类型及颜色。导出写入 PNG 和 JSON 清单，包含自动切片；无图像切片只写清单。背景色合成在透明像素下。URL 与目标只保存为数据，不打开网页，不输出 HTML 模板，不覆盖已有同名文件。

扩展切片属性和平滑圆角使用 [Windows v23 格式](../docs/project-format.md#windows-extension-version-23)。旧版不能读取 v23；没有使用新增字段的文档仍按最低必要版本保存。

## 窗口与主题

浮窗标题按钮的 8 像素高矢量标志在约 11 像素标题条中垂直居中；三点按钮统一圆点半径。上下文任务栏新布局默认关闭，已保存工作区的可见性继续保留，停靠时不显示标题名字。深灰主题的原生上边框跟随标题颜色，关闭按钮悬停为红色，保留项目 logo 和系统圆角。Windows 10 的外框圆角仍由系统能力决定。

四套主题采用实心矩形滑块与轻微圆角：深色主题使用较亮滑块，浅色主题使用较暗滑块。右侧纵向滚动条常驻，横向滚动条嵌入最底部信息栏中间。箭头、轨道和拖动滑块都能平移画布；侧面板使用同一套样式。左侧工具栏已取消滚动。

## 验证

`--selection-options-checks` 在英文与中文环境检查 15 个工具栏、单行／单列、固定尺寸、交叉、羽化、软画笔、预设、裁剪取消、切片编辑／取消／撤销以及实际滚动条拖动，并输出测试画布截图。现有指针、专业工具、窗口、停靠和标题栏检查继续运行。云端服务的实际生成、真实数位笔压力和 Windows 10 实机未在自动化中验证。


## 1.5.3.1 切片选项入口

切片选择工具的“切片选项”按钮直接打开属性窗口。未选择时先选取现有切片，若没有手动切片则选取自动切片（空白文档对应整幅画布）。取消不改动切片；确定后自动切片转为手动切片，属性修改可撤销。

窗口按参考布局分为类型与链接信息、X/Y 与宽高、背景设置，确定／取消在右侧。四个排列按钮依次为置于顶层、前移一层、后移一层、置于底层；[图标来源和完整生成提示词](design/slice-order-icons/README.md)随文档保存。
