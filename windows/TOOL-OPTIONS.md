# 填充、修饰、视图与路径工具 — Windows 1.5.13.0 Preview

当前为 **1.5.13.0 Preview**。控件顺序和弹出面板依据本次参考图，字体、圆角、按钮、焦点反馈和深浅主题沿用 Compositor。浮窗标题按钮保持原样。

## 渐变与油漆桶

- **渐变**在拖动后创建可编辑的渐变图层；再次选择该图层，可拖动两端控制点，或修改预设、形状、方法、反向、仿色。撤销会同时恢复像素和选项。选区限制以图层蒙版保留。
- **经典渐变**直接修改当前图层像素；使用不透明度和混合模式。通道及蒙版目标也使用像素渐变。
- 五种形状为线性、径向、角度、对称、菱形。方法包括可感知（Oklab）、线性光、古典（编码 RGB）、平滑和条纹（色标间保持颜色）。
- 点击色带编辑色标位置、颜色、不透明度；可增加或删除色标。预设菜单支持新建、重命名、删除、五种显示方式、追加默认、导入和导出。交换格式为 Compositor JSON，不是 Adobe GRD。
- **油漆桶**可选前景色或图案，使用完整混合模式、不透明度、0–255 容差、消除锯齿、连续和所有图层取样。图案复用图案预设库；填充受当前选区限制，所有图层只改变取样范围，结果仍写入当前目标。

## 局部修饰与调整画笔

| 工具 | 选项及行为 |
| --- | --- |
| 模糊 | 画笔预设、设置、七种混合模式、强度、角度、所有图层取样、压力大小；在笔触覆盖范围柔化像素。 |
| 锐化 | 同上，并提供保护细节，对局部对比增强作限制。 |
| 涂抹 | 同上，并提供手指绘画；把前一笔触位置的颜色带向后续位置，启用手指绘画会在起点加入前景色。 |
| 减淡／加深 | 阴影、中间调、高光范围，曝光度、压力强度、角度、保护色调和压力大小。保护色调使用亮度合成，减少色相变化。 |
| 海绵 | 去色／加色、流量、压力强度、角度、自然饱和度与压力大小；自然饱和度减弱对高饱和色的作用。 |
| 调整画笔 | 18 种调整、添加／减去、画笔预设、对象应用、蒙版叠加、不透明度、流量、压力与喷枪。每种调整生成独立调整图层，白色蒙版显现效果、黑色隐藏效果。 |

调整画笔支持颜色和自然饱和度、清晰度和去雾、颗粒、亮度/对比度、色阶、曲线、曝光度、色相/饱和度、颜色平衡、黑白、照片滤镜、通道混合器、颜色查找、可选颜色、反相、色调分离、阈值和渐变映射。选中同类型的调整图层可继续绘制；“调整设置”或属性面板可修改参数。“应用调整到对象”后单击对象，使用现有本地对象检测生成调整范围。叠加仅用于显示蒙版，不进入导出图像。

画笔预设包含四组、28 个原创程序笔刷，以双列笔触卡片展示。搜索、折叠组、缩略图大小和预设保存保持可用；这些不是参考图中 Kyle 商业画笔资产。笔触预览由实际画笔引擎绘制。局部修饰共享笔尖大小、硬度、角度、圆度、间距及压力动态；颜色源由各修饰工具决定。

## 缩放、抓手与旋转视图

- 缩放：放大／缩小，Alt 临时反转；细微缩放时水平拖动连续缩放，关闭时拖框缩放。100%、适合屏幕和填充屏幕分别使用原始像素比例、完整可见比例和覆盖视口比例。
- 抓手：拖动画布，支持滚动所有打开的文档窗口，并提供三个比例按钮。
- 旋转视图：输入角度或拖动圆盘，也可在画布上拖转；Shift 约束为 15°。复位恢复 0°。旋转所有窗口同步角度变化。
- 缩放所有窗口同步比例变化；调整窗口大小以满屏显示会在正常窗口状态下按工作区边界调整窗口。以上只修改视图，不修改文档像素或导出方向。

## 路径选择与直接选择

- 现用图层／所有图层控制点击拾取范围。路径选择移动整个被点击组件，Shift 可选多个组件；直接选择移动锚点、方向手柄或曲线段，Shift 可选多个锚点。
- 形状图层可修改填充、描边颜色、宽度、实线／点线／虚线／长虚线；W/H 改变路径尺寸，链接按钮约束比例。无形状目标时禁用外观控件，工作路径保持不直接渲染。
- 路径运算提供新建、合并、减去顶层、相交、排除重叠和合并组件；排列提供置顶、前移、后移、置底。
- 对齐弹窗提供六种对齐、六种分布、两个间距分布；目标可选当前组件的选区边界或画布。分布需有足够组件。
- 对齐边缘把拖动位置对齐到文档像素。约束路径拖动限制曲线段拖动对相邻手柄的影响；Shift 拖动曲线段约束角度。
- 路径选项设定显示线宽（0.5、0.75、1、2、3 像素或自定义）和十种显示颜色，只影响编辑辅助线，不改变图层描边。

## 上游 1.5.8 镜头效果

滤镜菜单新增变形镜头光晕、星芒、柔雾、棱镜、散景。参数使用上游定义；处理在浮点线性光中计算，最后恢复原始透明度，遵循选区并支持预览、取消和撤销。

Windows 使用 Skia CPU 算法：最长边 1024 的光学工作网格，散景 384；散景支持圆形、六边形、椭圆及猫眼光圈。长光晕／星芒通过旋转后的各向异性高斯扩散近似，亮源筛选采用局部密度权重，因此与上游 Core Image/Metal 输出不逐像素相同。散景按工作网格插值回原始尺寸，原有透明度保持不变。

项目仅在使用可编辑渐变、独立路径填充／描边字段或清晰度／去雾调整时写入 Windows v28；普通旧项目继续按所需最低版本保存。旧版不能读取 v28，应使用新版或先导出图像。

## 上游轮廓光与体积光（1.5.13.0）

“滤镜”菜单新增“体积光…”和“轮廓光…”，移植上游 `b9a0ed8`、`97c3b3f`、`1405545`。上游在 GPU（Metal）上计算；Windows 以浮点平面在 CPU 上计算，高斯模糊用三次盒式模糊近似，光照网格的长边限制为 2048（轮廓光）／1024（体积光的光束与雾气场），再把光叠加到每个原始像素；16 位与 HDR 图层保持位深。

- 轮廓光：主体由内置 U²-NetP 模型识别（每张图层图像只识别一次，面板打开前完成），经导向滤波贴合照片边缘；最多三盏灯，各自有颜色、角度、强度、宽度和收缩，可添加／移除；“发光”把灯光散入主体周围并向内包裹一点。杂乱背景中的发丝只有在比背景自身变化更突出时才被照亮。没有找到主体时不应用。
- 体积光：光源初始位于图层最大的明亮区域（与上游同一算法）；面板以“光源 X／Y（%）”移动光源，因为 Windows 的滤镜面板为模态对话框，不能在画布上点击或拖动。另有颜色、雾气、大小、强度、长度和光束分散。主体和照片中的暗部会在光束中投下阴影，雾气在主体前方更薄。
- 限制：预览与应用使用相同计算；上游 Metal 着色器的逐像素结果不保证位精确一致。
