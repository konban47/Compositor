# Windows 1.5.10.0 Preview

2026-10-26。本版继续遵循用户提供的面板布局与交互截图，使用 Compositor 的主题、字体和按钮。浮窗紧凑标题栏按钮不变。

## 主要变化

- 横排／直排文字和文字蒙版选项栏：本机字体、真实字重与字宽、字号、方向、对齐、动态文字、变形、提交／取消，与字符和段落面板联动。
- 紧凑字符／段落面板：字号、行距、字距、缩放、基线、颜色、OpenType、语言、消除锯齿、段落缩进／间距、断行和标点设置。继续使用 Skia／HarfBuzz；排版结果不承诺 Adobe 逐像素一致。
- 注释正文及导航；图层复合的可见性／位置／外观保存、应用和局部更新。
- 文档视频时间轴、帧动画、关键帧、工作区域、播放、链接视频／音轨、FFmpeg H.264 渲染窗口；原 GIF 帧编辑器保留。媒体工具为可选外部依赖。
- 指定配置文件的三种模式、预览、取消与撤销；共享预设管理器及 12 个等高线。
- Windows 项目格式按需升级为 v29。两个 README、使用手册、包内文档、版本号和源文件散列同时更新。

操作与明确的支持范围见 [时间轴与预设](TIMELINE-AND-PRESETS.md)、[文字](TYPE-AND-MASKS.md)、[颜色管理](COLOR-MANAGEMENT.md)。ACE 保持独立兼容实现，不包含 Adobe ACE 二进制，也不宣称逐位相同。Creative Cloud 同步继续移除。

## 上游

参考源码合并到 `2d75d9172835e1dd6111cb2b659958ec33fa5abf`，即 main 中的 1.5.10 更新。新增 Vignette、Lens Effects、Tonal Contrast、Sharpen 调整图层；Sharpen 以 Amount／Radius 执行 unsharp mask；裁切增加 2.39:1。已有移动工具及菜单提供对齐／分布。上游嵌套滤镜设置和版本 18／19 可读取，Windows 新保存采用独立 v29。

Windows 仍使用 CPU 滤镜与 Skia 显示，不移植 Metal／Core Image GPU 内核。镜头效果保留 1024 工作网格、散景 384 的近似；当前没有上游 Metal 散景缓存和同等性能承诺。参考 [上游发布说明](https://github.com/robbietilton/Compositor/releases) 与仓库提交。
