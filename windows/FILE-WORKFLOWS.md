# 文件工作流 — 1.5.12.1 Preview

适用于 **1.5.12.1 Preview**。菜单、对话框和导出共用文档、颜色、图层与撤销数据；按钮和文字使用 Compositor 的现有设计。以下区分可执行功能和未交付能力，避免截图或菜单标签被误认为实现证明。

| 入口 | 当前可执行行为 | 边界 |
| --- | --- | --- |
| 存储副本／恢复 | 副本不重绑当前文档；恢复从磁盘读取，可撤销，载入期间文档改变会取消 | 原生项目恢复 |
| 文件简介 | 编辑标题、作者、说明、版权、邮箱、网站、关键词、相机制造商／型号、拍摄日期 | 每字段 32768 字符，总计 131072；不是完整 EXIF 编辑器 |
| 导出为 | PNG、JPEG、TIFF、GIF、EXR、PDF，尺寸／质量与元数据策略 | 不支持 PSD 输出；格式支持项不同 |
| 储存为 Web 所用格式 | 四种预览布局；PNG-24／PNG-8／JPEG／GIF／WBMP；调色板、仿色、透明度、目标大小优化、重采样 | 静态图像；不输出 HTML 切片或动画；目标大小可能无法达到 |
| 批处理／图像处理器 | 文件／文件夹／已打开文档；内置自动色彩、色调、对比度、自然饱和度、去色、均衡化；重命名、缩放、多格式、取消及日志 | 内置动作集，不是通用 Photoshop 动作解释器 |
| 创建快捷批处理 | 保存 JSON 配方，生成 Windows 快捷方式；拖入文件按配方执行 | 需要已安装的本程序；不生成独立 EXE |
| 联系表 II | 文件／文件夹／已打开文档；cm／inch／px；分辨率；横向／纵向；行列与间距；旋转；文件名题注；字体与样式；拼合／图层 | RGB／灰度／CMYK／Lab，8／16 位，匹配模式的 ICC，真实字体样式；按文件夹分页、px／cm／inch 和 ppi／像素每厘米换算；保留高精度源像素 |
| 图像统计／载入图层 | 11 种统计量；可选平移对齐；非破坏性新文档结果 | 对齐仅平移，不是仿射或全景配准 |
| PDF 演示文稿 | 静态多页 PDF，排序、题注和背景 | 没有自动换片、循环或过渡 |
| 图层／图层复合导出 | 逐项文件或 PDF，保留必要祖先／裁剪关系 | 已支持格式，非 Adobe PSD |
| 限制图像／条件模式更改 | 保持比例缩放、不放大；按源模式匹配后转换，涉及拼合时提示 | 仅现有文档颜色模式 |
| 打开为智能对象／置入嵌入对象 | 使用现有智能对象保存与编辑机制 | 链接对象、打包依赖和 Bridge 尚未完成 |
| 脚本 → 删除所有空图层 | 单步撤销／重做；保留锁定层、GIF 层和仍被剪贴层依赖的空底层 | 不把透明首帧视为整个动画为空 |
| 脚本 → 拼合所有蒙版／图层效果 | 处理可编辑像素图层；GIF 蒙版逐帧应用；包含未选中和隐藏图层；保留整体不透明度、可见性与撤销 | 组蒙版／组效果、GIF 效果及锁定层不会被烘焙；依赖背景的混合效果仍需专项验收 |
| 导入 → 变量数据组 | 共用已有变量定义、CSV 数据组、应用与撤销流程 | 不是 Adobe 二进制数据组格式 |
| 导入 → 视频帧到图层 | 起止时间、帧速率、每 N 帧、最大尺寸；真实 FFmpeg 解码、取消、独立新文档和可选帧动画 | 需 FFmpeg / ffprobe 在 PATH；帧动画上限 100，纯图层上限 1000，并受内存预算约束；不提取音轨 |
| 导入／导出注释 | 作者、内容、位置、颜色往返；导入重新生成 ID；支持撤销 | 本程序 `.comp-notes.json` v1，最多 1000 条／4 MB；未实现 PDF/FDF/Photoshop 注释读取 |
| 脚本 → 载入多个 DICOM 文件 | ImageMagick DCM 解码，单帧和多帧，每帧独立图层，16 位文档，取消与失败释放 | 最多 256 帧且受内存预算约束；不保留原始医学元数据或提供体积重建；传输语法支持取决于解码器 |
| 导入 → WIA 支持 | 在 STA 线程调起 Windows 原生扫描仪选择／采集界面，成功后创建新文档 | 需 WIA 驱动及硬件；取消不创建文档，无设备报错；本次无扫描仪实机验收 |

视频帧导入保留源帧比例，不放大低分辨率素材。采样区间包含开始、不包含结束；每帧时长按采样间隔设置，末帧裁至选择结束。导入后项目保存所有像素，删除源视频仍可重开播放。失败／取消不会留下部分导入文档。

接口依据：[Windows WIA ShowAcquireImage](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/wiaaut/-wiaaut-icommondialog-showacquireimage)、[ImageMagick DCM 支持](https://imagemagick.org/formats/)。

元数据提供“无”“版权”“版权和联系信息”“除相机信息外的全部”“全部”。Web 与批处理默认保留版权和联系信息；普通导出默认无。PNG、JPEG、TIFF、GIF 使用 XMP；读取只覆盖本版支持的 XMP 字段，不保证保留原文件中的全部 EXIF、IPTC 或厂商私有信息。PDF、EXR、WBMP 不提供上述全部元数据输出。ICC 与 XMP 是不同选项，删除元数据不会隐式删除请求保留的 ICC。

批处理输出使用独立文件名，避免静默覆盖输入；进度中可取消，已成功生成的输出会保留。文件夹扫描跳过重解析目录，任务最多处理 10000 个文件。保存的配方和 Web 预设是本程序版本 1 的 JSON 格式，不是 Adobe 二进制预设。

截图中的脚本事件管理器、Photomerge、HDR Pro、完整镜头配置校正、Web HTML／切片／动画和 PSD 写入仍需后续实现。项目此前画笔、路径、文字、时间轴、颜色管理等功能也不能仅凭当前文件工作流检查认定全面验收；参见各专用手册中的限制。
